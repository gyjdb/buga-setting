这是对17份候选逐步追踪的规则推演，不是现实执行、软件自动模拟或世界物理实测。PASS仅指明确列出的输入条件下，权限和程序链闭合；CONDITIONAL指出实体法、设备或作者物理边界使整个案例不能无条件完成。每案包含全部八个环节，缺口不能用“主管机关依法处理”掩盖。全部依据指[候选索引](<../00_PROJECT/CANDIDATE_CANON_INDEX.md>)中的版本。

## S01 普通居民日常施法 — PASS

| 环节 | 推演 |
| --- | --- |
| 触发 | 已会二环家务术式的居民在自由区施法；另以十二环能力者施同一术式作对照 |
| 主管机关 | 居民承担合法使用义务，属地治安只在事故或违法触发时介入 |
| 法律依据 | K20第三、二十、三十一条；K13第五、六条 |
| 程序 | 核对实际术式与场所，不按施法者最高环级要求高阶许可，也不要求全民先持认定证 |
| 执行 | 按已有能力施法；涉危险知识或特殊职业另循其规则 |
| 监督 | 现场规则及事后合法调查，不普遍窥探心智 |
| 救济 | 被无依据索证可申请行政复核或裁断 |
| 结束条件 | 完成活动且无事故即结束，无额外逐次备案 |
| 具体缺口/适用限制 | 本例不推定每个居民都有施法能力 |

| 监督 | 考官回避、原始记录保存、复核独立 |
| 救济 | 三十日申诉及程序司法救济，不自动作学术授证 |
| 结束条件 | 发证登记或告知未证项目；复核结案 |

## S04 职业巫师执业 — CONDITIONAL

| 环节 | 推演 |
| --- | --- |
| 触发 | 有六环证的居民申请从事尚无完整规范的新专业服务 |
| 主管机关 | K10对应行业主管机关，不是认定公会单独决定 |
| 法律依据 | K20第二十条；K10行政第七条；K27学实二 |
| 程序 | 先查是否有现存专项准入依据；凭证分别核验，不凭目录新增强制许可证 |
| 执行 | 既有合法资格可维持，依法受雇于已有明确岗位者按岗位条件；新强制执业门槛不能虚构 |
| 监督 | 主管业务监督，监察公职滥权 |
| 救济 | 无依据拒绝可复核/司法；不得因行业规则缺失无限索证 |
| 结束条件 | 明确告知可办理事项及缺法部分，不发虚构全行业资格 |
| 具体缺口/适用限制 | 断点为IF02行业实体条件与职业责任，需未来模块；不需作者魔法物理决定 |

## S05 魔法事故 — CONDITIONAL

| 环节 | 推演 |
| --- | --- |
| 触发 | 持合法许可的施法者在工坊造成伤害 |
| 主管机关 | 工艺与奥术科技部技术牵头，治安/监察各查其部分，裁断归责 |
| 法律依据 | K20第三十三条；K10行政第六条；K23许可第八条；K26司实三 |
| 程序 | 先救助隔离、保存许可和设备记录，独立技术鉴定，分离操作者/组织者/设施/审批责任 |
| 执行 | 合法应急预算先行救助；违法部分移送；不因持证免责或事故自动定罪 |
| 监督 | 监察审公职和费用，庭署审保全和证据 |
| 救济 | 陈述、质证、保全异议，返还/纠正及赔补请求 |
| 结束条件 | 危险解除、复运验收、调查移送或结案；未定赔补单列 |
| 具体缺口/适用限制 | IF03缺通用损害估价和赔偿分担实体法，不能宣称全额赔付已可算 |

## S06 禁魔区事件 — PASS

| 救济 | 现场异议、复核与有权庭署救济 |
| 结束条件 | 风险消除或措施到期解除，保留凭证 |
