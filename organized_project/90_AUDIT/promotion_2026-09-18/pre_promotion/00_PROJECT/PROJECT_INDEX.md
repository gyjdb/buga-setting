# 项目入口

先读[作者基础原文](AUTHOR_FOUNDATIONS_v0.1.md)，再读[作者决定影响报告](AUTHOR_DECISIONS_IMPACT_REPORT.md)。本轮完成物理归整与权威映射，尚未改写法规。

| 文件 | 用途 |
| --- | --- |
| [PROJECT_CHARTER](PROJECT_CHARTER.md) | 目标、范围、最高权威与工作规则 |
| [PROJECT_STATE](PROJECT_STATE.md) | 新作者答案后的项目状态 |
| [CANON_INDEX](CANON_INDEX.md) | 17份现行原样副本及适用限制 |
| [VERSION_LEDGER](VERSION_LEDGER.md) | 作者v0.1入库与旧版本分支 |
| [DECISION_LOG](DECISION_LOG.md) | 作者逐项答案及52条历史记录 |
| [CONFLICTS](CONFLICTS.md) | F01–F25重新定性及AF01–AF10作者影响 |
| [OPEN_ISSUES](OPEN_ISSUES.md) | 作者级保留意见与一般制度任务 |
| [FILE_MAP.csv](FILE_MAP.csv) | 每个输入到副本的路径、分类、权威及哈希 |
| [ORGANIZATION_REPORT](ORGANIZATION_REPORT.md) | 复制范围、数量和完整性验证 |
| [作者决定登记](../90_AUDIT/AUTHOR_DECISION_REGISTER.md) | 原回答/副本行号与确定性边界 |
| [改进版逐条映射](../90_AUDIT/IMPROVED_VERSION_CLAUSE_MAP.md) | 4文件逐条A/B/C |
| [原归档索引](../99_SOURCE_ARCHIVE_INDEX/README.md) | 所有原始路径与源档关系 |

目录隔离：01_CURRENT_CANON按七个领域分类；02_PROPOSALS保留2份许可提案；03_UNRESOLVED保留混合/待定来源；04_REFERENCE为参考文本及包装材料；05_SUPERSEDED为13份旧正文；06_HISTORY为对话容器；90_AUDIT为旧审计完整副本与本轮映射；99_SOURCE_ARCHIVE_INDEX为原导出/清单和作者原TXT副本。

读取规则：先最高作者明确命题，再历史明确决定；作者未定的事项不得用低位文档补成确定。CURRENT_CANON中被覆盖的句子只用于识别待修位置。旧审计、脚本、Memory和raw容器永不整体提升为Canon。历史副本中的链接未因复制改写，若失效请查FILE_MAP，而不是沿旧链接判断文件丢失。
