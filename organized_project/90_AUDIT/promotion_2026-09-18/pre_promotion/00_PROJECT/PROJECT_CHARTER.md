# 项目主旨与当前工作规则

项目目标仍是可自洽运行的完整魔法国家：魔法作为生产、军事、科研和社会基础，必须能够解释国家治理、经济、教育与普通生活。不是仅设计政府机构。目标来自用户第二阶段指令，本轮没有撤销。

最高世界观依据为[AUTHOR_FOUNDATIONS_v0.1.md](AUTHOR_FOUNDATIONS_v0.1.md)。内容不得被旧法规、Claude Memory、历史讨论或自动推理覆盖。其内明确迟疑的命题保留AUTHOR_UNRESOLVED；索引只辅助定位，不能代替原文。

权威顺序：AUTHOR_CANON → EXPLICIT_AUTHOR_DECISION → CURRENT_CANON → PROPOSAL → REFERENCE → CLAUDE_MEMORY / assistant inference。世界内的宪章最高性与这里的作者权威是两个层面。

已确认方向与未定部分分开记录。能量非稀缺、传送和即时通讯、食物/水生产、心智/侦测等已经明确存在，后续不得继续从“没有这些魔法”出发设计社会；也不得外推出无限运力、零材料、免费服务、全知司法等作者没说的结论。

本轮范围仅为复制归整、最高来源入库、版本/冲突映射和影响报告。原始各目录以及chatgpt_ready均只读；回答.txt只读；所有新增记录放在organized_project。现行法规及改进版均为字节相同副本，不作润色、改名或制度改写。

未来新内容先作为PROPOSAL，取得明确作者确认后登记权威与替代范围。任何未决命题不得由旧正文抢先变成答案；冲突保留双方定位，再由高位明确决定覆盖低位命题。能力事实获得确认不等于一整套许可/调查/处罚程序被批准。

当前工作入口为PROJECT_INDEX；旧审计只在90_AUDIT保留历史记录。若下一轮获准升级法规，应另生成有版本的新稿与逐条变更说明，不能原地改掉本轮复制的审计基线。
