1. **AUTHOR_CANON**：AUTHOR_FOUNDATIONS_v0.1.md中明确答案，以及作者之后明确确认的决定。
2. **EXPLICIT_AUTHOR_DECISION**：历史对话中作者明确采纳、否定、纠正的决定。
3. **CURRENT_CANON**：现存正式工作正文，受前两层约束。
4. **PROPOSAL**。
5. **REFERENCE**。
6. **CLAUDE_MEMORY / assistant inference**。

AUTHOR_UNRESOLVED表示最高来源内部仍未确定，不是第七层权威。UNRESOLVED/SUPERSEDED是文件状态，不能拿它们与上述权威等级混为同一排序。文件在01_CURRENT_CANON只表示它是待升级的现存正文，不代表抵触作者的句子仍可当正确设定使用。
