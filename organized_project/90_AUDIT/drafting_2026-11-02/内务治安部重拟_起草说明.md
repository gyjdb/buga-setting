# 内务治安部组织架构重拟起草说明（2026-11-02）

## 一、缘起

作者看过八份组织架构的充实以后说：“之后可能我们拟定治安部的可以参考对标。”编者答复：现行的《内务治安部组织架构》2.3.8 在机构门类上已经照公安部排过，问题是仍用被作者否定的分节体例；联盟是自治城邦的联盟，内务治安部是“两层治安体制”中的联盟一层，在分工上更像联邦警察，不像领导全国警察的公安部。建议机构门类照公安部、联盟与城邦的分工参照联邦警察。作者答：“ok没问题，那你来决定吧。”

## 二、参照

1. 机构门类：公安部。作者给的机构表见《组织架构充实起草说明》第二节。现行稿已有的对应：情报指挥中心、督察审计局、人事训练局、法制局、按局序编号的业务局、要员警卫局（特勤局）、税关缉私局（海关缉私局）、域外追缉工作局（境外缉捕工作局）、留痕鉴证局与联盟刑事鉴证中心（物证鉴定中心）、联盟犯罪信息与通缉名录中心（国家犯罪信息中心）、誓印核验技术中心（证件密钥管理中心）、嗅痕兽基地与研究所（警犬基地与研究所）、《联盟治安公报》编印所（报社）、联盟治安疗养所（招待所）、寂环塔（秦城监狱）、三所院校。
2. 分工：联邦警察。德国联邦刑事警察局只办联邦管辖与跨州的重大案件，汇集情报、提供鉴定与技术支援，统一协调对外协作，各州警察办理一般治安；美国联邦调查局办联邦罪行与跨州案件；瑞士联邦警察署办联邦刑事管辖、协调各州、负责证件与要员安保；欧洲刑警组织不直接执法，只汇集情报、协助成员国。取其分工：内务治安部只办联盟事权清单内的事项，对城邦治安提供协查、鉴证、信息与通缉、技术支援，不领导、不指挥城邦治安。这一点现行稿第六节“两层治安体制”“联盟事权清单”已经写明，重拟时照旧并写得更清楚。

## 三、做法

1. 体例照《组织架构重拟写作规范》与 D92：十四条，条号后接全角空格，不设条标题；附件列处室。旧稿各部分的去向：
   - 一、定位与基本原则：第一条、第二条、第四条导语、第五条。
   - 二、职权与边界：2.1 入第四条；2.2 入第六条；2.3 战略设施之双轨守卫入第六条，要点照旧（《要塞军团组织架构》引用）。
   - 三、首长层：职数入第九条；分管改由部长公布的分工文件规定，写入第十二条。
   - 四、内设机构：第八条，局序照旧；处室入附件。4.3 禁区巡逻总队入第十条。
   - 五、执法权限与强制措施（5.1 至 5.7）：入第十二条，逐项保留规则的实质：权限总则、禁制器械的分级、临时禁魔场的布设、武力使用的分级、高环级对象的递补程序、誓约持证、技术侦缉的令状原则与期限。
   - 六、与城邦治安之关系：入第六条（两层治安体制、联盟事权清单、协作机制、争议处理）。
   - 七、直属机构与事业单位（含 7.2 寂环塔）与八、直属院校：入第十一条。
   - 九、职级与规模：入第九条。
   - 十、机关协作总表与十一、编制总览图：删去；必需的会签与移送写入第六条或者各机构段。
   - 实施附件（警实一至三）：入第十二条，各项规则照旧。
2. 实质不改：现行稿的职权、规则、程序、期限与作者已定的事项照旧；表格中的内容改写成条文，不丢项。
3. 名称：现行稿的内设机构、处室、直属单位、院校与总队名称一个不少，名称不改。下列名称（机构名录引用本文作为出处）必须在修订稿中逐字出现：议会殿卫、办公厅、秘书处、机要处、执政院对接处、公众事务处、总档案室、情报指挥中心、督察审计局、执法督察处、纪律审查处、审计处、外部移送处、人事训练局、法制局、治安管理局、治安政策处、暴乱处置处、大型活动安保处、公共场所治安处、流民与秩序处、刑事侦查局、经济犯罪侦查局、遗产走私犯罪侦查局、邪祀与特类犯罪侦查局、药剂与违禁制剂犯罪侦查局、航路治安局、技术侦缉局、留痕追溯处、侦讯占卜处、符讯侦听处、令状管理处、协查与通缉局、协作受理处、通缉发布处、跨邦追缉处、名录管理处、留痕鉴证局、监所管理局、羁押管理处、服刑管理处、禁制设施处、寂环塔管理处、要员警卫局、警务保障局、禁制器械处、装备标准处、财务装备处、后勤保障处、税关缉私局、域外追缉工作局、禁区巡逻总队、总队部、机动支队、联盟犯罪信息与通缉名录中心、联盟刑事鉴证中心、誓印核验技术中心、留痕技术研究所、禁制器械研究所、恰恩嗅痕兽基地、格雷修斯嗅痕兽基地、嗅痕兽研究所暨技术学校、《联盟治安公报》编印所、联盟治安疗养所、寂环塔、联盟治安学院、联盟刑事侦查学院、航路警察学校、盟约监察院。
4. 充实：现行稿的机构已经较全。参照公安部，只补联盟一层确有需要、现行稿缺少的单位，例如政策研究、通报与公告、术式技术与传讯、装备的采购与储备（不得违反现行正文对采办的规定）、对城邦治安的技术支援、证件与誓印的印制等；直属单位可到十五至二十个；可以按联盟事权所及之处（航路、禁区、口岸）设少量派出机构，不进入城邦的一般治安。每个新增单位须有现行职责可依，名称简洁。

## 四、硬约束

与《组织架构充实起草说明》第四节相同：不新设高等院校与部管专项局，不改《白银执政院组织架构》，新名称不与其他现行正文重名，正文不出现现实机构名、党政军群用语与现代技术词，地名只用现行正文已有的城邦与地点，期限照六、十二、三十六的量级。
