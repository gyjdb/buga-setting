## 第一编 总则

### 第一条 名称与渊源

1. 银色联盟大图书馆，常设于恰恩，是联盟最高知识守护与文明传承机关。
2. 大图书馆之名承袭巴贝尔要塞的白银图书馆。太初之世，布加人的先祖奥奇杜学者是巴贝尔通天塔的守塔人，掌管数万年来诸文明、诸种族以及神民与神的知识传承。通天塔毁灭后，白银图书馆随之湮灭，知识散落于元素疆界与大地。
3. 恰恩的大图书馆是白银之民流落大地后仿建的馆所，承担回收遗失知识的使命。本章程及联盟法律所称"大图书馆"，除另有限定外，指恰恩的联盟大图书馆。

### 第二条 法律地位

1. 大图书馆是银章认可的特许自治体，不列入执政院部委序列，不受执政院日常指挥。
2. 大图书馆的自治范围包括：典籍编目、抄录、校勘、馆藏封存、公开借阅、学术资质认可、馆员遴选与内部管理。
3. 大图书馆对白银议会负责，其年度运营经费列入联盟预算，经议会审议通过后拨付。
4. 执政院对大图书馆不设领导关系，通过常设接口进行会签、协约与拨付。

### 第三条 使命

大图书馆承担下列使命：

1. 收集、保存、整理、校勘沃恩德现存的一切知识与文献，维持文明传承，向联盟公民提供公共知识服务；
2. 作为巴贝尔白银图书馆的继承者，主导或者协助回收散落于大地与元素疆界的遗失知识，包括古代文献残卷、神器铭文、法阵遗构以及其他源于巴贝尔体系的传承碎片。

### 第四条 基本原则

大图书馆的运作遵守下列原则：

1. 大图书馆以知识的保存与传播为宗旨，不服务于政治派系、城邦利益或者个人权力；
2. 知识应当尽可能向联盟公民开放；涉及安全的知识按照本章程分级封存；
3. 任何人不得损毁、窃取、篡改或者隐匿馆藏；违反的，构成盟约重罪；
4. 馆藏的一切入库、出库、借阅、抄录、校勘、封存与解封，应当全程留痕，形成不可篡改的记录链。

## 第二编 治理结构

### 第五条 大图书馆馆长

1. 大图书馆设馆长一人，是大图书馆的最高管理者和对外代表。
2. 馆长由大图书馆馆员大会推举三名候选人，经白银学会学术资质审查后，由白银议会两院联席以简单多数确认任命。
3. 馆长任期为七十二年，可以连任一届。
4. 馆长应当为联盟公民，持有白银学会认定的高级学术资质，并在大图书馆或者白塔从事知识工作不少于一百年。
5. 馆长在任期内不得兼任执政院官员、军职或者城邦城主。

### 第六条 馆务委员会

1. 大图书馆设馆务委员会，是馆长的咨议与决策辅助机关。
2. 馆务委员会由下列成员组成：
   - 馆长（主席）；
   - 各典藏殿堂主管（按第十一条设置）；
   - 回收远征司主管；
   - 守护者代表三人（由馆员大会推选）；
   - 白银学会联络员一人（由白银学会指派，列席不表决）。
3. 馆务委员会就馆藏等级调整、重大入库决定、回收远征计划、年度预算草案等事项进行合议。合议以简单多数形成建议；馆长有最终决定权，偏离合议建议的，应当书面说明理由并存档。

### 第七条 圣殿守护者体系

1. 大图书馆的知识工作者统称圣殿守护者（Custodes Sacri），简称守护者。其职级以"守护者阶"标识，自高至低共七阶：
   - 第一阶·至高守护者（Custos Supremus）：大图书馆暨万书塔的最高守护者，由馆长担任，仅一人；
   - 第二阶·大守护者（Custos Magnus）：应当持有白银学会高级学术资质，由副馆长和总馆务官担任；
   - 第三阶·首席守护者（Custos Primus）：应当持有白银学会高级学术资质并具有卓越学术贡献，担任典藏殿堂主管、回收远征司主管或者圣殿封存署主管；
   - 第四阶·守护者（Custos）：独立主持研究项目或者管理分室的资深学者，应当持有白银学会基础学术资质，施法能力不低于七环；
   - 第五阶·副守护者（Subcustos）：独立承担编目、校勘、鉴定或者借阅管理的专业人员，应当持有白银学会基础学术资质，施法能力不低于五环；
   - 第六阶·学徒守护者（Custos Initiatus）：在守护者指导下工作的初级人员，应当完成誓约登记；
   - 第七阶·见习者（Novitius）：由各城邦学塔或者银翼学院推荐的实习人员，完成见习后可以晋升为学徒守护者。
2. 守护者的遴选由馆务委员会组织。守护者阶的晋升依据白银学会学术资质认定和馆务委员会评审，以学术能力与知识工作经历为主要标准，不以城邦出身或者学派归属为条件。
3. 守护者在任职期间享有学术研习的自由，大图书馆应当为其提供研究条件。

### 第八条 馆员大会

1. 馆员大会由副守护者及以上各阶守护者组成（学徒守护者与见习者列席不表决），是大图书馆的内部民主机构。
2. 馆员大会每三十六年召开一次常规会议，行使下列职权：
   - 推举馆长候选人；
   - 推选馆务委员会的守护者代表；
   - 审议馆务委员会提交的重大事项报告；
   - 就馆政提出建议与质询。

## 第三编 馆藏安全等级与借阅体系

### 第九条 安全等级总则

1. 大图书馆的全部馆藏按照其内容性质与潜在风险，划分为五个安全等级，以数字编码和代号标识。
2. 安全等级的划定应当兼顾知识开放与安全管控。
3. 馆藏的安全等级由馆务委员会按照本章程规定的标准认定。涉及禁术与混沌知识的定级应当会签禁术管制委员会；涉及节点安全的应当会签节点结界工程部。
4. 一切馆藏的等级标识以印记术式直接镌于载体，不可擦除、不可伪造。伪造等级印记的，以盟约重罪论处。

### 第十条 五级分类

#### 第〇级·"晨光"（Aurēa）——公开典藏

1. 不涉及安全敏感内容的一般知识、文献、历史记录、学术著作、工艺手册与教学材料。
2. 向全体联盟公民开放借阅、抄录与引用，并可以经外务部批准向凡世学者有限开放。
3. 晨光典藏的完整编目与目录向公众公开，陈列于大图书馆公共回廊。
4. 等级标识：载体封面左上角镌一枚日轮纹印记，色泽为暖白。

#### 第一级·"薄暮"（Vesperā）——限制典藏

1. 涉及联盟内部治理细节、军事历史、外交记录、城邦敏感事务、特定学术争议或者尚未校勘完成的古代文献。
2. 向持有白银学会基础学术资质以上的联盟公民开放借阅。借阅应当出示资质凭证，全程登记留痕。
3. 薄暮典藏的编目向联盟公民公开查询，全文不公开陈列，应当在专设的学者书斋内阅览。
4. 等级标识：载体封面左上角镌一枚半月纹印记，色泽为冷银。

#### 第二级·"星辉"（Stellāra）——机密典藏

1. 涉及高阶法术原理、节点结构的一般性信息、封印学参考文献、遗产回收的关键技术情报，以及回收自巴贝尔、尚未完成安全评估的知识。
2. 仅向持有白银学会高级学术资质并经馆长书面批准的人员开放查阅。查阅限于馆内专设的星辉密阁，不得外借，不得抄录全文，摘录应当经馆员审核。
3. 星辉典藏的编目仅向馆务委员会成员和经授权的联盟高级官员公开。
4. 星辉典藏中涉及禁术名录内容的，应当同步通报禁术管制委员会。
5. 等级标识：载体封面左上角镌一枚三星连纹印记，色泽为深蓝。

#### 第三级·"深渊"（Abyssāra）——禁入典藏

1. 涉及禁术核心原理、混沌知识的详细记载、节点脆弱点的精确数据，以及足以对联盟安全构成直接威胁的危险知识。
2. 查阅应当同时满足下列全部条件：
   - 馆长书面批准；
   - 禁术管制委员会或者银色学派的专项查阅许可；
   - 查阅全程由首席守护者陪同，在专设的深渊封库内进行；
   - 查阅过程以留痕术式实时记录，记录存入馆长密卷。
3. 深渊典藏的编目仅向馆长和馆务委员会公开。
4. 经安全评估认为已不具有直接危险性的深渊典藏，可以由馆务委员会提请降级为星辉级。降级应当经禁术管制委员会会签。
5. 等级标识：载体封面左上角镌一枚无底深渊纹印记，色泽为玄黑。

#### 第四级·"虚无"（Nihilāra）——湮灭典藏

1. 存在本身即构成重大安全风险的知识，包括可以直接引发混沌侵蚀的咒文、可以动摇Tiamat法则根基的禁忌理论，以及银色学派以终局权限指定封缄的特殊文献。
2. 虚无典藏不录入任何公开或者内部编目系统。其存在仅由馆长和银色学派知悉。馆务委员会中仅馆长一人掌握虚无典藏的确切内容与存放位置。
3. 查阅虚无典藏应当经银色学派以不少于七环同意的终局许可，并由馆长亲自陪同。
4. 虚无典藏的实体存放于大图书馆最深层的虚无之匣，即以多重封印术式隔绝、不与任何常规库房相连的独立空间。虚无之匣的位置与入口不得以任何形式记录或者传播，仅由历任馆长口传。
5. 等级标识：无任何可见标识。载体表面施以视觉湮灭术式，在常规感知下呈现为空白。

### 第十一条 馆藏典藏殿堂

大图书馆按照知识领域设七大典藏殿堂，分居万书塔各层（非穷尽列举，馆务委员会可以按照需要增设或者调整）：

1. 永世回廊（Atrium Aeternum）：沃恩德历史、各族编年、战争记录、条约文献与重大事件卷宗，按时间轴排列，白银之墙位于其核心；
2. 万法殿（Sanctum Arcanorum）：法则魔法、元素魔法、符文魔法、占星术、通灵术、法阵魔术等九大术式学派的学术文献；
3. 造物之庭（Hortus Fabricae）：工匠法则、炼金术、圣纹刻印技术、舰装设计、引擎工艺、材料谱系等实用知识；
4. 万象志馆（Bibliotheca Naturalis）：魔物图鉴、元素生态、云海资源、药草与制剂、矿藏分布等自然知识，附设实物标本陈列；
5. 通言塔阁（Turris Linguarum）：古代语系、符文语族、创世圣诗原文、契约文书范式、翻译与校勘学；
6. 尘世镜鉴室（Speculum Mundi）：四大帝国的历史、凡世诸国的地理人文、圣殿教义、外交通信与最低接触事务的参考文献；
7. 巴贝尔遗殿（Reliquarium Babel）：保存回收自巴贝尔白银图书馆的遗失知识。馆藏大部分初始列为星辉级或者深渊级，经安全评估后逐步降级；殿内设独立的入库鉴定区与临时封存区，是大图书馆安全等级最高的区域。

### 第十二条 等级调整

1. 馆藏的安全等级可以随研究深入、安全评估完成或者外部环境变化，按照程序升级或者降级。
2. 降级由典藏殿堂主管提请，馆务委员会合议通过。深渊级降为星辉级的，应当经禁术管制委员会会签。涉及虚无级的调整应当经银色学派终局许可。
3. 馆务委员会可以依职权或者按照禁术管制委员会的建议，将馆藏升级。升级决定应当书面说明理由并存档。紧急情况下，馆长可以先行升级、事后补办合议程序。
4. 一切等级调整应当更新载体上的等级印记，并在馆藏管理系统中留痕。

## 第四编 遗产回收的制度接口

### 第十三条 回收远征司

1. 大图书馆内设回收远征司，负责组织、协调与支援回收巴贝尔遗失知识的远征行动。
2. 回收远征司的职责包括：
   - 汇总与评估遗失知识的线索情报（来源包括银烛会、凡世代理人、白银学会与联盟公民的举报）；
   - 拟定回收远征计划，经馆务委员会审议后报议会批准；
   - 组织远征队的编组，远征队通常由馆员、灰袍巫师护卫与鉴定专家组成；
   - 远征回收物的现场初步鉴定与安全封装；
   - 回收物的押运链条管理，从发掘地到大图书馆全程留痕。
3. 远征队的军事护卫由银色舰队按照回收远征司的请求调派。护卫力量的指挥权在军事层面按照联盟军事委员会与军种指挥体系的规定确定，在任务层面听从远征队长的指引。

### 第十四条 回收物的入库流程

回收自大地或者元素疆界的知识与遗产，入库前应当经过下列程序：

1. 现场封装：远征队在发掘现场对回收物进行初步安全评估与魔力封装，防止运输途中泄漏或者侵蚀。封装过程全程留痕。
2. 押运：回收物由远征队押运返回恰恩。押运路线应当事先报备银烛会与国用工务总局，重大遗产的押运应当有舰队护航。
3. 入库鉴定：回收物运抵大图书馆后，由馆务委员会指定的鉴定小组进行全面鉴定，包括：
   - 知识内容的初步解读与分类；
   - 安全评估，即是否涉及禁术、混沌知识、节点相关信息或者其他危险内容；
   - 真伪与完整性鉴定，即是否为巴贝尔原初传承，或者属于后世伪作、被篡改的文本。
4. 定级定档：鉴定完成后，馆务委员会按照第十条的标准确定馆藏安全等级；涉及禁术的，应当会签禁术管制委员会。
5. 分流：定级为深渊级或者虚无级，且经评估不宜由大图书馆保管的（例如极端危险的混沌知识或者封印学核心文献），移交白塔封存。移交全程留痕，由大图书馆与白塔双方签署移交清册。
6. 登记入库：完成定级与分流后，馆藏正式入库，编入大图书馆的总目录体系（虚无级除外）。

### 第十五条 凡世代理人体系

1. 大图书馆可以在凡世各国设立不公开的知识代理人，负责收集遗失知识的线索、采购凡世珍稀文献，以及在不暴露联盟身份的前提下进行初步调查。
2. 知识代理人的遴选与管理由回收远征司负责。代理人名册为深渊级信息，仅向馆长、回收远征司主管与银烛会总监公开。
3. 知识代理人的活动应当遵守银章第四条最低接触原则，不得介入凡世政治，不得利用联盟身份谋取凡世权力。
4. 知识代理人获取的线索与文献，应当通过安全渠道回传回收远征司，不得自行处置或者出售。

## 第五编 与白塔的关系

### 第十六条 分立原则

1. 大图书馆与白塔是联盟两大知识机关，分立并存，互不统属。
2. 白塔负责法则守护与高阶知识封存，并以其内嵌的寰宇文库积藏历代典籍；大图书馆负责知识传承与文明延续，以主动经营与系统远征收纳知识，向白银之民开放。
3. 寰宇文库与大图书馆是联盟并立的两大知识渊薮，互不统属、互不隶属。寰宇文库不设独立法人地位，其管理隶属白塔，由守护法师统辖（《白塔章程》第十七条）。本章程涉及寰宇文库的一切接口，以白塔为对接机关。
4. 两机关的首长（大图书馆馆长与白塔守护法师）互不兼任，互不指挥。

### 第十七条 移交与分流

1. 大图书馆在入库鉴定中认定某项馆藏属于白塔封存范围的（极端危险的禁术核心原理、封印学最高机密、混沌知识的原始样本等），应当移交白塔。
2. 白塔在其封存体系中发现某项知识经评估已不具有危险性且具有学术价值的，可以移交大图书馆降级纳入公开或者限制馆藏。
3. 馆藏来源分工：经联盟系统性回收远征、外交渠道或者购藏取得的知识与文物，归大图书馆；由白塔位面自身积淀、朝圣者奉献产生的典籍，归寰宇文库（《白塔章程》第二十一条）。两馆藏品性质交叉重合的，以先入库者为准，不强行调拨、不重复收藏。
4. 回收远征司发现疑似应属寰宇文库范围的典籍（如失落已久的法则领悟手稿）的，可以移交白塔；白塔发现疑似应属大图书馆范围的公共知识的，也可以移交大图书馆。
5. 一切移交应当由双方签署移交清册，全程留痕，并报盟约监察院备案。

### 第十八条 联合研究

1. 同时需要大图书馆的文献资源与白塔（含寰宇文库）的典藏或者封存知识的重大研究课题，两机关可以组建联合研究组；两馆并可以就珍稀典籍互通有无，互通应当遵守各自的安全规程与借阅等级。
2. 联合研究组的人员由双方馆务机构各自指派。研究过程中接触的深渊级及以上典藏与白塔封存知识，应当遵守各自的安全规程，不得因联合研究降低任何一方的安全标准。
3. 联合研究的成果归属由双方协议确定；涉及禁术的，报禁术管制委员会备案。

## 第六编 与其他机关的关系

### 第十九条 与白银学会的关系

1. 白银学会是联盟最高学术共同体，大图书馆是联盟最高知识保管机关，两者互为补充。
2. 白银学会的学术认定结论是大图书馆馆员资质审查的依据。
3. 大图书馆的馆藏是白银学会学术研究的重要资源，学会院士享有薄暮级及以下馆藏的优先借阅权。
4. 白银学会可以就馆藏安全等级的学术合理性向馆务委员会提出咨询意见。

### 第二十条 与教育典籍部的关系

1. 执政院教育典籍部主管教育行政与典籍流通监管，大图书馆主管馆藏自治。
2. 教育典籍部不得干预大图书馆的编目、校勘与定级决定。
3. 大图书馆向联盟公共教育体系提供教材支撑与典籍资源，具体协作方式由双方签订年度协议。

### 第二十一条 与禁术管制委员会的关系

1. 馆藏定级涉及禁术名录内容的，应当会签禁术管制委员会。
2. 禁术管制委员会可以要求大图书馆将特定馆藏升级为深渊级或者移交白塔，但应当书面说明理由。大图书馆有异议的，可以提请银色学派裁断。
3. 禁术管制委员会对大图书馆的深渊封库与星辉密阁享有定期安全巡查权，巡查不得干扰正常馆务。虚无之匣不在常规巡查范围。

### 第二十二条 与银烛会的关系

1. 银烛会的混沌态势通报与节点异常预警是回收远征司评估线索的重要来源。
2. 回收远征计划涉及联盟空域以外行动的，应当事先通报银烛会评估安全风险。
3. 银烛会发现凡世出现疑似遗失知识线索的，可以直接通报回收远征司。

### 第二十三条 与盟约监察院的关系

1. 盟约监察院对大图书馆的财务、遗产入库流程与馆藏安全管理享有独立监察权。
2. 盟约监察院的监察限于流程合规与财务审计，不得延伸至馆藏的学术内容与定级判断。
3. 涉及馆员渎职、馆藏失窃或者遗产走私的案件，由盟约监察院调查后移送裁断体系处理。

---

## 第七编 白银之墙

### 第二十四条 白银之墙

1. 大图书馆设白银之墙，即镌刻于恰恩大图书馆中枢大厅的巨型银质壁面，按编年顺序铭记白银之民的历史。
2. 自奥奇杜学者守护巴贝尔时期起的重大事件，均铭刻于墙。
3. 白银之墙的铭文由永世回廊主管负责编纂，新铭文的刻入应当经馆务委员会合议通过。
4. 白银之墙向全体联盟公民开放参观，不收取费用。

## 第八编 附则

### 第二十五条 馆藏不可侵犯

1. 大图书馆的馆藏是联盟文明的共同财产，不得出售、抵押或者赠予联盟以外的任何势力。
2. 窃取、损毁、篡改或者系统隐匿馆藏的，构成盟约重罪，移送裁断体系依法追究。
3. 紧急状态下，大图书馆可以启动馆藏疏散预案，将核心馆藏转移至预定的安全地点。疏散预案由馆务委员会拟定，报议会备案。

### 第二十六条 判例汇编的纳入

按照《裁断体系组织法》第四十四条，白银高等裁断庭的判例汇编纳入大图书馆公共借阅体系，列为晨光级典藏。

### 第二十七条 过渡条款

1. 本章程生效后，大图书馆现有馆藏应当在五年内按照第十条的标准完成全面安全等级评定。
2. 回收远征司应当在本章程生效后一百八十日内完成组建。
3. 凡世知识代理人的现有网络应当在一年内完成向回收远征司的正式移交与备案。
4. 虚无之匣应当在本章程生效后一年内完成建造与封印。在此之前，符合虚无级标准的馆藏暂按深渊级规程管理。

### 第二十八条 本章程的修订

1. 本章程的修订应当经两院各以三分之二多数通过。
2. 涉及大图书馆的特许自治地位、馆藏不可侵犯原则、馆长产生方式与虚无级设定的，应当另经银色学派以不少于七环确认。

### 第二十九条 生效

本章程经两院通过并由元老会签署后生效。
