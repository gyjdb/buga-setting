# 白银学会章程（草案 v1.0）

> **拟定依据：《银色联盟宪章》第三条、第五条、第二十六条；《白银执政院机构设置》特许单列第4条**  
> **性质：议会法，规定白银学会之法律地位、使命、院士制度与学术承认、学术资质体系、术式标准与度量原器之认定权限、内设学部、以及与执政院各部、白塔、大图书馆等机关之制度接口。**

---

## 第一编 总则

### 第一条 白银学会之名与渊源

1. 白银学会（Academia Argentea），为银色联盟最高奥术与工艺学术共同体，常设于卡奈奇。
2. 布加人以"工匠巫师"为族之本色——工匠法则、术式工业、舰装设计、炼金冶炼、材料谱系，皆为白银之民安身立命之根基。白银学会之存在，正是为了确保这一切知识与工艺的最高学术权威不依附于任何行政权力，而以学术共同体之自治来守护学术之纯粹。
3. 白银学会与大图书馆之造物之庭以空中廊桥相连，象征学术创造与知识保管之一体两面。

### 第二条 白银学会之法律地位

1. 白银学会为银章所认之**特许自治体**，不入执政院部委序列，不受执政院日常指挥。
2. 白银学会之自治范畴包括：基础奥术理论研究方向之确立、工匠法则之学术评议、术式标准与度量原器之学术认定、学术资质与荣衔之授予、院士之承认。
3. 白银学会对白银议会负责，其年度运营经费列入联盟预算，经议会审议通过后拨付。
4. 执政院对白银学会不设领导关系。白银学会之学术认定结论对执政院各部具有参考效力，经议会法确认者具有约束力。

### 第三条 白银学会之三重使命

白银学会肩负三重使命：

1. **学术之犁**——推动基础奥术理论与工匠法则之前沿研究，为白银之民的知识边疆持续拓荒。白银学会不守护知识（此为白塔与大图书馆之职），而创造知识。
2. **标准之锚**——作为联盟术式工业标准、材料谱系、计量体系与度量原器之最终学术权威，确保联盟之工艺体系建立在可靠之学术基础之上。
3. **资质之门**——建立并维护联盟学术资质认定体系，为联盟各机关之人员准入、晋升与专业评审提供权威之资质凭证。

### 第四条 基本原则

1. **学术独立**：白银学会之学术判断不受行政权力、城邦利益或派系意志之干预。
2. **学术承认制**：白银学会院士经由学术共同体之承认产生，不由行政任命——此制与银色学派之"古例承认"在精神上一脉相承。
3. **工匠本色**：白银学会同等尊重纯理论研究与实用工艺创新——布加人从不将"学者"与"工匠"对立。一名能将法则理论化为舰装设计之巫师，与一名纯粹推演法则之学者，在学会中享有同等尊崇。
4. **开放评议**：学术争议以公开辩论与同行评议解决，不以权势压人、不以环级定论。

## 第二编 院士制度

### 第五条 院士之地位

1. 白银学会院士为联盟最高学术荣衔，代表其持有者在特定学术领域之卓越成就与同行公认之学术权威。
2. 院士荣衔为终身制——一经承认，非因严重学术不端经学术纪律程序撤销者，不得剥夺。
3. 院士在联盟中享有以下特别权利：
   - 大图书馆薄暮级及以下馆藏之优先借阅权；
   - 受裁断体系传召时作为专家证人之资格；
   - 在白银议会公议院学术席之被推举资格；
   - 出席学会全体大会并享有表决权。

### 第六条 院士之承认

1. 院士之产生采取**学术承认制**——由现有院士提名与合议承认，不经行政审批。
2. 承认程序：
   - **提名**——由不少于三名现任院士联合提名候选人，提交提名书，载明候选人之学术贡献、代表性成果与同行评价。
   - **评审**——由候选人所属学部之学术评审组（不少于七名院士）进行书面评审与答辩考核。评审组出具评审报告与建议。
   - **合议**——候选人所属学部全体院士以记名投票方式合议。获三分之二多数赞成者，提交学会全体大会确认。
   - **确认**——学会全体大会以简单多数确认后，由会长宣布承认，颁授院士铭牌。
3. 院士之承认不以城邦出身、学派归属、性别或种族为条件——联盟公民中非布加血统之巫师，只要其学术贡献经学会公认，同样可被承认为院士。

### 第七条 院士之类别

白银学会院士分为两类：

| 类别 | 名称 | 说明 |
|------|------|------|
| **正式院士** | 银冠院士（Academicus Coronatus） | 在特定学术领域有原创性重大贡献者。正式院士享有全部院士权利与表决权 |
| **荣誉院士** | 银桂院士（Academicus Laureatus） | 授予非联盟公民之杰出学者（如凡世之卓越学者、银精灵之符文大师等），以表彰其对沃恩德知识之贡献。荣誉院士享有借阅优先权与学术交流权，但不享有表决权 |

### 第八条 院士之规模

1. 正式院士之总人数不设硬性上限，但各学部每三十六年之新增承认名额由学术委员会拟定、全体大会通过，以确保院士荣衔之含金量。
2. 以联盟目前之学术人口规模，全会正式院士总数约为**八十至一百二十人**。

## 第三编 治理结构

### 第九条 会长

1. 白银学会设会长一人，为学会之最高代表与学术事务之首席主持人。
2. 会长由全体正式院士以记名投票选举产生，获简单多数当选。
3. 会长任期为三十六年，可连任一届。
4. 会长须为现任正式院士，施法能力不低于九环。
5. 会长在任期内不得兼任执政院官员、军职或城邦城主。
6. 会长之礼遇比照联盟最高级公务职级之惯例。

### 第十条 副会长

1. 白银学会设副会长二人，分别主管学术事务与标准事务。
2. 副会长由会长提名，全体正式院士以简单多数确认。
3. 副会长任期与会长同步。

### 第十一条 学术委员会

1. 白银学会设学术委员会，为学会之日常学术决策机关。
2. 学术委员会由以下成员组成：
   - 会长（主席）；
   - 副会长二人；
   - 各学部部长（依第四编设置）；
   - 院士代表若干（由各学部院士推选，合计不超过学部数之二倍）。
3. 学术委员会职权：
   - 研究方向之宏观指引与资源配置；
   - 学术资质标准之审定与修订；
   - 术式标准与度量原器之学术认定之最终审议；
   - 新增院士名额之拟定；
   - 学术纪律案件之审查。

### 第十二条 全体大会

1. 全体大会由全体正式院士组成，为白银学会之最高权力机构。
2. 全体大会每三十六年召开一次常规会议，行使下列权力：
   - 选举会长；
   - 确认新承认之院士；
   - 审议学术委员会提交之重大事项报告；
   - 审议修订学会内部章则；
   - 院士规模与名额之批准。
3. 会长得在必要时召集临时全体大会。

## 第四编 学部设置

### 第十三条 学部体系

白银学会依学术领域设下列学部，各学部为学术组织单元而非行政机构：

| 学部 | 学部名 | 涵盖领域 |
|------|--------|---------|
| 第一学部 | **法则与真理学部** | 法则魔法理论、Tiamat法则研究、真理学、高阶术式理论 |
| 第二学部 | **元素与术式学部** | 元素魔法、符文魔法、占星术、通灵术、法阵魔术之理论与应用 |
| 第三学部 | **工匠法则与造物学部** | 工匠法则、炼金术、圣纹刻印、附魔工艺、材料谱系、冶金与精密器械 |
| 第四学部 | **舰装与引擎学部** | 浮空舰装设计、引擎工艺、城体结构学、航行动力学 |
| 第五学部 | **封印与位面学部** | 封印学理论、位面学、空间法则、位面工程。与白塔学会之学术互认领域 |
| 第六学部 | **博物与生命学部** | 魔物学、元素生态、云海资源学、药草与制剂学、矿藏地质学 |
| 第七学部 | **度量与标准学部** | 计量学、度量原器、术式工业标准、材料认证、质量检验方法 |

### 第十四条 学部之治理

1. 各学部设部长一人，由本学部全体院士互选产生，任期十八年，可连任。
2. 各学部自行组织学术评审、课题立项与成果评议。
3. 各学部之部长为学术委员会之当然成员。

## 第五编 学术资质认定体系

### 第十五条 资质体系总则

1. 白银学会为联盟学术资质之法定认定机关。联盟各机关凡以"白银学会认定之学术资质"为任职或晋升条件者，均以本章程所定之资质体系为准。
2. 学术资质认定以学术能力为唯一标准，不以城邦出身、学派归属或行政关系为条件。

### 第十六条 资质等级

白银学会之学术资质分为**三级**：

| 等级 | 名称 | 认定标准 | 主要适用场景 |
|------|------|---------|------------|
| **基础学术资质** | 银卷凭证（Diploma Argenteum） | 在特定学术领域完成系统学习与实践，通过学会之基础考核。施法能力不低于五环 | 大图书馆副守护者、公议院学术席之基本门槛、大图书馆薄暮级借阅 |
| **高级学术资质** | 银章凭证（Insignia Argentea） | 在特定学术领域有独立之学术成果，通过学会之高级考核。施法能力不低于七环 | 大图书馆守护者、馆长候选人、白塔持杖巫师候选条件之一、星辉级查阅 |
| **卓越学术资质** | 银冠凭证（Corona Argentea） | 在特定学术领域有原创性重大贡献，经学部评审与学术委员会审定 | 高等裁断庭裁断官之替代条件、院士提名之前置条件 |

### 第十七条 专项资质

除上述三级通用资质外，白银学会另认定以下专项资质（部分亦可由白塔认定）：

| 专项资质 | 认定内容 | 主要适用场景 |
|---------|---------|------------|
| 封印学资质 | 封印术式之理论与实践能力 | 禁术与遗产重罪裁断庭裁断官之必备资质之一 |
| 留痕鉴识资质 | 施法留痕之采集、鉴别与真伪判定能力 | 同上；禁术管制委员会留痕稽查司人员之任职条件 |
| 遗产分级鉴定资质 | 巴贝尔遗产之年代、来源与安全等级之鉴定能力 | 同上；大图书馆入库鉴定组之任职条件 |
| 混沌学专项资质 | 混沌力量之识别、评估与管控能力 | 禁术管制委员会相关机构之任职条件 |
| 奥术鉴定资质 | 法术属性、威力等级与构成之综合鉴定能力 | 禁术管制委员会术式鉴定室人员之任职条件 |

### 第十八条 资质考核之组织

1. 基础学术资质之考核由各学部自行组织，每年至少举办一次。
2. 高级学术资质之考核由学术委员会统筹、各学部执行，每三年举办一次。
3. 卓越学术资质之认定由学部评审与学术委员会审定，不设定期。
4. 专项资质之考核由对口学部（或白塔学会）组织，视需求举办。
5. 一切资质考核之标准、程序与结果须公开透明，考核卷宗留档。

## 第六编 术式标准与度量原器

### 第十九条 标准认定权

1. 联盟术式工业标准、材料谱系认证标准、计量体系与度量原器之**学术认定**，由白银学会作为最终学术权威。
2. 学术认定由第七学部（度量与标准学部）主导研拟，经学术委员会审定后发布。
3. 学术认定结论发布后，其行政推行与执法由执政院工艺与奥术科技部负责，计量原器与标准样本之行政检定由该部所辖标准谱系局（挂联盟标准化委员会牌子）执行。白银学会认定标准，行政机关推行与执法，二者分立——白银学会不直接执法。

### 第二十条 度量原器

1. 联盟度量原器之学术认定与校准由白银学会主导。
2. 度量原器之物理保管由执政院工艺与奥术科技部所辖标准谱系局负责，白银学会享有随时调取校准之权利。
3. 度量原器之更新与替换须经学术委员会审定。

### 第二十一条 舰装标准

1. 联盟浮空战舰之设计规格、建造标准与材料谱系之学术基础，由白银学会第四学部（舰装与引擎学部）提供技术认定。
2. 舰装标准由执政院工艺与奥术科技部依白银学会之技术认定拟定，其部件谱系检定由该部所辖舰装谱系检定局实施；涉军用需求者，由联盟军事委员会提出，检定局负责技术检定。白银学会不介入舰队编制、列装优先级与作战用途之决定。

## 第七编 内设行政机构

### 第二十二条 学会秘书处

白银学会设秘书处，为学会之行政枢纽，由会长指定一名资深学者任秘书长主管。

| 下设单位 | 职能 |
|---------|------|
| 会务科 | 学术委员会与全体大会之会务、院士联络、日程安排 |
| 议会与外部事务科 | 年度报告呈送议会、与执政院各部之对口联络、预算报批 |
| 资质管理科 | 学术资质凭证之制发、注册、年检与档案管理——联盟学术资质之"证照中枢" |
| 标准发布科 | 术式标准与度量原器认定结论之编纂、发布与存档 |
| 经费与总务科 | 学会经费编制与执行、课题经费管理、设施维护 |
| 学术出版室 | 学会学术期刊与研究报告之编辑出版、成果公示 |

### 第二十三条 学术纪律委员会

1. 白银学会设学术纪律委员会，负责学术不端行为之调查与处理。
2. 学术纪律委员会由学术委员会指定之五名院士组成，任期十八年。
3. 学术不端行为包括但不限于：数据伪造、成果剽窃、资质考核舞弊、利用学术权威谋取不正当利益。
4. 学术纪律委员会之处分权限：警告、撤销特定学术成果之认定、暂停资质、撤销院士荣衔（须经全体大会三分之二多数确认）。
5. 涉嫌盟约违法者，移送盟约监察院或裁断体系。

## 第八编 与其他机关之关系

### 第二十四条 与执政院各部之关系

| 对口机关 | 接口事项 | 分工原则 |
|---------|---------|---------|
| 工艺与奥术科技部 | 工坊标准与术式工业标准之执行 | 学会认定标准，工艺与奥术科技部行政推行与执法 |
| 工艺与奥术科技部·标准谱系局 | 度量原器、计量体系、标准样本 | 学会学术认定与校准，标准谱系局行政检定与保管 |
| 工艺与奥术科技部·舰装谱系检定局 | 舰装标准与部件谱系 | 学会提供技术认定，检定局实施谱系检定 |
| 教育典籍部 | 术式教育体系、学术资质 | 学会认定资质标准与荣衔，教育典籍部管教育行政与公共拨款 |

### 第二十五条 与白塔之关系

1. 白银学会为联盟最高通用学术共同体（"知识之犁"），白塔学会为专精封印学与法则理论之特殊学术共同体（"知识之盾"之学术臂膀）。
2. 两学会之学术互认：白银学会第五学部（封印与位面学部）与白塔学会在封印学、法则理论与位面学领域互认学术成果与资质。
3. 白银学会院士得依程序兼任白塔学会成员，反之亦然。
4. 白塔守护法师之遴选，白银学会就候选人之学术资质与法则领悟造诣出具审查意见（《白塔章程》第十一条）。

### 第二十六条 与大图书馆之关系

1. 白银学会之学术认定结论为大图书馆守护者资质审查之依据。
2. 大图书馆之馆藏为白银学会学术研究之重要资源，院士享有薄暮级及以下馆藏之优先借阅权。
3. 白银学会得就馆藏安全等级之学术合理性向大图书馆馆务委员会提出咨询意见。
4. 白银学会与大图书馆之造物之庭以空中廊桥相连——此为两机关日常学术交流之物理通道。

### 第二十七条 与禁术管制委员会之关系

1. 禁术管制委员会之术式鉴定室人员须持有白银学会认定之奥术鉴定资质。
2. 禁术管制委员会之留痕稽查司留痕标准须会签白银学会。
3. 白银学会得就禁术名录之学术合理性向禁术管制委员会提出咨询意见。

### 第二十八条 与裁断体系之关系

1. 白银学会院士得受裁断庭传召作为专家证人。
2. 高等裁断庭裁断官之资格，得以白银学会卓越学术资质为替代条件之一；禁术与遗产重罪裁断庭裁断官所需之封印学资质、留痕鉴识资质、遗产分级鉴定资质，由白银学会（或白塔）认定（《裁断体系组织法》相关条款）。

### 第二十九条 与银色学派之关系

1. 银色学派为联盟终局监护机关，其地位超然于一切公务与学术序列之上，不纳入白银学会之院士体系与资质序列。
2. 白银学会之"学术承认制"与银色学派之"古例承认"在精神上一脉相承——皆以同行或世间之公认，而非行政任命，确立其地位。
3. 银色学派不干预白银学会之学术判断、院士承认与资质认定。

### 第三十条 与元素使公会之关系

1. 法师之环级认定，由白银学会与元素使公会共同主持：白银学会主理学术资质，元素使公会主理实战环级（《法术环级标准》第十一条、《环级认定规程》）。
2. 二者就环级认定之标准、程序与试炼监试建立常设协作。

### 第三十三条 本章程之修订

1. 本章程之修订须经两院各以三分之二多数通过。
2. 涉及白银学会之特许自治地位、院士承认制与标准认定权者，须听取全体大会之学术意见。

### 第三十四条 生效

本章程经两院通过并由元老会签署后生效。自生效之日起，与本章程抵触之一切旧制，依上法优先原则处理。
