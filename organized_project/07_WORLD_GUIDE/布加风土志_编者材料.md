# 《布加风土志》编者材料

> 与[《布加风土志》](布加风土志.md)正文配套。本文件不属于正文，供作者审阅、核对与网站编辑使用。六节整合版保留在 [02_PROPOSALS](../02_PROPOSALS/银色联盟设定导读_草稿.md) 供核对。

## 一、定位与写法

- 读者：初次接触布加的地上读者。
- 作者：暂拟为一位长期研究布加的地上学者。姓名、族属与经历均未确定；正文不用第一人称，也不写任何见闻。作者的声音只体现在：选择讲什么、怎样解释、在哪里停下，以及少量有依据的概括与判断。
- 结构：天上的国度 → 白塔与大图书馆 → 巫师的成长 → 魔法与它的界限 → 城邦之间 → 议会与十二环 → 来历 → 天空的边界 → 岁时。先让读者看见布加，再解释它的人、制度与来历。
- 第一章沿用已确认的开篇四段，未作改动。

## 三、作者的概括与判断

以下句子是作者依据已有事实所作的概括或组织，并非新设定。

- “构成这个国家的，始终是天上的城”：依据是正式成员全为浮空城。
- “坠落是一种需要预先防范、事后追查的事故”：依据是联盟为城体设有检验机构，并设有坠落事故复盘机构。
- “天空在这里也有它的地形”：依据是“天空测绘与航标研究院”负责天空地形与航标。
- “衣食既然不成问题，一个布加人真正缺少的……”：概括自作者关于富足与个人缺知识、能力的回答。
- “如果说白塔是封存与领悟之所，大图书馆就是保存与传播之所”：依据两部章程各自的职能（白塔：法则守护、封存、领悟；大图书馆：保存、校勘、公开借阅、回收）。
- “蓄意破坏白塔门户……同属最严重的罪行”：依据白塔章程第二条，破坏门户等同宪章第六条的红线事件。
- “在布加，训练比出身更重要”：概括自“血统关系不大、年龄也还好、训练挺重要”。
- “与地上人类的巫师学徒相比，布加学徒的修行之路要顺畅得多”：依据作者基础设定 2.1。
- “空间法术最能说明十环前后的差别”：组织性判断，所用事实均出自基础设定第七节。
- “最低限度的接触，并不等于不闻不问”：承接句，后文所写均为银烛会的现行职责。
- “许多城邦的城主，同时就是银色十二环的成员”：依据十二环中有十一位兼任城主。
- “一个巫师能施展到哪一环，大体标示着其能力”：依据作者基础设定 2.4（综合评判以最高等级为准）及环级凭证记载“已证最高等级”。

## 四、只写到已确认范围的地方

- 环级认定只写一至十四环的非弦术式；弦魔法与第十五环不在认定之列。十四环不设执照，须经银色十二环许可（环级认定规程第四条之一、第五条、附件二；魔法基本法第八条）。
- 第九章不说“布加人的一年围绕议会展开”，只写议会的两个常规会期；会期所审议的事项写作“以……为主”。月份写作“布加与地上一样，以十二个月记一年”，依据是现行法规以这套月名定会期，且作者所述各月风俗兼及地上。
- 萨萨尔德双城的正式名称未定，正文只写“双城联盟”“萨萨尔德双城”。
- 班西亚只写“一部分人可以成为联盟公民”，不写哪些人，也不写席位安排。
- 公民只写“以白银之民为主，也有混血者与妖精”，不写入籍条件。
- 尤基、洛加尔、罗安、阿佳妮、阿卡斯所在城邦的名称与位置未定，正文只写“十一位都兼任城主”，列出已知的城邦对应。
- 太阳黑子、大银杖是否为环席圣物，均未对应。
- 奈奥奇堡只写位置，不写等级与监视对象。
- 书卷之月考校只写“白色大理石广场”，不写地名。
- 复苏祭写作“大多数圣殿的历法”中的祭典，不写布加是否庆祝。
- 圣物继承争议的处理、环之仪式的细节、特殊用途与高危活动的类别，正文均不涉及。

## 附录：推荐阅读顺序（网站编者用）

银色联盟的设定，大部分写在十七份法律与章程里。它们是联盟自己的法典，用联盟的语言写成：宪章常被称为“银章”，条文之间彼此援引，一项制度往往要在几份文献之间对照着读。第一次读，不必从头到尾依次通读，可以先读五份入门文献，搭起整个国家的轮廓，再按兴趣进入各个领域。
