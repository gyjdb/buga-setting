```text
# 白银议会组织法（草案 v3.5）

> **拟定依据：《银色联盟宪章》第十七条至第二十一条**  
> **性质：议会组织法，规定白银议会之两院构成、席位分配、元老会形成、议事规则、立法程序、质询与问责、以及议会与终局机关之制度界面。**  
> **v3.1 → v3.2 修订说明：第三十二条第三款将年中通报会所系之月份由"丰收之月"更正为"流火之月"——丰收之月（九月）落于书卷会期之内，并非两个常规会期之间；流火之月（七月）方为第三十一条所定之盛夏休会，与"年中""上半年施政"之表述相合。**  
> **v3.2 → v3.3 修订说明：增订第二十六条之一"执政首席之选任与任期"，以落实《银色联盟宪章》第二十三条"执政首席之任期与连任限制由议会法规定"之授权——原议会法未就此设条，属授权落空。新条定执政首席由两院联席简单多数选任、任期三十六年、可连选连任而不设次数限制，并明定出缺补选程序。本条以"之一"增订体例置于第七编之首，不变动其后各条条号与交叉引用。**  
> **v3.3 → v3.4 修订说明：对接最高军事指挥体制。第四编“军务席”原依旧体制设计——代表仅由银色舰队产生、提名权属舰队统帅部。今联盟常备军已为三军种（银色舰队、银色战团、要塞军团）并立于联盟军事委员会之下，故第一款代表来源由“银色舰队”扩为“联盟常备军各军种”，第二款提名机关由“舰队统帅部”更正为“联盟军事委员会”，第三款任职回避由“舰队指挥职务”扩为“军事指挥职务”。军务席之席位上限与其余各席设置未作改动。**
> **v3.4 → v3.5 修订说明：军务席第三款由"不得同时担任军事指挥职务"改为保留军职、表决回避——军务席议员得保留其军事指挥职务，但涉及联盟军事委员会或本军种切身事项之表决应予回避。此为全法唯一之兼职限制条款；改采回避机制后，各机关首长兼任议员不再另设立法侧禁令（见裁断体系组织法、防务基本法、大图书馆章程、白塔章程之同步修订）。**

---


```

```text
### 第四十条 议会中之主要政治倾向

本条不构成法定分类，仅为理解议会政治生态之参考附注：

1. **守约派**：主张严格遵守最低接触原则，联盟不应介入凡世纷争，首要任务为知识回收与内部秩序维护。在城邦院中势力最强。
2. **弗洛斯派**：主张布加人有责任以知识与力量影响世界进程，抵御混沌之蔓延不应止步于联盟边境。在公议院之元素使公会与战斗序列代表中有较强影响力。
3. **实利派**：不持强烈立场，关注具体利益分配——贸易通道、军工订单、资源配额、船坞工期。多为中小城邦与工匠行会之代表，为两院中关键之中间力量。

---
```

候选新规则：

```text
### 第四十条 议会中之主要政治倾向

本条为非规范参考，不设法定党派身份。各倾向共同承认联盟知识回收、秩序存续与共同体保障的使命，分歧在于实现路径。沿历史授权采用现代简名：保守派（旧称守约派）侧重内部维护与最低接触；弗洛斯派侧重知识责任与抵御混沌的外部作用；实业派（旧称实利派）侧重生产、通商与共同工程的制度安排。旧名称保留为历史检索别名，不据此新增党派特权或变更最低接触原则。
```

```text
1. 两院分别计算出席、回避及门槛，不将联席人事表决规则移作立法。一般“简单多数”指有权参与表决的出席议员过半；特别法规定全体成员门槛的依特别规定。回避名单及理由入卷，回避不得借机虚报法定人数。

4. 银烛调和会议不逐字公开协商，不妨碍记录代表名单、形成方案、回避事项与最终文本；法定两院复决仍完整入卷。

6. 对计票、议员资格、程序处分的异议，元老会须记录、说明并在下一次表决前处理影响票数的事项；涉嫌越权或侵害法定权利的，得依裁断体系请求审查，元老会的程序裁定不自行变为银章终局解释。
```
