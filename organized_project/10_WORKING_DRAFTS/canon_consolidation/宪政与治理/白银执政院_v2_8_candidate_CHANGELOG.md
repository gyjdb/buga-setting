```text
# 附：本版相对 v2.6 的主要调整

1. **合并工业与科技两部**：原"奥术科技部"与"工艺与术式工业部"合并为"工艺与奥术科技部"，研发（应用研究、技术攻关、术式工程转化、青年学徒科研）与产业（工坊治理、产能动员、军工转产、检定执法）合于一部，与白银学会的学术认定边界一并整合。组成部门由二十四部缩为二十三部。
2. **魔核能源治理收口**：撤销原挂于奥术科技部的"联盟魔核能机构"牌子，将魔核能源的规划、研究、安全评估、重大实验备案合并入"魔核能源局"一处，并自发展筹计委员会改隶工艺与奥术科技部；采权仍归云海资源与生态部，质检仍归银材与魔核质量检验所，事故鉴定仍归术式工业事故鉴定所。魔核能源由原"规划／研究／质检／事故"四处分切收紧为"一处主政＋必要技术口"。
3. **统一命名，去除古语与冗赘**：盟约司法部改称法制部（避免与裁断体系的司法权混淆）；铨叙与誓约部改称组织部；市易行会部改称商贸与行会部；粮农储备部改称农务与粮储部；直属机构市易监督总局相应改称市场监督总局。
4. **订正全篇遗留称谓**：终局机关、机要处、密卷与传讯部等处的"秘银学派"统一订正为"银色学派"（与《银色联盟宪章》《白银议会组织法》《银色联盟防务基本法》一致）；浮空城建设与水务部全篇统一（不再混用"浮城建设与水务部"）；特许单列机关中的最高防务机关统一称"联盟军事委员会"。
5. **与防务基本法同步对接**：执政院不再设"舰务行政部"，军务后勤行政分由国用工务总局（军需采办、船坞征调与委托运营、军工履约、战备仓储）、财政部（军备与军工账及拨款）、工艺与奥术科技部（产能动员与产能基线标准）、联盟公产监督管理委员会（军用船坞等国用资产出资人监督）承担，并明确国用工务总局为军委的军需对口机关。《银色联盟防务基本法》同步升至 v2.3，删除其对执政院组成部门、所属机构的硬序号引用，改为按名称与职能对应衔接。
```

```text
### 行政第一条 授权、申请与决定
本目录列职责不等于直接创设税费、处罚、搜查、征收或执业禁令。主管机关办理已有法律依据的事项，应公布法源、申请条件、材料、责任窗口和时限；没有特别时限的五日内一次补正、齐备后三十日内决定，复杂事项可延长一次三十日并说明。无依据的新增负担不得实施；有争议的存量事项登记后依法核明，不得假称新法已经存在。

### 行政第二条 程序与救济
受理、技术审查、合议/批准、文书签发、执行、监督分别记责任人；同一申请不得要求向两个部门重复证明相同事项。拒绝或不利决定说明事实、依据、理由及救济；重大不利决定先给十日申辩，利害关系人员回避。当事人三十日内可向原机关的上级机关申请复核，由未参加原审人员三十日内答复；执政院自身决定由其另组回避原审的审查人员复核。复核不妨碍请求裁断救济。

### 行政第三条 跨部门与央地接口
法制部审合法性，城邦盟务部协调央地事项，财政部核预算，技术机关出意见；牵头机关不得把会签变成共同而无人负责。跨机关争议三日内移送有权协调者，十日未解决或涉及法定权限争议的，转有管辖权裁断机关；协调不暂停依法必要的最小救助，也不先行改变争议权属。城邦继续依宪章自治，不以本目录另造地方政府层级。

### 行政第四条 预算与国库接口
支出单位提出用途、法源、金额和所属三账，财政部核预算与拨款条件，议会决定新增或变更预算，国用工务总局等承办采购验收，联盟储备系统凭合法支付指令结算，监察院独立审计。储备院不决定拨款政策，财政部不指令超规则发行；三账间变更须取得原授权要求的预算批准。紧急支出先用已有合法应急额度，不足即提请追加，不虚构无限垫款权。争议款项分别记录，已无争议的法定救助不应被无关争议拖延。

### 行政第五条 紧急权限与退出
临时征调、封锁、疏散须记授权、事实、范围、责任、终止日和救济。现实紧迫风险依已有止险权最小先行，二十四小时内书面报告，七日内由有权机关复核，超出上位授权立即停止并纠正。紧急授权到期未依法续展即失效；危险提前消除即缩减或终止。运行机关恢复常态、返还或移交被征调财产、登记损失请求，三十日内交清册，议会的九十日审计期不因此推迟。赔偿实体标准缺口另行登记，不因缺标准拒收请求。

### 行政第六条 事故与责任
节点事故以节点结界工程部为技术牵头，城体事故以浮空城建设与水务部、工业事故以工艺与奥术科技部、疫害以卫生与疫害委员会为技术牵头；跨领域由执政院办公厅明确一名牵头者并记界面。所属检验单位作技术鉴定，治安机关调查涉嫌违法，监察院调查公职失职，裁断机关定争议与法定责任；原审批或运营人员不得独自裁定自身无过错。先救助隔离、再保全鉴定、后分别归责，结案须列复运条件与未决赔偿。已有预算承担先行处置，不预断最终损失归属。

### 行政第七条 身份、职业与服务
民籍誓籍局保存既有合法身份，材料缺失优先核对原登记而不以不会施法取消公民保障；新的争议入籍条件不由本目录擅定，申请应有回执、理由和复核入口。职业准入依已存在的专项授权，由对应机关受理；学术、环级、施法许可和职业登记分别决定。尚缺完整行业规则的，主管机关不得仅凭职责表新设强制证种或扩张封业权，列为后续接口并维持已合法取得资格。

### 行政第八条 魔法事实与公共设施
供能网络为人工设施，与银烛外部监测台网分开；魔核能源局依核心设备职掌协同，不重复节点接入决定。水与食物可由魔法生产，但造物须有输入；不推定普遍能源短缺、零输入产物或无限设备容量。即时通讯可用于送达与协作，仍须核验身份及回执。医疗可救濒死，不承诺死人复生；危险术式、装置和隐私取证遵守魔法法系与裁断程序。

### 行政第九条 文件发布与监督
银章文枢署登记令号、原卷和认证版本；新闻公报署按原本公开传播，办公厅公报处组织渠道，均无权改变实质决定。政务督察局查行政执行，盟约监察院独立追责；内部督察不代替司法救济。撤销、到期、替代文件应在同一登记链注明，防止旧令继续执行。
```
