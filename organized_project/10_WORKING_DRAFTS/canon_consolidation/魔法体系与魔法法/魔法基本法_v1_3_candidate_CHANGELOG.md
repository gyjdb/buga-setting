```text
## 序言

魔法是白银之民的立身之本。从浮空城的悬停，到战舰的驱动，到造物与传承的每一道工序，联盟的存续无不系于对魔法的掌握。

魔法的本原秩序——法则、魔力、环级与弦魔法——是沃恩德固有的法则，并非联盟所创设。本法载明这一秩序，承认它、写下它，却不僭称创造它；联盟所能规定的，只是这一秩序之下，魔力如何取用、法师如何认定、施法如何禁制。

```

```text
## 序言

魔法是联盟生产、公共设施、防务与知识传承的重要基础。本法区分已经确认的能力事实与联盟制定的制度，不以行政认定创造自然能力，也不以尚未定论的本体解释剥夺依法取得的资格。
```

## K20-C004 第三条

| 项目 | 内容 |
| --- | --- |
| 类别 | AUTHOR_CANON / CROSS_FILE_ALIGNMENT |
| 修改原因 | 纠正天然魔网，建立五概念和两类节点的单一主定义。 |
| 依据 | 作者1.3—1.7、3.3—3.7、4、6；M07/M09/M10/M15 |
| 影响文件 | K20、K15、K21、K13、K23 |

原规则：

```text
### 第三条 基本术语

本法所称：

1. 魔法：作用于现实的奥术力量的总称；
2. 法则：维系沃恩德运行的根本规则，即提亚马特（Tiamat）之守则；
3. 魔力：可被引导以施展魔法的能量；
4. 法术：施法者依特定术式施展的、可重复的魔法；
5. 环级：法术因触动法则的深浅而天然区分的等级；
6. 神之下：一环至十四环的法术，在法则之内运作；
7. 弦魔法：作用于法则本身的魔法；
8. 魔网：沃恩德弥漫的魔力的源头，只供给能量，本身不施法术；
9. 节点：接入魔网、汲取能量的枢纽设施；
10. 结界：约束、引导或阻断魔法的术式构造；
11. 禁魔：以结界对施法行为本身的禁制；
12. 法师：经认定具有相应环级的施法者；
13. 环级认定：联盟对施法者实际施法能力的确认与登记。
```

候选新规则：

```text
### 第三条 基本术语

本法统一下列术语，其他魔法法规引用本条：
1. 法则：维系沃恩德运行的根本规则，即提亚马特（Tiamat）之守则；魔力：可被引导施法的能量；法术：以特定术式实施的魔法。
2. 环级：术式等级；总体系十五环，十四环为凡人的终点，十五环为神的力量。次级法术不计环。现行普通认定与许可覆盖一至十四环的非弦术式，不授予十五环许可；各体系十五环可达范围不据本条推定。
3. 弦魔法：直接作用于法则的魔法，存在低环；不以“神域”作为当代高环或弦魔法的法律类别。
4. 魔网：布加建造的魔法网络；纯供能不代替施法能力。供能节点为接入或中转设施；外部监测节点用于观测沃恩德其他地区，二者登记、权限和预算分别标识。
5. 实际能力、环级认定、施法许可、职业执业资格、学术资质分别成立。环级认定确认能力记录，许可授权具体行为，职业资格授权专业执业，学术资质确认学术水平，任一项不自动替代其余项。
6. 结界为约束、引导或阻断魔法的术式构造；禁魔针对施法行为，不等于切断供能。
```

## K20-C009 第九条

| 项目 | 内容 |
| --- | --- |
| 类别 | AUTHOR_CANON / HISTORICAL_CORRECTION |
| 修改原因 | 保留低环弦纠正，删除以不能施弦穷尽黄金白银本质的推断。 |
| 依据 | 作者1.4、1.7、5.1；C06 M003/C09 M005 |
| 影响文件 | K20、K15、K21、K13、K23 |

原规则：

```text
### 第九条 弦魔法

弦魔法是作用于法则本身的魔法——它不在法则之内运作，而是直接拨动、改写法则。弦魔法不是更高一环的神之下法术，而是另一种秩序：神之下的力量运作于法则之内，弦魔法的力量作用于法则之上。施展弦魔法者亦自一环起算、自成环级，与神之下的环级各自独立计数，不相承接、不可直接比较高低。

弦魔法为龙族所本有——龙族天生执掌法则。在上古，敏尔人、上古英雄及不少存在也曾习得弦魔法；诸神黄昏与其后的离乱之后，弦魔法大多失传，今唯龙族与极少数存世的上古存在仍能施展。

白银之民——纵使是神之下最强的银色十二环——也不能及于弦魔法。此为金之民高于银之民的根由：银族的力量终究在法则之内，而龙族的力量作用于法则之上。
```

候选新规则：

```text
### 第九条 弦魔法

弦魔法直接从提亚马特法典底层抽取力量，以法则之弦重塑能量与魔力；存在从低环起的术式，不能理解为普通十四环的单纯延长。当前大陆明确使用弦魔法的种族为巨龙。黄金之民与白银之民的根本分工不以单一环级高低定义；银色十二环是领袖身份，不强制等同个人第十二环能力。弦魔法的法律禁制依第二十八条。
```
