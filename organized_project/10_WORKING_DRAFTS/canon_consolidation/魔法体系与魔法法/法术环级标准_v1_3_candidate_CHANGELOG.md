```text
### 第三条 基本术语

本标准所称：

1. 法术环级：法术因触动世界法则的深浅而天然区分的等级，简称环级；
2. 神之下：一环至十四环的法术，在世界法则之内运作，可由施法者施展；
3. 弦魔法：直接作用于世界法则本身的法术，与神之下并列而非承接，其力狂暴难驯；
4. 环级认定：联盟对施法者实际施法能力的确认与登记；
5. 禁魔：以结界技术对施法行为本身的禁制；
6. 魔网：沃恩德弥漫的魔力的源头，只供给能量，本身不施法术；
7. 节点：接入魔网、汲取能量的枢纽设施。
```

```text
### 第三条 基本术语
```

## K15-C007 第五条

| 项目 | 内容 |
| --- | --- |
| 类别 | AUTHOR_CANON / CROSS_FILE_ALIGNMENT / STRUCTURAL_REFACTOR |
| 修改原因 | 与基本法及专门程序建立单一来源，清除本条重复或相反规则。 |
| 依据 | 作者1、3、4、6；M01—M30；DD01/DD02/DD03/DD09 |
| 影响文件 | K20、K15、K21、K13、K23 |

原规则：

```text
### 第五条 神之下与弦魔法

1. 一环至十四环，称“神之下”。此类法术在 Tiamat 的守则之内运作，可由施法者凭自身修为施展。
2. 弦魔法不在法则之内运作，而是直接改写法则本身——它与神之下并列，而非神之下更高一环的延伸。施展弦魔法者，同样自一环起算、自成环级，与神之下的环级各自独立计数，不可直接比较高低。
3. 逾十四环的威能，唯弦魔法可及——这是世界法则本身的边界，不因联盟的规定而生，也不因联盟的规定而变。但弦魔法未必逾此境：施展弦魔法者，其力未必超越神之下的极限，亦未必到达凡身所不能及的烈度。

神之下与弦魔法之间的界线，是世界的法则；任何规定都不能跨越或更易这一界线。
```

候选新规则：

```text
### 第五条 神之下与弦魔法

总体系十五环、十四凡人终点；低环弦存在。普通目录一至十四环的非弦术式与弦知识分别标识，后者不进入普通认定或许可。不得采用将低环弦删除或把弦全归神域的分类。
```

```text
### 第十九条 禁制的分区

联盟空域内的施法禁制分为四档：
```
