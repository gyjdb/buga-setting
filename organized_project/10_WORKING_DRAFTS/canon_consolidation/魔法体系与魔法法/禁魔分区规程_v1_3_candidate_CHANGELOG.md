| 影响文件 | K20、K15、K21、K13、K23 |

原规则：

```text
### 第三条 禁魔的原理

禁魔是对施法行为本身的禁制，不切断能量（《魔法基本法》第二十五条）。禁魔结界搅乱施法回路，使施法者纵有自身魔力，也无法在其作用范围内成功施法；其效力不因施法者环级的高低而自动失效，但与禁魔场的强度相关（见第三章）。
```

候选新规则：

```text
### 第三条 禁魔的原理

禁魔的作用范围依《魔法基本法》第二十五条。纯供能不等于施法，既成效果不因入区自行消失；弦魔法不能被禁魔。装置启动、主动维持或重复产出是否受场压制，不作通用物理结论，依附件一逐项验证；不能只凭“设备有魔力”批准运行。
```

```text
（基准未设本节）
```

候选新规则：

```text
1. 设施运行机关逐项列出装置的纯供能、既成效果维持、新启动、重复产出和关闭动作。节点结界工程部安排隔离测试，术式鉴定室提供必要鉴定；测试本身需高阶许可时先取许可。
2. 验证报告只说明特定装置、条件与场域下观察到的行为，不宣称适用于全部装置的自然法则。报告记录失败模式、控制人、应急停机方法与复测触发条件。
3. 未验证行为不得作为绝对禁制区安全功能的唯一依赖；现场以物理隔离、场外执行、人工记录或停止该动作安排替代。纯供能及既成效果也应评估其工程风险，不因此自动准许危险设备。
4. 获准设备目录、责任人和例外范围由运行机关备案，节点结界工程部复核。改变核心、术式、场强或用途须重新验证；事故立即暂停相关行为、保存记录并依附件二调查。
5. 该协议是运行许可和工程验收，不回答所有设备能否被禁魔。必要功能仍无法验证和隔离时，该具体设施不得宣告具备开放条件。
```


候选新规则：

```text
1. 申请人向节点运营责任人提出接入用途、设备、需求范围及安全材料；运营人先核可接入条件，节点结界工程部或其依法授权的城邦工程单位作技术接入决定，魔核能源局就其核心设备职责出具意见，不重复发同一接入许可。十日内告知补正或安排审查，三十日内作有理由的决定；复杂项目一次延长三十日并告知。
2. 接入决定记录端口、设备、容量实测、安全阈值、值守责任与停运条件；不授予高阶施法许可，不裁定设施产权，也不自动产生新收费或资源配给权。作者确认的能量非稀缺不等于每个设备无限承载。

4. 工程机关主导技术调查，治安负责涉嫌违法部分，监察负责公职失职线索，裁断机关负责争议；参与设计或审批的人员不得独自鉴定自身责任。查明前不得销毁日志和争议设备。复运须由运营与工程责任人分别确认已满足原安全条件，写明未恢复部分。
5. 先行抢修和救助费用记入责任单位的已批准工程/应急预算，超额依《白银执政院》预算接口办理；最终分担与赔偿保留请求及证据，依现存适用法裁断，尚缺的产权、收费、赔偿通则另列后续接口。
6. 对接入、停运或复运决定可依《白银执政院》行政实施通则申请复核并请求裁断救济；即时危险的最小隔离可以先行，但二十四小时内书面说明、七日内复核，不以事故无限期维持停运。
```
