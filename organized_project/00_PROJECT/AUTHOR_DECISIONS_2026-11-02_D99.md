# 作者决定 D99：《银色联盟工艺产权法》按建议定

作者原话：“按建议定”。

答复的是《银色联盟工艺产权法》提案编者说明（四）的三个问题。作者此前要求“写工艺产权法”：工艺产权局已设，现行正文给它的实体规则只有《银色联盟学术研究与特许知识保管法》第三章的五条。

## 一、决定

1. 职务成果的权利属于工坊；完成人保留署名，登记后得奖金，实施或者许可后每年得报酬，不得低于实施所得利润的五十分之一或者所收许可费的十分之一；学徒自己的成果与出师之作归学徒（问题 1 甲）。
2. 不为侵害工艺产权另立罪名，只引现有罪名，其余以赔偿、没收、罚款与口岸扣留处理；《银色联盟罪名与刑罚法》不改（问题 2 甲）。
3. 《银色联盟学术研究与特许知识保管法》第十三条至第十七条并入新法，该法第三章只留两条指引，其后条号顺移，全法由二十八条减为二十五条；该法第十九条的特许知识保管机关加列工艺产权局（问题 3 甲）。
4. 《银色联盟契约与赔补法》第二十四条第1款改为分指两法：署名与共同成果依《银色联盟学术研究与特许知识保管法》，工艺产权依《银色联盟工艺产权法》。

## 二、执行

第三十二版新增现行正文《银色联盟工艺产权法》（K60）1.0.0，列入财政货币与经济；《银色联盟学术研究与特许知识保管法》修订为 1.1.0，《银色联盟契约与赔补法》修订为 1.0.3。现行正文增至 48 份。
