# 作者决定 D107：第一纪三百七十五年院校排行

> 年代已由 [D109](AUTHOR_DECISIONS_2026-11-03_D109.md) 改定：排行第一次刊出的前一年，白银学会公布的是第二十七轮；本文的“第四轮”改称“第三十轮”。

作者说“开始呗”，Claude 起草了[院校排行提案](../02_PROPOSALS/第一纪三百七十五年院校排行_提案.md)。对第二节（五）的两个问题，作者原话：“按建议定”。

## 一、决定

1. 《恰恩评论》霜降之月号的排行专题照提案第一节：综合排行三十四所、文理学院排行十一所、门类前三、排行办法与本刊统计。
2. 卡奈奇大学重回第一，图门大学第二（问题一甲）。
3. 恰恩大学第六，排在星月学院之后（问题二甲）。
4. 现行正文不改。

## 二、设定（不入法典）

- 《恰恩评论》是恰恩的月刊，第一纪192年创刊。院校排行始于第一纪340年，每年霜降之月号刊出，今年是第三十六次；卡奈奇大学二十二次第一，图门大学十四次，图门大学在371年至374年连续第一。今年改法：学科评定改用九级；得奖人从阿伦德尔奖、卡莱尔奖章两项扩到七项。
- 排行办法：综合排行收开设三个以上门类、向公众招生的大学与学院，文理学院另排，银烛学院与银色舰队学院不列入；六项指标为学科评定 30%、同行声誉 20%、院士 15%、得奖人 15%、录取率 10%、资质率 10%；文理学院排行用四项；门类前三先看第四轮的等级。
- 综合排行前十：卡奈奇大学、图门大学、卡奈奇理工学院、白塔大学、星月学院、恰恩大学、万物之塔学院、萨萨尔德大学、塔林工业大学、风暴王座大学。文理学院前三：银翼学院、艾弗拉德学院、安斯利学院。全部名次、分数与去年的名次见提案。
- 院士只出自白银学会的八个学部。在世的银冠院士约一千三百人，其中八百三十九人在高等院校任教。各院校的院士人数与七项奖的得奖人数，以提案的“本刊统计”为准，院校简介照此写。
- 各奖累计得主：阿伦德尔奖228人，卡莱尔奖章42人，阿什比奖105人，温斯洛奖147人，德拉蒙德奖27人，巴贝尔奖章70人，蒙塔古奖144人。
- 同行声誉、录取率与资质率只为排行的四十五所院校拟定；其余院校的，写简介时按需要补。

## 三、执行

不出新版正文，现行正文仍为 49 份；提案改标 REFERENCE。下一步拟学位的提案：作者提出要分学位，现行只有毕业文凭（《银色联盟高等院校法》第二十三条）与白银学会的银卷、银章、银冠三级资质。然后写院校简介，先请作者看定一篇样稿，再分批写。
