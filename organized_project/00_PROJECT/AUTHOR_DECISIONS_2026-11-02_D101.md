# 作者决定 D101：八份组织架构充实，按建议定

作者先说现行组织架构“都一般”，要求参照国务院部门的组织架构充实：“对口的肯定要参考对口的”，“虽然我们的人没那么多”；内务治安部以后单独重拟时再对标公安部。这一部分可以用 API，“搞定这一部分我觉得就可以发布了”。

对提案的答复，作者原话：“可以，按建议的可以。然后现有的也可以相对应的修改，因为我感觉有些名字一般般，可以简洁也可以调整，如果工程量不大的话。要是要消耗很多额度那算了。”

## 一、决定

1. 《外务部组织架构》《天空航务部组织架构》《节点结界工程部组织架构》《教育典籍部组织架构》《联盟军事委员会组织架构》《银色舰队组织架构》《银色战团组织架构》《要塞军团组织架构》八份充实提案照建议采纳。
2. 提案请作者决定的两问照建议：银色舰队的驻泊基地设于纳瓦里斯、格雷修斯与奈奥奇；教育典籍部的地区教育联络处设于格雷修斯、奈奥奇与翼狮城。
3. 八份里的机构名称，新设的与原有的，都可以改得简洁、贴切；其他现行正文引用的名称不改，以免牵动别的正文。改名经 API 提出、编者核对，列在各份提案的编者说明（七）。

## 二、执行

第三十四版修订八份组织架构：外务部 3.1.0、天空航务部 3.1.0、节点结界工程部 2.1.0、教育典籍部 2.2.0，联盟军事委员会、银色舰队、银色战团、要塞军团 1.1.0。现行正文仍为 49 份。第三十至三十四版随后发布到公开仓库。
