# 作者决定 D127：期刊名单与《期刊引证年报》

这是学术体系补完的第一项，次序见 OPEN_ISSUES 开头，作者 2026-11-04 定。Claude 先拟框架（`tmp/期刊名单草稿/期刊名单_框架.md`），作者转来一份审读意见，十条都照改；全文见[期刊名单与《期刊引证年报》提案](../02_PROPOSALS/期刊名单与期刊引证年报_提案.md)，提交为 99e0ce0。作者看后问：“你这些时间是不是不太对，咋都是第一纪的？”于是十八种刊改在古典时代创刊，并补写了大魔潮后的复刊年份（623ebb8）。Claude 问“改过年代的这一稿采纳吗？”，作者答：“采纳，登记D127”。

## 一、决定

1. 期刊名单照提案第一节的收录总表。收录九十三种：综合刊三种，《白银学会会刊》八辑各计一种，各门类的专门刊物六十七种，院校学报十五种；另列不收录而被引的七种。D105 的七种都在其中。
2. 创刊年代。连会刊与《白塔学会年刊》在内，有二十种创刊于古典时代（混沌纪年 824—1516 年）。这些刊物大魔潮以后多半停刊，第一纪初年复刊；《白塔学会年刊》没有停过。D105 定的五种照旧在第一纪，第一纪新办的共五十一种。各刊的主办、所在、创刊年、刊期与简介照提案。
3. 《期刊引证年报》：
   - 编者是大图书馆期刊编目室，馆务委员会依《大图书馆章程》第十一条于第一纪 356 年增设的分室。
   - 358 年试编，359 年起每年流火之月刊行，375 年是第十七版。
   - 卡奈奇、塔林两处机房各配一遍，对不上的由守护者核对。
   - 六项数字：两年引证率、十二年引证率、被引半衰期、自引比、收稿至刊出、查无此引。
   - 分档在门类内按名次除以种数，分一档至四档；不满四种的不分档；坊间把一档叫“头档”。
   - 同列、停列、送存年份与“查无此引”的口径，照编例。
   - 《引证总目》363 年起列为晨光级。
4. 第一纪三百七十五年版的各项数字照提案，停列《维瑟兰大学学报》与《赫兰大学学报》。
5. 年报的来历与沿革照提案：
   - 318 年，恰恩公共书库的馆员普雷斯科特手数引文。
   - 360 年起，千年七题所说的“正式学术期刊”以年报收录的为准。停列之年所登的论文照算；在讲演里宣布的解答，要等登上收录的刊物才起算六年。
   - 361 年，《书卷之月宣言》。
   - 362 年，白银学会把“刊在哪种期刊、得过什么奖、被引用多少，都不代替审读”写进第三十轮评定办法。
   - 363 年，添列十二年引证率与被引半衰期。
   - 364 年，不向月刊提供各校的引证数，所以 D107 的排行没有引证一项，D107 不改。
   - 366 年，头一回停列。
   - 370 年，添列“查无此引”。
6. 《书卷之月宣言》七条与《奥术》来信两则，照提案第二节。
7. 新定的人物：普雷斯科特；科尔布鲁克，期刊编目室主管，守护者；霍尔布鲁克，混沌纪年 1112 年在恰恩大学创办《纯粹与应用算学杂志》。
8. 编者说明（五）列的建校年份上限，写院校简介时照办。十五种院校学报的创刊年份，随院校简介一并定。
