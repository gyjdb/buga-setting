# 作者决定 D108：学位

> 年代已由 [D109](AUTHOR_DECISIONS_2026-11-03_D109.md) 改定：学位的规定改为第一纪四十年加入、四十一年施行，此前各院校依章程授予学位；第二节的年代以本决定为准。

作者在排行一步提出：“之后我们是不是得分一下学位啥的，但是那都是细节了。”Claude 起草了[学位提案](../02_PROPOSALS/学位_提案.md)。对第四节（三）的三个问题，作者原话：“可以，按建议定”。

## 一、决定

1. 学位分学士、硕士、博士三级，冠以学科门类的名称，外文写作 Bachelor、Master、Doctor（问题一甲）。学位由院校学术委员会决定授予，载在毕业文凭上，不另发证书。
2. 授予资格依该门类最近一次学科评定的结果：开设完整修业课程的门类可以授予学士学位，评为 B 等以上的可以授予硕士学位，评为 A 等的可以授予博士学位；指导博士学位论文的教师须持银章凭证或者银冠凭证（问题二甲）。
3. 修业年限由院校自定，通常学士八年左右，硕士在学士以后再修四年左右，博士不少于八年（问题三甲，设定）。
4. 学位与白银学会的学术资质分开；白银学会可以将博士学位论文作为高级学术资质考核的学术成果。博士学位论文公开答辩，涉及特许知识的除外；论文送大图书馆收藏。

## 二、设定（不入法典）

- 这次修改由第三十届白银议会在第一纪三百七十五年书卷会期通过，第一纪三百七十六年春晓之月初一日施行。第一批照新法授予的学位，按第四轮学科评定的等级确定授予资格。
- 布加的孩子入高等院校多在十六至二十岁，取得博士学位多在四十岁上下。
- 各院校的学士学位考核多在书卷之月举行；书卷联盟七校的联合考校，是七校学士考核的一部分。
- 十二个门类的外文名称与文凭式样，见提案第三节（四）、（五）。
- 自第一纪三百七十六年起，三十七所院校可以在七十七个门类授予博士学位；可以授予硕士学位的门类二百项，学士学位二百一十七项。各院校的名单见提案第三节（六）。
- 名誉学位与专业学位暂不设。
