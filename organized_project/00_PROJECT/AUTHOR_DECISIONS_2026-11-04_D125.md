# 作者决定 D125：学术名篇第一批定稿

第一批三篇是韦斯特法尔《论弦术的取力》（混沌纪年 930 年，《白塔学会年刊》）、卡明斯《论可判之事，兼答塞弗林第五问》（第一纪 318 年收稿、319 年刊出，《法则年刊》）、塞尔比与奥姆斯《论魔力交换的最小份额》（第一纪 338 年，《白银学会会刊》第一辑），见[学术名篇提案（第一批）](../02_PROPOSALS/学术名篇_第一批_提案.md)与[英文原刊](../02_PROPOSALS/学术名篇_第一批_英文原刊.md)。三篇照原作逐节扩写，先后经 GPT 同行评审与 Argon 审稿修订，提交为 6dd6ae9、5917c96、59cd409、5357544、1060d04、a8f662a。编者说明（七）请作者看三篇与六份 PDF，并问全书的篇目。作者当时答“写第二批”，此后第二至六批照（二）的篇目写成，逐批定稿，第一批本身一直没有登记。D124 登记以后，Claude 问“第一批三篇也登记定稿吗？”，作者答：“登记定稿”。

## 一、决定

1. 三篇与六份 PDF 定稿。
2. 本批新定的事一并认可，见编者说明（四），包括扩写与两轮审稿后补的设定，以及排印本里的刊处、页码与封面。要点：
   - 选本的体例：《联盟学术名篇》，恰恩大学出版部编，第一纪 375 年修订本；每篇有题解、正文、附三部分；第一纪论文照原刊，古典论文用今译；圆括号为原注，【】为编者注；
   - 论弦术的取力：三扰表、叠扰与层层折耗；929 年霜降之月在学会宣读，930 年（沙漏之年）卷刊出；韦斯特法尔的老师阿瑟顿 944 年用自己的器械重做试验，认了错；
   - 论可判之事：卡明斯 233 年生；第五问的原话；刊于《法则年刊》第二百二十三卷第二期（319 年），320 年刊出订正；可演之数、待令之链、〈通演〉与各条定理；普雷斯科特 316 年提出的递推可定之函；
   - 论魔力交换的最小份额：第八问的原话“魔力是否连续？”；换序余量与 19,762 次记录；汤顿所测的 1.011；一缕合（3.47 ± 0.01）× 10⁻¹¹ 旧制交换单位；联盟计量学院 339 年刊在《奥术》上的短报。
3. 两轮审稿的取舍认可，见编者说明（六）。
4. 编者说明（七）第二问的全书篇目：第二至六批照（二）的篇目（甲）写成；D124 撤下罗伊斯一篇、另补三篇，全书现为二十篇，以 D124 为准。
