# 作者决定 D109：高等院校法、学科评定与学位的年代

第三十八版以后，作者说：“你这些生效时间太晚了吧，学位啊，学科评定都稍显晚了吧。但是排名可以是今年的。”联盟创盟已经一千零六十八年，名校多半比第一纪还老；高等院校法第一纪三百三十年才施行，学位三百七十六年才施行，确实太晚。本决定把这几件事提前，院校排行仍是今年的。年份由编者拟定。

## 一、新的年代

| 事项 | 年份 |
| --- | --- |
| 各院校依章程授予学位，名称与层级不一，最早的上溯到混沌纪年 | 混沌纪年起 |
| 《银色联盟高等院校法》由第二十届白银议会通过，春晓之月初一日施行；《联盟高等院校名录》首版 | 第一纪18年 |
| 第一轮学科评定，按五等公布 | 第一纪27年 |
| 第二轮学科评定 | 第一纪39年 |
| 第二十一届白银议会在书卷会期增设学位（第二十三条之一至之四、第四十条之一），次年春晓之月初一日施行，授予资格依第二轮的等级 | 第一纪40年通过，41年施行 |
| 《恰恩评论》第一次排行院校，用的是前一年第二十七轮的结果 | 第一纪340年 |
| 修改第三十一条，A、B 两等各分三级，自下一轮起适用 | 第一纪369年，书卷会期 |
| 第三十轮学科评定，第一次按新等级公布 | 第一纪375年（今年），书卷之月 |
| 第三十一轮学科评定 | 第一纪387年 |

- 学科评定每十二年一轮，第一纪二十七年至今共三十轮。前二十九轮按五等公布，旧结果照原等级记载。
- 名录每年一版，今年是第三百五十八版；正文里的“第一纪三百七十五年版”不变。
- 施行后九年才办第一轮评定，缘由同 D104：已有的院校有三年申请设立认可，白银学会还要拟定评定办法、组建评审组。
- 学位的授予资格随每轮评定调整：评定结果公布的次年起，新招的学习者照新的等级（第二十三条之二）。第三十轮的结果（D106）适用于第一纪三百七十六年起招收的学习者。
- 正文的版本号记的是本项目补写的先后，不是立法的先后：学位的条文（1.2.0）第一纪四十一年施行，A、B 两等的分级（1.1.0）三百六十九年修改。

## 二、取代的说法

- D104 第二节：本法由第二十九届通过、第一纪三百三十年施行，名录今年是第四十六版，第一至四轮在三百三十九至三百七十五年。
- D106：“第四轮”改称“第三十轮”，“前三轮”改称“前二十九轮”，“第五轮”改称“第三十一轮”。
- D107：排行第一次刊出的前一年，白银学会公布的是第二十七轮，不是第一轮；“第四轮”改称“第三十轮”。
- D108 第二节：学位的规定在第一纪三百七十五年通过、三百七十六年施行。
- 不变的：院校排行是《恰恩评论》第一纪三百七十五年霜降之月号的第三十六次排行（D107）；学术荣誉的年份（D105）。

## 三、执行

现行正文不改。学术荣誉与院校联盟、学科评定结果、院校排行与学位四份提案里的轮次与年份照改，学科评定结果提案改名为《第三十轮学科评定结果提案》；学科评定等级修订提案与 D104、D106、D107、D108 的文首注明以本决定为准。
