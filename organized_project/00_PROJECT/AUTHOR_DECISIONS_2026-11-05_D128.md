# 作者决定 D128：教师职级与聘任

这是学术体系补完的第二项，次序见 OPEN_ISSUES 开头，作者 2026-11-04 定。Claude 先拟框架（`tmp/教师职级草稿/教师职级_框架.md`），作者转来一份审读意见，照改；全文见[教师职级与聘任提案](../02_PROPOSALS/教师职级与聘任_提案.md)，提交为 2338ca5。Claude 问“教师职级这一稿采纳吗？”，作者答：“采纳，登记D128”。

## 一、决定

1. 《书卷联盟教席通约》照提案第一节，现行为第一纪三百六十二年修订本，共二十九条。
   - 第一纪二十六年由书卷联盟五校订立：卡奈奇大学、白塔大学、恰恩大学、万物之塔学院、星月学院。历次修订与加入，见第二十九条。
   - 截至三百七十五年，六十五所院校中有五十四所加入。
   - 没有加入的十一所：四所部属院校（联盟治安学院、联盟刑事侦查学院、银烛学院、银色舰队学院），以及七所私立院校（费尔顿商学院，惠特莫尔、埃勒里、芬威克、诺斯科特、科尔温、英格拉姆六所文理学院）。
2. 职级与任期：
   - 助教由高年级博士生兼任，至多六年。
   - 讲师须持银卷凭证，一任十二年，可续一次；两任期满仍未升任教授的，不再续聘。
   - 教授须持银章凭证，可以指导博士。长聘三十六年，期满前三年审读代表作，决定是否续聘。长聘期内，非经学术纪律程序，不得解聘、降级或者削减薪俸。
   - 讲席教授不设资质门槛，一任三十六年，不续，坐满让席。
   - 研修员须持银卷以上，一任六年或者十二年。
   - 客座一次至多十二年。
   - 退席教授保留称号，可以授课，可以带完门下的博士生；不占员额，不计入学科评定的在任教师。
   - 不设退休的年岁。学科评定所称在任教师，指讲师、教授与讲席教授。
3. 聘任：
   - 只看候选人自选的代表作，讲师两件，教授与讲席三件；院外审读人不少于三人。
   - 不数头档（三百六十二年修订）。
   - 候选人的师父、同门与门下弟子，不得担任审读人。
   - 聘教授须在城里作公开讲演；坐讲席须作就席讲演。
   - 本门不聘：不得直接聘任本校授予其博士学位的人，在外任职满十二年可以回来。
   - 设席人可以列席选任组，不参与表决。
4. 年资与流动：
   - 院外的年资照算；工艺院校另算工坊年资，师范院校另算学塔年资。
   - 每任满十二年，休修一年。
   - 教授可以借往他校，至多十二年。
   - 可以两校兼任，以其中一校为本校。
5. 让席：
   - 期满之年的书卷之月让席。
   - 席牌银质，正面刻讲席的名目，背面刻历任坐席者的名字与起止年份。
   - 讲席暂虚，至多六年。
6. 沿革：
   - 混沌纪年九百零二年，卡奈奇、恰恩、塔林三城合捐塞弗林讲席，这是联盟最老的讲席。
   - 古典时代的讲席是终身的。
   - 一千三百八十八年，几所老校订立《让席约》，讲席以三十六年为限，照议员一任的先例。
   - 大魔潮以后讲席空了十五年，第一纪十五年重开。
7. 四件文书照提案第二节：
   - 卡奈奇大学聘伊莉丝·肯德尔为教授，三百七十五年起，长聘至四百一十一年。
   - 温特沃斯在三百七十五年书卷之月，把塞弗林讲席让给阿什福德。
   - 卡奈奇大学讲席名录一页：讲席一百一十四个，坐席一百零九人；在任银冠院士中，八十一人坐讲席，四十七人任教授；另有三十一人已经退席。
   - 《奥术》招聘启事两则。
8. 新定的人物与名目照编者说明（六），给院校简介的数字照编者说明（五）。
