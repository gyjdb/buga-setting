# 作者决定 D126：学术名篇第七批定稿

第七批是 D124 另补的三篇：梅特卡夫《元素亲和表》（混沌纪年 1271 年，《白银学会会刊》）、费尔法克斯《位面几何所依的假设》（1283 年宣读于白塔学会，1286 年刊《白塔学会年刊》）、索恩《讯量与线的容量》（第一纪 248 年，《白银学会会刊》第七辑），见[学术名篇提案（第七批）](../02_PROPOSALS/学术名篇_第七批_提案.md)与[英文原刊](../02_PROPOSALS/学术名篇_第七批_英文原刊.md)，提交为 b0362ff。审稿原拟请 GPT，OpenAI 的账户没有余额，改由三个 Claude 子代理各审一篇，取舍记在编者说明（五）。编者说明（六）请作者看三篇与六份 PDF，认可三篇的篇名、作者、年代与刊处和本批新定的几件。Claude 问“第七批三篇可以定稿登记 D126 吗？”，作者答：“可以定稿”。

## 一、决定

1. 三篇与六份 PDF 定稿。
2. 三篇的篇名、作者、年代与刊处照提案：
   - 梅特卡夫《元素亲和表》，卡奈奇，混沌纪年 1271 年送交白银学会，刊《白银学会会刊》当年卷；
   - 费尔法克斯《位面几何所依的假设》，白塔的银袍法师、白塔学会会员，1283 年复苏之月宣读于白塔学会；因讲到白塔深处的折叠先送审，1286 年刊《白塔学会年刊》，那一段删去不印；
   - 索恩《讯量与线的容量》，塔林工业大学，第一纪 247 年秋暮之月收稿，刊《白银学会会刊》第七辑（度量与标准）248 年第一、二期。
3. 本批新定的事一并认可，见编者说明（三）。要点：
   - 元素亲和表：以六分之一为距的八十四个格点；照艾尔沃西的法则代数推出的骨架 xF + yG、骨架之强、相抵之对与斜之数 xy，两轴相交总是火水一轴在先；加斜试验，寻常的地方承得住八份半上下的斜；骨架为空的四个格点无晶，斜之数为九的四个格点是空格；蓄能与骨架之强成正比，晶型只看骨架的方向，硬度只看相抵之对；四处订正；空格的晶体带到寻常的地方一点一点失去晶型，是梅特卡夫的推想；贝拉米 1337 年在莎拉之泪里见到的第一枚；
   - 位面几何所依的假设：位面是多重的延展，度量是另加的一层；曲与三种匀曲，没有边不等于无穷；卡奈奇的试验半位面由白塔学会维护门户，半径 9.64 步，直行六十步上下回到门口；万物之塔测站的三个大三角；锻造的位面里度量由法则维系，交给法则学；彭布罗克 1441 年的序与八种标准的几何块；
   - 讯量与线的容量：讯量与择、余疑与容量、五条定理；潮汐之噪只算预报不了的部分，照潮汐表挪动判别的界线，照潮相换码、调速率；塔林—卡奈奇线平月与潮月的数；布鲁尔、曼宁、格雷夫斯三位前人；第七学部研拟、学术委员会审定的 256 年《传声网符讯编配规程》。
4. 审稿的取舍认可，见编者说明（五）。这一批由 Claude 子代理代审，作者没有等 GPT 重审，直接定稿。
5. 全书二十篇至此写完，篇目以 D124 为准。
