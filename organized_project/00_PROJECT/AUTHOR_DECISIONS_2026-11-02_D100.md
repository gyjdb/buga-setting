# 作者决定 D100：《银色联盟学派与行会法》按建议定

作者原话：“按建议定”。

答复的是《银色联盟学派与行会法》提案编者说明（三）的四个问题。作者此前要求“写学派与行会法”：公议院的学派席、行会席由学派与行会推举，现行正文却没有一部法律规定学派与行会本身。

## 一、决定

1. 新的学派与行会由公议院资格审查委员会审查、公议院以出席议员过半数决议认可；《银色联盟白银议会组织法》第十三条点名的十个视为已认可，其认可只以修改该法变更（问题 1 甲）。
2. 开设工坊不以加入行会为条件；成员城邦不得强制工坊或者从业者入会，不得授予行会专营（问题 2 甲）。
3. 学派与行会可以按术式、技艺、师承、学艺与品行设入会条件，不得仅因血统、城邦或者出身拒绝；被拒的可以提合法性异议（问题 3 甲）。
4. 推举方式由章程定，可以全体表决、代表大会或者合议推举；全体表决一人一票，不按环级、资历、会费、出资分票，代表大会与合议不得按会费、出资或者环级组成（问题 4 甲）。

## 二、执行

第三十三版新增现行正文《银色联盟学派与行会法》（K61）1.0.0，列入宪政与治理；《银色联盟白银议会组织法》修订为 3.6.11（第十三条、第十五条六处）。现行正文增至 49 份。
