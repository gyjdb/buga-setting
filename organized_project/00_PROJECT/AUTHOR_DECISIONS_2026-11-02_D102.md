# 作者决定 D102：内务治安部组织架构重拟，按建议定并发布

作者此前说：“之后可能我们拟定治安部的可以参考对标。”编者答复现行稿已照公安部排定机构门类，建议机构门类照公安部、联盟与城邦的分工参照联邦警察；作者答：“ok没问题，那你来决定吧。”对重拟提案，作者原话：“按建议定并发布”。

## 一、决定

1. 《内务治安部组织架构》改为三定条文体例，机构门类参照公安部，联盟与城邦的分工参照联邦警察，照提案采纳；现行稿的规则、程序与期限照旧。
2. 设地区治安协作办事处，设于格雷修斯、奈奥奇与翼狮城，只收转协作请求与通缉协查、联络案卷交接，不受理城邦治安事务，不指挥城邦治安机关（提案问题甲）。
3. 《银色联盟罪名与刑罚法》按节号引用本架构的四处改引新的条、项；《白银执政院组织架构》的对外挂牌表补列“联盟治安协办”。
4. 升为现行后发布到公开仓库。

## 二、执行

第三十五版修订《内务治安部组织架构》为 3.0.0、《银色联盟罪名与刑罚法》为 1.0.4、《白银执政院组织架构》为 2.8.9。现行正文仍为 49 份。
