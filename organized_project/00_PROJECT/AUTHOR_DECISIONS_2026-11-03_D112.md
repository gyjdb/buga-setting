# 作者决定 D112：学科史大改

[学科史大改提案](../02_PROPOSALS/学科史大改_提案.md)依据《琥珀之剑》原著的底层设定与作者对四批学科史词条的意见，挑出可用的原著设定，重排《联盟学科年表》与 D110 的成果年代，定下十七条学科史词条的改写方向。作者答复：“不采纳的四六七八十和十一，感觉都还可以……你的这些建议，我觉得也都没问题。”作者又说明目标：眼下只写学科史，后面还有学校等各方面；多出来的原著资料，以后可以用来重整以前的设定。

## 一、决定

1. 原著设定照提案第二节。采纳的五十二项、改写后采纳的十项照录；不采纳的十三项里，第四、六、七、八、十、十一项改为采纳，处理见第二节；其余七项仍不采纳：联盟只有十二座城邦、联盟分裂为三派、恰恩是地上的城市、辉耀之年白银之民遁世、拥有十个魔力池才算魔法领地、上一次大魔潮的另两种年代、小说当下以后的事。
2. 新年表照提案第三节，D110 照第四节改。
3. 十七条学科史词条照第五节改写。
4. 昼夜同步（第七节问一）取甲：文明疆域之内各城日出同时，“太阳是法则的显现”作为学说。
5. 目标分先后：眼下只做学科史；院校简介等照原计划以后再做；原著资料对旧设定的影响，另做一份清单，以后分批重整。

## 二、改为采纳的六项

- **第四项，穴兽之年。** 复核原文：原著两处都把穴兽之年放在第一纪 342 年，一处直写“历史上的穴兽之年（342年）”，一处说是“差不多三十年前”的事；“322 至 325 年之间”是对照时据另一句推出来的，不可靠。所以穴兽之年照 D103 仍是 342 年。采纳的是同一处原著记下的地上编年：第二次圣战约在第一纪 315 年前后开始，最后七年是十一月战争，到穴兽之年前后告一段落（第五卷第五十五、一百五十二幕）。联盟在这场战争以后分裂一说，仍不采纳。
- **第六项，要素。** 采纳为世界一级的设定，写在 Tiamat 的规则里。要素分六等：微要素、杂要素、强要素、法则之力、元素之力、存在性之力。微要素人人都有，不显现；杂要素是强要素的显化，又称显性要素。要素五境是开化要素、真理之侧、巅峰法则、极之境界、圣贤领域。作者基础原答已用到真理之侧与存在性之力，白塔承五境第二境之名，都照旧。→ 法则学史、医学史（凡人开化要素以后，寿命增加约一半）。等级、经验与数值不取。
- **第七项，邀请地上的天才进白塔进修。** 采纳为少见的例外：白银学会审定以后，邀请个别地上的天才进白塔查阅卷宗、进修。现行的《教育典籍部组织架构》已有“白塔访学”的联络职责，照此衔接；《白塔章程》的登塔资格只写公民，访学者能否登塔，以后再定。
- **第八项，十二环法术学会。** 采纳。这是专研十二环法术的学会，曾是布加最高的学术团体之一，在七色之年解散；最后一任银色首领是图拉曼，学会解散以后，他离开卡奈奇，回到地上隐居（游戏记忆）。它与银色十二环（银色学派）是两回事。七色之年的年份，到年名一项再定。
- **第十项，元素纪。** 采纳。元素种族以一百五十年为一个元素纪（第六卷，火妖精鲁特的说法）。→ 史学与典籍学史，作异族的纪年。
- **第十一项，天界巨鲸。** 采纳为博物的记录，写作“据说”：天界巨鲸在元素疆界上以能量为食，一天吃下的魔力，够一座浮空城用一百年；它排出的星形石魔力驳杂，极不稳定，随时可能爆炸（第四卷第一百零六幕，游戏记忆）。→ 博物学史。

## 三、设定要点（不入法典）

- **时间：** 第十六、十七、十九、二十、二十二问移到古典时代晚期：霍尔特 1330、奥斯本 1390、塔尔博特 1410、格兰维尔 1460、里弗斯 1490，都不再是第一纪的得奖者。古典时代解出十三问，第一纪解出六问。黑斯廷斯的跨城改道提前到第一纪 110 年前后。新年表一百二十二条，第一纪三十六条，古典时代六十三条。
- **魔导与城：** 魔枢在圣者之战末年有了雏形，战后定型，最早的燃料是琥珀原石；浮空城在战后一百年内陆续建成，创盟时只有首批几座。奥奈斯以坠入亡月之海的一块米洛斯残骸为城基。托力的链条最前面是 Tiamat 的法则之线。
- **世界的结构：** 世界的地基是魔力之海；Tiamat 降在其上，深处筛滤、分流魔力，上层是法则之网，最上是元素层。七层说是未经验证的学说。魔力经四大元素疆域并入 Tiamat。半位面按来历分三类；众月航道另记。
- **潮汐：** 十二轮魔月，十年一潮，百年一次大潮；大魔潮没有定期，“千年之潮”是地上对它规模的叫法。第一纪 375 年先兆正在升高。
- **秩序的边界：** 火种（原始火种与巫师的火种），火种会衰老；混沌纪年 1435 年起开拓者撞上过往之壁，1455 年（繁茂之年）永世回廊认定它是神民时代玛莎庇佑之地全盛时的疆界。
- **医学：** 白银之民不染凡俗的疾病；医学管法力池、魔力侵蚀、魔物毒、晶化与反噬。微魔是潮汐投出的极小魔物，疫害伤的是城里的凡人与混血居民、牲畜、作物与浮空生物，检疫兼用隔离与秩序结界。
- **用词：** “魔网”只指联盟的供能网；原著的“魔网”写作 Tiamat 或法则之网。Tiamat 是卫星矩阵、神民来自地球、Tiamat 由构装体组成、七层各自的名称，学界不知道，词条不写。
