# 作者决定 D110：学问与科技史、千年七题与代表性得主

[千年七题与代表性得主提案](../02_PROPOSALS/千年七题与代表性得主_提案.md)写了五稿，每一稿都照作者的意见改：
- 要多设几个奖、加些期刊，用刊物的形式来呈现；
- 不必照搬爱因斯坦、牛顿这些名人，要多写这个世界特有的发现；
- 要有一道算学题，但已经解出，仿照希尔伯特的问题清单；
- “一亿有点拉吧”，这个文明显得不如人类，成果的年代都太近，也没说有没有计算机。

对第五稿第二节（八）的三个问题，作者原话：“可以，都按你的来定吧，稍微打磨一下……你这些名字也可以稍微调整一下，比如什么‘算书’，感觉有点垃圾啊。”

## 一、决定

1. 塞弗林二十四问在创盟那年（Chaos 824），白银学会第一次全体大会上提出（问题一甲）。
2. 联盟有计算器械（问题二甲）：
   - 古典时代有专用的星算阵与可编程的演算机；
   - 第一纪有阿什比的通用符文单元；
   - 近年有对标人工智能的推演机。
   
   名称由第五稿的“算阵、算枢、推演器”改为“星算阵、演算机、推演机”。
3. 卡莱尔奖章改由白塔学会评选（问题三甲）。D105 与学界专号里“白银学会第一学部评选”的写法随之改。
4. 千年七题由千年基金会在创盟的第一千年（第一纪 307 年）公布：
   - 解出两道：最小魔力、偏折传送；
   - 解了一半：三万六千字符问题；
   - 四道未解：奥尔丁猜想、验证与构造、魔潮方程、第十环。
5. 学界几家机构的分工、七项奖的代表性得主与科技简史，照提案第一节与第二节（二）（三）。

## 二、设定要点（不入法典）

- **二十四问：** 解出十九问，其中古典时代八问，第一纪十一问；两问解了一部分，三问未解。第四问的答案是从巴贝尔残片里找回来的。第一纪九年订立书卷之约时，清点过二十四问。
- **古典时代（Chaos 824–1516）：** 分层说（930）；星算阵（930 起）；元素转化（980）；质数的近似规律（1010）；法则代数（1060）；潮汐方程（1100）；演算机（十二世纪起）；病原与无菌（1190）；奥尔丁猜想写成（1200）；魔网联调（1320）；偶数问题（1340）；三维位面的分解（1440）。
- **计算：**
  - 星算阵、演算机、跨城联算；
  - 典藏编码（第一纪 40–175）；
  - 阿什比的通用符文单元（约 200）；
  - 形式核验（213 年已有成果）；
  - 照应术式与推演机（约 350，林恩）。
  
  推演机的成果，须附可以独立复查的证明、实验记录或安全证书，否则不算数。
- **奥尔丁猜想：** 各城的演算机联算，核验了最前十的十八次方个非平凡零点。
- **第一纪的奖项只奖第一纪的发现。**
  - 卡莱尔奖章：芬利（213）、温德尔（249）、布莱斯（285）、卡明斯（321）、梅瑞克（345）、罗伊斯（357）、奥克利（369）。
  - 阿伦德尔奖：洛温（149）、霍尔特（152）、费恩（191）、奥斯本（203）、塔尔博特（251）、格兰维尔（278）、里弗斯（323）、塞尔比与奥姆斯（341）、哈尔丁（359）、沃尔什（374）。
  - 阿什比奖：莫顿（288）、黑斯廷斯（304）、奥克斯利（331）、林恩（352）。
  - 温斯洛奖：加德纳（263）、佩恩（318）、布鲁克（349）。
  - 巴贝尔奖章：斯塔福德（294）、阿普尔比（354）。
- **仍未解的：** 奥尔丁猜想；验证与构造；魔潮方程，以及大魔潮能否可靠预报；第十环；字符是否完备；时间术式的因果；法力池损伤快速而普遍的修复。
