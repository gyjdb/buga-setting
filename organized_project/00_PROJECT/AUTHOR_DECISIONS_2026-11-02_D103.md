# 作者决定 D103：纪年与年名

编者先提出由联盟另立“银章纪年”。作者答：“这个年份应该是全大陆通用的，就占星术士会在前一年的末尾定好类似下一年的年号，带有预言或者什么性质的？当然这个原作者没写，是我想的，我想要不联盟来做这件事？毕竟地上的占星术士应该一般吧。……我在想是结束了总结还是带有预言性质呢？我觉得后者更有感觉吧？”编者据此改写为第二稿，问今年是哪一年。作者答：“今年可以是繁华与夏叶之年。但是我给你的那么多年份里面就是单纯的罗列名称，我觉得作者也没有这方面的考究，就都能拿来用，我也懒得在这方面完全对上原作了，太麻烦了。当然我们也可以自己拟定。那联盟啥时候建立的呢？总之你来拟定吧，那就是启示之年作为第一纪的开端？总之你来设定，目前我感觉你做的还可以。”编者照此定稿，见[纪年与年名提案](../02_PROPOSALS/纪年与年名_提案.md)。

## 一、决定

1. 年份全大陆通用，依纪顺数，称某纪某年；联盟不另立纪年。
2. 每年另有年名。年名是预言，不是事后的总结：每年沉眠之月末日，联盟宣布来年的年名，由占星术士之万物之塔依星象推定。
3. 一纪终于大魔潮，由万物之塔推定、联盟宣布改纪。
4. 今年是繁花与夏叶之年。
5. 原作的年名都可以拿来用，不必与原作的年份完全对上。
6. 创盟的年份与改纪由编者拟定；启示之年是第一纪的第一年。

## 二、设定（不入法典）

- 混沌纪年（Chaos）在 Chaos 1516 的大魔潮之后结束，联盟在那年沉眠之月末日宣布改纪；来年为第一纪第一年（1st.1），年名启示。地上有的史官照旧往下数，把这一年记作 Chaos 1517。
- 年代锚点：月暮之年 Chaos 471，图门发明圣纹刻印；曼克托尔誓约 Chaos 712，圣者之战开始；Chaos 812 圣者之战结束；Chaos 824 奈塔斯创盟、颁布银章，第一届白银议会就任，年名光辉重返；启示之年即 1st.1，是创盟第694年。
- 今年是第一纪三百七十五年（1st.375），繁花与夏叶之年。按长日历，是创盟第1068年，第三十格第二十四年；在任的是第三十届白银议会（第一纪352—387年）。
- 长日历自创盟之年起，每三十六年一格，与白银议会的届次相同；只用于任期、届次与典礼，不另作年份。
- 年名在拉塔基推定，以联盟的名义宣布，同日刊于联盟公报，外务部照会地上诸国与诸圣殿。联盟不要求谁使用，地上照抄。年名与大魔潮的预警公开；逐月星历按价出售。万物之塔在创盟以前就推定年名。
- 写法：“第一纪三百七十五年书卷之月十二日”，需要时附年名；表格写“第一纪375年8月12日”；外文写 1st.375、Chaos 1517。
- 原作给了年数、又在今年以前的年名照原数用，如穴兽之年（第一纪342年）、呼啸之年（第一纪350年）；在今年以后的暂不用；没有年数的按需安排。同一纪之内年名不重复。

## 三、执行

第三十六版在《银色联盟宪章》增第一条之二“纪年与年名”，宪章升为 0.5.8。现行正文仍为 49 份。各法的颁行年份、学科评定的轮次、公布令与登记编号，以后另提。
