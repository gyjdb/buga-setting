# 《帕林大学学报》撤稿声明

《帕林大学学报》（自然编）第一纪三百六十九年第五期

本刊第一纪三百六十九年第二期所登哈伯德（Hubbard）《承斜器中空格晶体的保存》，现予撤回。

缘由：本年夏胧之月，炼金行会的一位会员来信，说文中第四条引文找不到。本刊随即逐条核对全文的四十一条引文，其中九条在送存各刊、字码典藏与大图书馆的存目里都核无其物，列在下面。第三节推出晶体的保存时间与器中余下的斜有关，所据的是第四条与第七条，两条都查无此引，这一关系不能成立。第二节所报十九件晶体的保存记录，本刊没有发现问题，但全文的结论出自第三节，所以全文撤回。

作者说明：第一节的综述与第三节的论证，是作者托塔林机房的推演机代拟的，引文也是推演机给出的。作者没有逐条核对原文，投稿时也没有写明用了推演机。作者同意撤稿。

本刊依《期刊编者约》第二十三条，把材料送帕林大学学术委员会。撤了的论文照存大图书馆，送存本加盖撤稿印。

查无此引的九条（编号照原文）：

［2］坦纳：《人工水晶的投料与亲和》，《炼金术汇刊》混沌纪年一千三百五十二年卷。该卷没有这一篇，坦纳名下也没有这一题。

［4］霍尔斯特德、莫斯廷：《承斜器中余下的斜与晶面的流失》，《核验录》第一纪三百五十一年第二期。《核验录》第一纪三百五十六年才创刊。
