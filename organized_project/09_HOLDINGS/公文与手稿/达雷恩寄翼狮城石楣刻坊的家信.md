# 达雷恩寄翼狮城石楣刻坊的家信

师傅：

今日离坞，我听见念到我们刻坊的名字。

左舷的接口我已经同装舰的哈维恩一道看过了。我们那块板外侧的接边，早已和整道护盾阵列熔接在一起；我在坊里灯下刻它时朝着自己的花纹，如今朝着船外的云海。午后试航加载平稳，您不必再派人来。

船太大了，连邻坞泊着的阿卡加斯之龙级停在它旁边都显得小。我画了两回都出了纸边，这张信纸背面那半截画不下的艉楼，就当它画完了吧。您接活那年说过，这么大的船多半造不完，让我们只管把板刻好。它今天从臂梢那道门里出去了，横桅先探出来，等了很久船身才跟上；坞里一点风也没有，帆却是满的。船坞街屋顶上坐满了人，全都没有说话。

船坞长在臂根念参建的名录，船出了门还没有念完。我站得远，不知道“石楣刻坊”后面念的是不是我的名字，但我想应该是。请告诉坊里替我磨刀备料的人，板现在朝着船外。

明早有顺路的运输舰回程，我搭他们的船到半路换客运艇。到家以前，这封信应该先到。

达雷恩  
春晓之月初八夜，于卡奈奇
