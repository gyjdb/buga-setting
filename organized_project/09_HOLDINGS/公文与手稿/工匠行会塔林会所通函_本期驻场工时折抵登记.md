# 工匠行会塔林会所通函：本期驻场工时折抵登记

各工坊：

塔林本年度共同义务份额已依《银色联盟税赋与共同义务份额法》核定，其中经议会认可的联盟工程驻场工时，现由本会所汇集材料，送交估值评议。

承担相关工程的工坊，请将本期驻场工时留痕簿、派工记录和工程验收材料送到会所。簿内写清参与人、所做工序及已交付的工作，由工程承办人签认；曾以同一工作领取报酬或申请其他折抵的，请一并说明，便于分清给付范围。请附一名熟悉工序的联络人，评议中需要查看样件或询问施工经过时，会所将与其联系。

估值由白银学会会同行会评议，采用本期公布的标准，储备院按结论记账。收到评议结果后有异议的，可按该法第二十四条递交说明与补充材料，由另行组成的评议人员复核；原已入账部分继续有效。

折抵登记在塔林城邦名下。工坊与城邦之间的款项结算，依塔林地方规定及承担工程的约定执行，请各工坊自行保存送交材料的副本。具体送件日期依本期份额文书所列日程，会所接待处备有全文，可供查阅。

工匠行会塔林会所执事
