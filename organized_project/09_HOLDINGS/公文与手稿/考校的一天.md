# 考校的一天

书卷之月一日，赛琳达记。

白塔的钟响时，我已经醒了，正躺着听母亲在厨房挪动锅盖。贝莉卡从床的另一头爬过来，问是不是该出门了。我把她抱下床，替她点亮桌边的灯。她还不会施法，伸出手指去够那一点光，我赶紧把灯挪远。

父亲穿着做工的白袍，在炉边用火术热早饭，袖子上留着昨日修器具时沾的灰。母亲把饼切开，叫我先吃。这是我头一回在广场受考，咬着饼却总想着待会儿要站在那么多人面前，嘴里什么味道也没有。贝莉卡倒吃得高兴，还问我考完能不能给她带东西。

出门前，我把学徒执照放进衣袋，将桌面腾出来，练了一遍牵引。木环从杯沿上方经过，落到垫子中央，我又试着让它掉头回来。第一次擦着了杯子，水晃出来一点。父亲没有说话，把杯子拿走，放下修补用的小块材料。我把垫边的裂口补好，再让木环走了一遍，这回没有碰到东西。

师父来接我们时，母亲正在替我系发带。贝莉卡在门边喊“诺德林大巫师”，喊完又躲回母亲身后。师父听我说昨夜没睡好，伸手把我紧紧攥着的练习册抽出来，说到了广场再看。他把册子还我，便先飞去了。我和米塞尔沿街走过去，米塞尔一路背着步骤，走到卖果子的摊前还在念。我拉了拉他的袖子，免得撞上掌柜正用术式托起的果筐。

白色大理石广场上已经来了许多人。有人抱着孩子找自己的家人，有人蹲下替学生系鞋带。我们在师父身旁放下包，隔壁那位巫师的学生正在练光术，亮起的光照得他自己眯了眼。他的老师把手移到低处，让他跟着重来。

轮到我时，母亲站在人群后，抱着贝莉卡。妹妹看见我便想喊，被母亲轻轻按住了嘴。我先做侦测魔力，那是入门时学的第一个小术，手势一摆出来，心倒定了一些。师父让我接着牵引桌上的木环。我盯着它，直到它越过支架、稳稳落回垫上，才敢抬头。

接下来是光与火。我点起灯盏，又依师父的示意收住火光；练轻量护身结界时，肩膀绷得太紧，师父叫我把气息放匀。我听见米塞尔在后面挪脚，差一点又去看他。末了，师父给我备好的材料，让我做一个小小的托座，再修好边缘的缺口。我做出的底面有些歪，放到桌上时轻轻晃了一下。

师父用指节压住托座，让我自己找问题。我摸到偏厚的那一侧，重新修平。他收起手，我又放了一遍，这次稳住了。贝莉卡终于挣开母亲，喊了一声我的名字。旁边有人笑，我的脸一下热起来，师父却只把托座递给我，说拿回去留着。

米塞尔受考时，我站到母亲旁边。贝莉卡马上要我的托座，她拿它比在自己杯底下，觉得正合适。我说那是练习用的，她便问练完了能不能给她。我只好答应，提醒她别把还没收好的材料弄到裙上。

午饭以后，我和米塞尔去广场东侧的白塔大学听讲演。青色界标旁摆好了座椅，后面站着没找到座位的人。一位学者在讲低环牵引术的新用法，桌上放着形状不同的小木件。他让木件绕过支架，重新排回图样里的位置，讲到转折处便停下来，请前排的人看他怎样收束术式。

我想起自己早晨碰着的杯子，把那处手势画在册边。米塞尔没看清，凑过来问我，等我画完又说弯得不对。我们争了几句，讲演结束便一起去问。学者拿起木环演了一遍，我才发现自己把回转的方向记反了。他让我改好，又告诉我可以看讲义的哪一页。

傍晚，在杏壳书铺，我挑了一本画着草木和果实的小书。贝莉卡常指着厨房里的叶子问名字，我想她会喜欢。掌柜让我摸封面的压纹，问要不要系一条带子。我选了深蓝色的，在扉页写她的名字，写到最后一笔才想起来，该让墨干了再合上。

回家经过白塔时，米塞尔问我什么时候去申请登塔。我说先把今天学的回转练好。望着塔的方向，我想起祖母讲过的故事：相传玛莎在法则之塔写下真理，旅者绕着塔向上走，一层一层领会其中的意思。我们城里的白塔，是先祖依记忆与残存的建造法则仿建的。小时候听到这里，我总要祖母接着讲那个旅者后来到了哪里。

米塞尔又说，塔里有人说位面共振会把承载真知的孤本吸引过去，书不知怎么就出现在塔内。他看了一眼我的包，问给妹妹的那本会不会也跑掉。我隔着包摸了摸书脊，叫他别拿这个逗我。

到家时，贝莉卡已经把托座放在她的小杯下面。她拆开书，先摸那道压纹，再叫我念扉页上的字。父亲问考得怎样，我把歪过的托座指给他看。他翻到背面，摸了摸修平的地方，说这次收得还算干净。晚饭后，我把讲义摊在桌上，贝莉卡捧着新书坐在旁边，要我每翻一页，都停下来听她念一个刚认得的字。
