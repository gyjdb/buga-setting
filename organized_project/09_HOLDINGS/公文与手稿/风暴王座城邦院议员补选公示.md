# 风暴王座城邦院议员补选公示

原由本城推选的城邦院议员经本城撤回，现依《银色联盟白银议会组织法》第九、十条完成补选，公示如下。

本次沿本邦已公布的议事会指定程序，由议事会成员托兰德提出提名，议事会审议后指定埃塞恩为本城推选的城邦院议员。埃塞恩为依法取得联盟国籍、已完成誓约登记的公民，常住风暴王座；有关资格材料已经核实，议员名册连同推选方式及登记资料报送元老会备案。

本邦公民可到议事会公示处查阅推选程序、提名人与产生结果的文书，向公示处提出意见；需要核实登记资料的，由公示处联系原登记机关。查阅与来函均由指定人员接待，并记录答复去向。

公民认为推选程序违法的，得依《银色联盟白银议会组织法》第九条第五款及《银色联盟裁断体系组织法》，向银章裁断庭提出异议。请说明所指程序、事实与理由，附所持有关材料；已经向本城反映的，可一并提交原答复。

风暴王座城邦
