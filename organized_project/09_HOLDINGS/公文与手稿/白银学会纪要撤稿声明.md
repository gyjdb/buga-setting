# 《白银学会纪要》撤稿声明

《白银学会纪要》第二百一十卷第八期　第一纪三百六十五年书卷之月

本刊撤回卡德沃思的下列九篇论文。九篇都由院士阿伯克龙比荐稿。

| 卷期 | 篇名 | 缘由 |
| --- | --- | --- |
| 第二百零六卷第三期（361） | 闭合符环与银线附魔的散失 | 数据伪造 |
| 第二百零六卷第九期（361） | 双重符环 | 数据伪造 |
| 第二百零七卷第二期（362） | 符环与晶体的斜 | 数据伪造 |
| 第二百零七卷第六期（362） | 潮位对符环减散失的影响 | 数据伪造 |
| 第二百零七卷第十一期（362） | 三重符环 | 数据伪造 |
| 第二百零八卷第四期（363） | 减散失可以叠加 | 数据伪造 |
| 第二百零八卷第十期（363） | 减散失的上限（短报） | 所据数据伪造，结论不能成立 |
| 第二百零九卷第三期（364） | 九重符环 | 数据伪造 |
| 第二百零九卷第七期（364） | 近于无散失的附魔：四十一次试验 | 数据伪造 |

八篇经白银学会学术纪律委员会认定为数据伪造（学纪字第三六五〇二号）。第二百零八卷第十期一篇是短报，只有推算，所据的是作者此前各篇的数据，数据既已认定为伪造，结论不能成立。

撤稿由本刊编者提出。作者与荐稿人都同意撤回。

本刊第二百一十卷第一期所登的存疑声明，至此有了结论。撤了的九篇照存大图书馆，送存本加盖撤稿印。《附魔》与《塔林工业大学学报》另登撤稿声明，分别撤回三篇与一篇；《塔林工业大学学报》第一纪三百六十年所登的第一篇不在撤回之列。
