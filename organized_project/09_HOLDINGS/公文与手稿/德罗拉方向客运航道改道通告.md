# 德罗拉方向客运航道改道通告

据航道气象与风暴预报台之风暴、乱流预报，开往德罗拉方向之客运艇自丰收之月十四日起暂循公布之临时航路航行，至恢复通告发布时止。新航路及沿途符文航标，见候乘廊航图与航道传讯。

依《天空航道与空港规程》第十六、十七、二十、二十二条：原有通行文书照常有效，旅客凭原有身份文书或来访者通行证继续行程；登艇栈台请向候乘廊客运承办处核对。需换乘他艇者，由空港人员带引，行李一并交接。

暂留空港之旅客，可向客运承办处询问候乘地点、饮水、饮食与医护；有幼儿、病弱者同行者，请当面说明。来访旅客同获上述协助。此后之航道消息，由客运承办处张贴、播告。

航道空港局
