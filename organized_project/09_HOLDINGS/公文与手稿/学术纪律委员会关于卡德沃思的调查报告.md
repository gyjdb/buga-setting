# 白银学会学术纪律委员会关于卡德沃思所发十四篇论文的调查报告（节录）

学纪字第三六五〇二号

一、受理。第一纪三百六十四年霜降之月，附魔学院研修员罗温娜·斯塔布斯（Rowena Stubbs）致信《白银学会纪要》的编者，说塔林工业大学讲师卡德沃思（Cudworth）所发的减散失论文，她照着做了三回，都做不出来；又说其中七篇所注的塔林测站当日读数，与该站第一纪三百四十一年同月同日的四次读数一位不差，误差也一样。《纪要》在第二百一十卷第一期登出存疑声明，把信转给塔林工业大学学术委员会。卡德沃思持白银学会银卷凭证，《纪要》所登的九篇都由院士阿伯克龙比（Abercrombie）荐稿，塔林工业大学学术委员会于三百六十五年春晓之月报送本会。本会依《白银学会章程》第二十三条受理。

二、所涉论文。卡德沃思第一纪三百六十年至三百六十四年发表论文十四篇，题目都是附魔时散失的魔力：《白银学会纪要》九篇，《附魔》三篇，《塔林工业大学学报》两篇。头一篇（三百六十年，《塔林工业大学学报》）报告，附魔时在银线外加一道闭合符环，散失可以减去一成上下；此后各篇所报的减幅一篇比一篇大，三百六十四年的一篇说，散失已不到寻常的十分之一。十四篇里有两篇是短报，只有推算，没有试验。

三、查证。

（一）读数。本会请卡奈奇理工学院机房，把各篇所注的测站读数与万物之塔所存塔林测站第一纪三百年至三百六十四年的全部读数逐一比对。注有读数的十二篇中，七篇与三百四十一年同月同日的读数相同；四篇也与三百四十一年的读数相同，只是日子错开了三至九日；只有头一篇所注的读数，与三百六十年实验当日的读数相合。

（二）原始记录。塔林工业大学调阅原始读数簿。卡德沃思称读数簿已于三百六十三年秋暮之月毁于工作间的一场法阵火；该校的安全记录里，那一年他的工作间没有登记过火情。

（三）用料。附魔所用的晶体与银线由学校库房发放。照库房的发放记录，三百六十一年至三百六十四年卡德沃思领用的材料，只够论文所报试次的五分之一上下。

（四）复做。斯塔布斯照头一篇做出了相近的减幅，照其余各篇都做不出来；她的三回复做，登在《复现》第一纪三百六十五年第二期。本会另请塔林以外的两处工坊，复做三百六十二年、三百六十三年的各一篇，也都做不出来。

四、本人的陈述。本会三百六十五年夏胧之月十四日听取卡德沃思的陈述。他说头一篇是真做的；此后照头一篇的路子往下推，推出的数他相信是对的，读数是事后照旧表补上的，原想以后补做。他承认那场火是他编的，读数簿从来没有记过。

五、认定。

（一）头一篇与两篇短报以外的十一篇，所报的试验没有做过，读数与数据都是编造的，构成《白银学会章程》第二十三条所称的数据伪造。

（二）两篇短报只是推算，所据的是此前各篇的数据。数据既已认定为伪造，推算失去依据；推算本身不构成伪造。

（三）头一篇的数据与读数相合，经复做相近，本会不予追究。

六、决定。

（一）撤销第五项第（一）目所列十一篇的成果认定。

（二）暂停卡德沃思的银卷凭证三十六年。

（三）第一纪三百六十一年至三百六十四年，卡德沃思领有工艺与奥术科技部的公共科研资助，所报的成果有五篇在上述十一篇之内。本会依《白银学会章程》第二十三条，把材料移送盟约监察院；经费追回与否，由工艺与奥术科技部依《银色联盟学术研究与特许知识保管法》第六条决定。

（四）卡德沃思的教职，由塔林工业大学依本校教师章程与学术纪律程序决定。

（五）各篇的撤稿，由三刊依本刊的办法办理。

七、关于荐稿。《纪要》所登九篇，都由院士阿伯克龙比荐稿。阿伯克龙比与卡德沃思的博士导师是同门。本会查明，九篇的荐书都在收稿以后三日之内写成；阿伯克龙比陈述，他看过提要与结果表，没有看读数，也没有请人复做。本会认定阿伯克龙比事先不知情，不构成学术不端。但荐稿的本意，是荐稿的人读过、信得过；这九篇荐而未读。本会提请学术出版室：荐来的稿件另经外审，荐稿人避开作者的师承。阿伯克龙比已于本月致信学术出版室，自请不再荐稿。

八、复核。卡德沃思不服本决定的，可以在收到本报告之日起三十日内，向学术委员会申请复核，由未参加本案的院士办理。

白银学会学术纪律委员会　主任　彭福尔德（Penfold）
