# 铜线装帧坊工坊学徒契约

立约人：铜线装帧坊，业主奈莉安；工坊学徒泰洛；监护人佩林。

各方于第一纪三百七十四年雷鸣之月一日在恰恩订立本约，确认如下事项。

**第一条 手艺与传授**

本约所称工坊学徒，指在作坊学习装帧手艺，并按约参加作业、领取报酬的人。泰洛随奈莉安学习裁纸、配帖、缝订、封皮与银箔装帧，奈莉安为指导人，布伦纳协助日常指导。压书机等器械的使用须先受教、练习，再由指导人准许参加相应工序。

**第二条 食宿与工钱**

作坊提供约定食宿。工钱以阿根特计，按双方签认的工钱单支付；工钱单与本约一并保存，逐次记明应付、实付与领讫。工票的出具与兑付依《银色联盟非货币票据与互助金机构法》，到期工钱应依约给付。

**第三条 作业与休息**

每日学艺、作业与休息依本约排定，不超过恰恩所定的上限，由奈莉安告知泰洛及佩林；临时调整应说明缘由。指导人准备适用的工具、防护及指导，泰洛依教导操作，发现器械异常立即告知，停止有关工序。

**第四条 工伤与照护**

泰洛因作业受伤，作坊立即安排医治，承担救治费用与治疗期间的生活补助，不问过错，并保存事故记录和医治凭单。恢复期间依医师意见调整作业，其余赔补依《银色联盟契约与赔补法》确定；伤害由他人过错造成的，作坊依法向该人追偿。

**第五条 验艺与出师**

学徒年限依已交各方阅知的工匠行会章程定为六年，传授进度和出师条件也依该章程。指导人应保存完成的作品与学习记录，达到验艺条件时为泰洛向行会申报；出师以行会验艺结果为准，并向工坊凭照局报送师承变更。

**第六条 解约与结算**

一方提出解约，应说明缘由，依行会章程通知对方，并清点作品、工具与应付工钱；作坊解约的，提前三十日通知或者支付三十日工钱。遇欠付报酬、持续拒绝传授手艺或危及人身安全的情形，可依法请求改正、停止有关作业或解除契约。解约时，作坊交还泰洛的私人物品，提供已完成的学艺与作业记录，结清应付款项；有争议的部分另列。

**第七条 争议与存卷**

发生争议，先请工匠行会恰恩会所调解；未能达成协议的，向有管辖权的法庭请求裁判。奈莉安、泰洛及佩林分别留存本约，师承事项送工坊凭照局登记。

业主及指导人：奈莉安（签）  
工坊学徒：泰洛（签）  
监护人：佩林（签）  
立约日：第一纪三百七十四年雷鸣之月一日

**工坊凭照局师承登记存根**

工坊：恰恩铜线装帧坊。指导人：奈莉安。工坊学徒：泰洛。工艺门类：装帧。凭本约登记师承关系，契约副本随谱系卷保存；传授、出师或解约有变，报送有关文书记入原卷。

工坊凭照局（登记印）
