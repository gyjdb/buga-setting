# 公共科研资助年报（第一纪三百七十五年，节录）

工艺与奥术科技部科研资助司　第一纪三百七十五年霜降之月

说明：

一、资助数含线边档抽中的项数。本年线边档七十三项，抽中三十四项；未抽中的三十九项，明年再申请同一研究的，可以沿用本年的外审意见。

二、舰装与引擎门类的资助率最高。节点、结界与魔网的课题，自第一纪一百二十六年起就是本资助的首要门类，额度向来从宽。

三、一般课题的申请，有六百一十二项来自书卷七校，资助一百五十一项，资助率 24.7%；其余五十八所院校、学会、大图书馆与工坊的学者，申请一千三百八十八项，资助二百七十项，资助率 19.5%。

四、本年资助的三项重大课题是：

1. 潮年节点负荷的十二年观测。牵头：联盟节点与结界工程学院；合作：万物之塔学院、塔林工业大学、节点结界工程部。
2. 推演机引文核对的通用办法。牵头：大图书馆；合作：卡奈奇理工学院、恰恩大学。
3. 字码典藏中残卷的推演机释读。牵头：银翼学院；合作：大图书馆、白塔大学。

五、本年申请机房时日的三百一十项中，依第一纪三百五十五年的定例申请第二处机房复核的，有七十四项，全部配给。
