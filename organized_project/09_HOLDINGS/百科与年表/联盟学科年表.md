# 联盟学科年表

**《联盟学科年表》**（Chronology of the Disciplines）　第三十版

白银学会学术委员会编　大图书馆永世回廊校订　第一纪三百七十五年（繁花与夏叶之年）刊行

## 前言

本表初编于第一纪二十七年。那一年白银学会办第一轮学科评定，各评审组要先弄清一门学问从哪里来、走到了哪一步，学术委员会便请各学部与大图书馆永世回廊合编了这份年表。此后每轮评定增订一次，这是第三十版。

一门学问的事情很多，本表只录转折：第一次做成的，第一次证明的，从此改了做法的，以及从遗迹与残卷里找回来、从此读懂了的。

年代以永世回廊的编年为准。混沌纪年一千五百一十六年的大魔潮毁了许多手稿，古典时代的事，年代多只能写到“前后”；再早的事，只能写到时代。

## 凡例

1. 门类的次序依《银色联盟高等院校法》第二十九条：先列以白银学会八个学部为纲的门类，后列史学与典籍、语言、艺术、商贸。
2. 年代写作“混沌纪年某年”“第一纪某年”。已有年名记载的，注在年份之后。地上有的编年接着混沌纪年往下数，第一纪一年在那里记作混沌纪年一千五百一十七年。
3. 成果的年份难以确指的，以得奖之年记。
4. 人名只录有记载的，注所属的院校或者城邦；不知名姓的，写机构或者城邦。
5. “问”指塞弗林二十四问，“七题”指千年基金会的千年七题。
6. 借助推演机取得的成果，在备注中注明；学界尚未验证的学说，也在备注中注明。
7. 依法属于特许知识或者封存的事项，不录。银色十二环诸位的事迹，年代多不可考，又多涉封存，本表也不录。
8. 有的门类之末，列出与本表所录事项相关、至今未解的大问题。

## 法则与真理

这一门问世界依什么规则运行、什么能够证明。法则一支把登塔的领悟写成算式，算学一支沿着塞弗林二十四问一路解下来。秩序的边界也归这一门：火种为什么点得着，过往之壁以外又为什么点不着。

| 年代 | 事项 | 备注 |
| --- | --- | --- |
| 纪元之前 | 据巴贝尔残卷，玛莎降下法则之线，在魔力之海上织成 Tiamat 法典。法则之线显形时，是一条条银色的光链 | 晴天可见横跨半空的白线 |

| 混沌纪年 1000 年前后 | 万物之塔把 Tiamat 的显形列为长期观测：透明的光环、横跨半空的白线、天幕上层层咬合的齿轮纹，何时出现、持续多久，都记入星历 | |

| 混沌纪年 1060 年前后 | 艾尔沃西（白塔学会）用四十年建成法则代数，法则之线可以用一套算式记写 | 问六 |

| 混沌纪年 1200 年前后 | 奥尔丁写下以他命名的猜想：数到任何一个数为止，实际的质数个数与疏密算式之间的误差，不超过大致与所数之数的平方根同一量级的界限 | 问一。近似的规律在混沌纪年 1010 年前后证出 |
| 混沌纪年 1250 年前后 | 蒙克顿（恰恩）证明，在当时形式化的语法里，古典法则代数的每一个式子都能译成字符的组合，反过来不成立：字符的描述力至少不弱于法则代数 | 问十的前半问，白银学会只承认解了一部分 |
| 混沌纪年 1260 年前后起 | 威洛比（白塔）把位面门户用作仪器，连续记录法则运行的轨迹，至今没有中断。在门户监测得到的范围与精度之内，轨迹几乎不变 | 白塔与法则的共振由霍尔布鲁克测明，见封印与位面 |
| 混沌纪年 1340 年前后 | 诺兰证明，凡大于二的偶数都是两个质数之和。手稿毁于大魔潮，证明靠拉塔基的一份副本保全 | 问二 |
| 混沌纪年 1380 年前后 | 白塔学会比对两种火种：德鲁伊根植的原始火种，先断绝一地的魔力与元素，再重写那里的规则；巫师制作的火种，直接重新布置法则。小火种开辟不了秩序之地，只稳得住身边的一小片 | |
| 混沌纪年 1440 年前后 | 彭布罗克证明，三维的封闭位面可以按确定的规则分解成几种标准的几何块 | 问三 |
| 混沌纪年 1455 年（繁茂之年） | 地上的开拓者自 1435 年起，在四方相继点不着火种。永世回廊比对巴贝尔时代的旧图，认定这条看不见的“过往之壁”，正是神民时代玛莎庇佑之地全盛时的疆界：光辉重返之年以来地上的开拓，只是在收复故土 | 见史学与典籍 |
| 混沌纪年 1470 年前后 | 白塔深处的一位领悟者提出七层说：Tiamat 自下而上，三层筛滤、分类与分流魔力，居中的一层承担推演，最上三层是法则层，也就是通常所说的法则之网 | 学说，至今无法以实验验证 |
| 第一纪 290 年（铜钥之年） | 一套不自相矛盾、足以表达自然数算术、规则可以照章列出的体系，不能只凭自身证明自己不自相矛盾。证明找回于巴贝尔残片 | 问四；见史学与典籍 |
| 第一纪 307 年（晨钟之年） | 创盟的第一千年。千年基金会（卡奈奇）公布千年七题，其中五题承接二十四问；解出任何一道，奖金与一届阿伦德尔奖相当 | 至今解出两道，一道解了一半 |
| 第一纪 318 年（浓雾之年） | 卡明斯（卡奈奇理工学院）证明，不存在判定一切符文链能否走完的总判验程序 | 问五；卡莱尔奖章 321 |
| 第一纪 338 年（细雨之年） | 塞尔比（卡奈奇大学）与奥姆斯（图门大学）从法则代数推出魔力交换的最小份额，即“一缕”；此后三年，几所院校用不同的器械独立测得 | 问八；七题之五；阿伦德尔发现奖 341 |

未解：奥尔丁猜想（七题之一）；验证与构造（七题之六）；魔潮方程的解是否永远平顺（七题之四）；第十环的分界（问九，七题之二）；时间术式能否改变它施展以前的事（问十一）；七层说能否验证；过往之壁以外，火种为什么点不着。

## 元素与术式

施法本身的学问：元素、符文、占星、通灵与法阵。九派与十四环都比联盟老；联盟的贡献在于算总账、做预报，并把符文写成可以移植的单元。魔月与潮汐的推算，也在这一门。

| 年代 | 事项 | 备注 |
| --- | --- | --- |
| 敏尔王朝中后期 | 九派的分类形成：法则魔法、元素魔法、弦魔法、巫术、符文魔法、圣言、占星术、通灵术与法阵魔术。各派后来又分出许多支系，大的框架沿用至今 | |
| 厄加图时代 | 十四环的环级体系诞生。法术按力量分为十五环，第十五环属于诸神 | |
| 图门的时代 | 图门，人称元素大帝，创立混沌时代之后的元素法阵。据说他的法阵得自一块战争石板的残片 | 圣纹刻印见工匠法则与造物 |
| 年代不详 | 环之仪式：主持的大导师立于主星之位，借众人之力完成一人做不到的法术或炼金。法阵以星座的坐标标注，常见十六、三十二、六十四人的形制；传送一支舰队，要数万巫师合力 | 高阶的弦魔法也要用它，须十二环授权 |
| 混沌纪年 870 年前后 | 萨克维尔（白银学会）会同各派编成第一部标准术式集：新的术式与同一体系已登记的标准术式在相同的条件下对照施展，作可以复核的环级认定，耗魔照记而不作唯一的依据；施法者要准备停当、休息足够才上场 | 今天的《法术环级标准》由此而来 |
| 混沌纪年 930 年（沙漏之年）起 | 万物之塔的德雷顿把环之仪式里站在星位上的人换成水晶，造出专算历法、轨道与潮汐的星算阵。同一张星历由几座阵、几座观测台交叉核过，“两处各算一遍，对上才算数”的规矩由此而来 | |
| 混沌纪年 980 年前后 | 芬奇确立元素转化的总账：把元素、储能材料、环境与散失都算上，魔力的总账相符 | 问十二 |
| 混沌纪年 1100 年前后 | 奥德里奇（万物之塔）依靠星算阵与几代人的测站记录，写下潮汐方程：十年一潮、百年一次大潮之外，若干分潮与十二轮魔月的周期稳定对应 | 问十三 |
| 混沌纪年 1150 年前后 | 卡奈奇的阵法营造行会改用分块营造：大阵由彼此交叠的标准阵块拼成，检修一块以前先把供能与边界的约束交给邻块，大阵从此可以边运行边检修 | 突发故障的自动接管，要到 1320 年前后的联调 |
| 混沌纪年 1250 年前后 | 风暴王座的元素使提出通道说：元素池是一条通道，法术借它重组天地间游离的元素，并不真正消耗；只有十环以上的法术，才动用元素使自身的储备 | 学说 |
| 混沌纪年 1270 年前后 | 梅特卡夫的元素亲和表：按实测的火、水、风、土四种亲和的比例，排列已知的材料与晶体。有几种比例，照法则代数算得出能成晶，却只在别样的法则环境里才稳得住，表上留作空格。此后两百年间，坠落的莎拉之泪里与古代器物上陆续见到这几种晶体，取出来都放不久；成晶要什么样的法则环境，从此成了一门学问 | |
| 第一纪 40 年代 | 万物之塔比对大魔潮以前几十年的星历与测站记录，认出大魔潮的几种先兆。此后每年沉眠之月末日，联盟随来年的年名一并公布大魔潮的预警 | |
| 第一纪 200 年前后 | 阿什比（翼狮城）定下通用的符文单元，以及串接、分岔与回环的规则。术式从此可以在不同的演算机与魔枢之间移植，常用的术式库可以复用 | 阿什比奖纪念他 |
| 第一纪 265 年前后 | 达比（万物之塔学院）的归纳术式：演算机从几百年的测站记录里自己找出潮汐表的修正项；修正项要用没有参与归纳的新记录检验，预报得准才采用 | 后来推广到星历、病历与工坊的留痕 |
| 第一纪 298 年（晴空之年） | 玛达拉以南的星坠之灾。银烛会与万物之塔把这几年莎拉之泪坠落的次数、秩序边境魔力风暴的汇聚与 Tiamat 节点的位移放在一起比对，列为大魔潮的候选先兆 | |
| 第一纪 350 年前后 | 大图书馆的字码典藏里，有魔力的符形只存代号，读一卷残书，要把代号、失能的转写与施法留痕对起来。林恩（卡奈奇理工学院）照七层说里分流一层的样子写出照应术式：符文链读到一处，能在很长的文字与复杂的符号里找出与它相关的各处 | 阿什比奖 352；推演机由此而来 |

未解：大魔潮能否可靠预报，星历看得出先兆，潮汐方程还算不出它；魔月是潮汐的因，还是与潮汐同为魔力之海的倒影。

## 工匠法则与造物

把法则刻进器物的学问。圣纹刻印、炼金、魔偶与魔枢都比联盟老；联盟把它们变成了可以计算、可以复制、可以担保安全的工业。

| 年代 | 事项 | 备注 |
| --- | --- | --- |
| 年代不详 | 布加以魔锻法锻造，不用火炉。敏尔人的元素锻法，在圣者之战以前已经失传 | |
| 混沌纪年 471 年（月暮之年） | 图门发明圣纹刻印，解开了给魔法物品注入第二级力量的难题。哈泽尔人魔导技术最早的概念也出自他 | |
| 圣者之战中前期 | 今天的炼金术与魔偶技术产生。石像鬼成为布加的基础战争造物，由黑檀木护符控制，一座巢穴每年只出两只；另有钢铁傀儡与钻石傀儡。更古的泰坦巨像，造法已经失传，现存的都是古物 | |
| 圣者之战末年 | 布加的工匠巫师为转化琥珀原石的力量，设计出魔枢的雏形，战后定型，把储存的能量转成稳定的输出。琥珀原石从索米尔原矿中分离，与金、银、铜伴生。此后的浮空城与舰船都靠魔枢驱动，燃料又添了元素水晶与魔核。大陆各大帝国的王室，后来也秘密掌握了这门技术 | |

| 混沌纪年 1050 年前后 | 工匠巫师仿照高阶的风元素生物，造出大气神盾 | |

| 混沌纪年 1490 年前后 | 里弗斯（卡奈奇）使耗尽的魔核重新充满。回充要耗用外来的能量，有损耗，次数有限 | 问十七 |

## 舰装与引擎

城体、引擎与船的学问。一座浮空城首先是一件造物；这一门的主线是冗余：坏了一处，城不能掉下来。托力的链条最前面是 Tiamat 的法则之线，这一环不归匠师管，只能假定它始终如一。

## 封印与位面

封住不该放出来的，造出原本不在的。白塔是这一门最大的作品；封印要年年照看，是这一门最要紧的结论。

## 博物与生命

活物、资源与医。白银之民不染凡俗的疾病，医学管的是法力池、魔力侵蚀、魔物毒与晶化；疫害伤的是城里的凡人与混血居民、牲畜、作物与浮空生物，而且随潮汐起落。

| 混沌纪年 1080 年前后 | 埃尔斯沃思（恰恩）解剖几百具遗体，看到一层遍布全身、死后很快消散的极细脉络，推测它就是法力池 | 二百五十年后由霍尔特证实 |

## 度量与标准

秤、尺与“算不算数”。联盟的老规矩：同一件事，两处量，两处算，对上了才算数；后来又添了两条：两处要各自独立，量出来的数要注明误差。

## 盟约法学

布加的法从誓约来，先有誓，后有法。断案时，最难造假的证据放在最前面。

| 年代 | 事项 | 备注 |
| --- | --- | --- |
| 混沌纪年 712 年（白石之年） | 曼克托尔誓约刻上圣白之碑。按碑上的盟约，弦魔法不得轻易用于攻击其他种族；这一条至今仍管着天上的巫师与大陆上的巨龙 | |
| 混沌纪年 824 年（光辉重返之年） | 奈塔斯创盟誓约，颁布银章 | |

| 混沌纪年 1130 年前后 | 裁断以施法留痕为第一等的证据：留痕带着施法者独有的魔力纹样；魔石留得住数十年的影像，显影水晶录得下几段三五分钟有声的影像，都可以当庭回看。采集的地点、时刻、经手的人与保管的经过都要记明，有争议的可以另请一城复验；书证、物证与留痕交叉验证，证言只作辅助，单凭证言不定禁术与遗产的重罪 | 霍顿主持修订证据的规则 |
| 混沌纪年 1200 年前后 | 裁断从议会分出，设立独立的裁断庭：裁断官经两院确认，任期之内不受议会、行政机关与城邦的干预；强制执行另设机构，与审理分开 | 起因是 1190 年代一座城邦与联盟的航道税之争 |
| 混沌纪年 1280 年前后 | 莫布雷（卡奈奇）著《城邦与联盟》：城邦自管本邦的事务；联盟依银章与据此制定的法律行使共同的事权，事权跨城、城邦力所不及，不是哪个机关自行取得权限的根据；冲突由裁断决定 | 银章第八条与内务治安部的“补位不替位”出自这一学说 |
| 第一纪 1 年（启示之年） | 光明圣堂威胁男巫不得参与圣战；联盟以三座浮空城回敬，向教皇宣读十二则条文 | 宪章第十三条“对外惩戒与条文宣读”的著名先例 |
| 第一纪 331 年（火漆之年） | 奥克斯利（卡奈奇理工学院）的留痕签记：魔力纹样，上位的法则模拟得出来；签记把每一道留痕与施法者不可逆的算学签记绑定，在现有的算法与演算机算力下无法伪造。此后裁断采信留痕，先验签记 | 阿什比奖 |

## 史学与典籍

这一门起于一场损失。它的事是三件：找回来，校得准，排得对。

| 年代 | 事项 | 备注 |
| --- | --- | --- |
| 纪元之前 | 奥奇杜学者守护巴贝尔通天塔的白银图书馆，掌管数万年来诸文明、诸种族以及神民与神的知识 | |
| 巴贝尔毁灭以后 | 白银图书馆湮灭，典籍散落于大地与元素疆界。整理与保存从此变成寻找与回收 | 史家称为文明之黯 |
| 年代不详 | 白银之民流落大地以后，在恰恩仿建大图书馆，沿用白银图书馆的旧名 | |
| 混沌纪年 1120 年前后 | 永世回廊的雷德芬以年数、年名与共同的事件互相核对，校正地上诸国与诸圣殿旧编年里缺漏的年数、误抄的年名与互相冲突的次序。地上沿海的水手历以盾之月在前半夜升起的月份为岁首，对勘以前先换算岁首 | |
| 混沌纪年 1150 年前后 | 惠特克的版本谱系法：有魔力的符形，抄书人常有意改成失能的写法，所以异文有三种，抄错的、改写的、为了安全而失能的，要先对照施法留痕分清；再据各个抄本共有的讹误，重建一部书的主要抄传支系，上溯祖本；抄本互相校改、支系杂糅的地方，异文并存，不强定一是。恰恩的抄书坊从此按谱系校书 | |
| 混沌纪年十三世纪 | 永世回廊定下考订史料的规矩：同一件事，编年、条约、往来的文书与实物互相比较；分清事件发生、材料形成与后来抄写的时间；抄自同一来源的几份只算一份见证 | |
| 混沌纪年 1455 年（繁茂之年） | 永世回廊比对巴贝尔时代的旧图与地上开拓者点不着火种的地点，认定过往之壁就是神民时代玛莎庇佑之地全盛时的疆界 | 见法则与真理 |
| 第一纪 9 年（灯芯之年） | 大魔潮以后，卡奈奇大学、白塔大学、恰恩大学、万物之塔学院与星月学院订立书卷之约，合力抄补散失的典籍，并清点二十四问：哪些证明已毁，哪些靠别城的副本保全 | 书卷联盟由此结成 |
| 第一纪 40 至 175 年 | 大图书馆把馆藏编成演算机能读的字码，做目录、比异本、整理公式。有魔力的符形不照录，检索用不带魔力的代号；原文、转写与能施展的术式分开存放，编进目录的书，馆藏等级照旧 | |
| 第一纪 290 年（铜钥之年） | 大图书馆把一卷回收多年的巴贝尔残片降级释出，校订的斯塔福德（恰恩大学出身）发现上面有问四的完整证明 | 巴贝尔奖章 294 |

## 语言

在这个世界，文字不只是记号：最古的符文本身蕴含魔力。语言之学一半是史学，一半是法则学。

| 年代 | 事项 | 备注 |
| --- | --- | --- |
| 最早的时代 | 原始符文。符文本身蕴含魔力，最初的文字都由它脱胎而来 | 如今通晓原始符文的，据说全联盟不过十人 |
| 纪元之前 | 约两万年前，一种形声的古字符突然传遍大陆 | |
| 年代不详 | 女巫的传统：三万六千个字符足以描述一切可以描述的法则。符文魔法与圣言的许多理论建立在这些字符上 | |
| 混沌年代以来 | 文字的魔力以混沌年代为分水岭，逐渐减弱：有些比女巫文字更古的符文支系已经失能，如今只用来储存信息；原始符文仍然蕴含魔力。风族语是仅存的几种带魔力的文字之一，风暴使节必修 | |
| 混沌纪年 1180 年前后 | 罗克斯伯勒（恰恩）写成第一部字符语法，分清“合法”与“有效”：合法是组合合乎规则、解析得出确定的含义，有效是带魔力的实际符形施展得出 | 后来的形式化研究都从这部语法起步 |
| 混沌纪年 1230 年前后 | 卢埃林比对各族文字与符文的对应规律，排出文字的传承谱系：各族的文字都可以上溯到原始符文的几支古写法。他在书里先说明，文字同源，不等于语言同源 | |
| 混沌纪年 1400 年前后 | 通言塔阁的斯特拉顿汇校馆藏的《苍之诗》各种译本，编成对照本。原本在世界之环的万物大厅，不在联盟 | |
| 第一纪 345 年（石楠之年） | 梅瑞克（星月学院）证明，三万六千个字符里有十几个多余的字符，在一切合法用法里都能由别的字符组合替代 | 问十的一半；七题之三；卡莱尔奖章 345 |
| 第一纪 354 年（蕨叶之年） | 阿普尔比（银翼学院出身，任职于大图书馆）借推演机比对巴贝尔遗殿的全部残片，证明“第三种文字”是三万六千字符的一种古写法 | 问二十四；推演机协助；巴贝尔奖章 354 |

未解：三万六千个字符是否足以描述一切可以描述的法则（问十的另一半，七题之三）。

## 商贸

计价、分摊与发券。商贸之学到第一纪才有自己的理论，起因是一场停供。

| 年代 | 事项 | 备注 |
| --- | --- | --- |
| 混沌纪年 824 年（光辉重返之年） | 定阿根特为联盟的计价单位，一阿根特等于一百星 | |
| 混沌纪年 900 年前后 | 哈蒙德（卡奈奇）提出共同义务的算法：按各城从公共航道得到的收益，与为舰队护航、公共结界维护、回收远征担负的成本，分摊联盟的开支 | |
| 混沌纪年 1240 年前后 | 联盟开始发行银券，见券兑付阿根特铸币，以白银十足准备 | |
| 混沌纪年 1310 年前后 | 联盟财政分为三本账：航权与公共工程、军备与军工、遗产与封存，分别编列、核算，按法定的用途支出；涉及几类用途的项目事先分摊，不得事后换账 | 起因是护航的开支几次挪用遗产回收的拨款；银章第三十四条 |
| 第一纪初年 | 大魔潮毁坏的节点修复以前，许多城的工坊停工，工票与仓储凭证一度被当作钱流通；发票的工坊停了工，仓里的货受了损，这些票便大幅折价。“钱是钱，票是票”的规矩由此而来：票可以转让、抵押，却没有人必须把它当钱收 | |
| 第一纪 238 年（冻泉之年） | 斯坦霍普论停供：一处节点停供，缺魔力的工坊开不了工，这是停供本身；有魔力的工坊也因收不到货款而停工，人们又囤积银券，损失就传到没有停供的城，比停供本身大得多。前一种要靠修复节点、调配备用的魔核来缓解，城体保底的储能却一分不能挪去开工；后一种可以救：停供期间储备院收贴合格票据，联盟以共同工程雇用停工的工匠，先修节点 | |
| 第一纪 246 年（银鳞之年） | 银券的发行准备改为白银不低于四成，其余以联盟公债与合格票据充抵 | |
