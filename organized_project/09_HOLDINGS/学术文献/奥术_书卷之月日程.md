# 书卷之月日程

《奥术》第一百七十二卷第三十一期　第一纪三百七十五年（繁花与夏叶之年）流火之月

下月是书卷之月。本刊照例把这一个月里学界的活动排成一表，供读者安排行程。本年没有卡莱尔奖章（下一次在三百八十一年），也没有巴贝尔奖章（下一次在三百七十八年）。

| 日期 | 事 | 地点 |
| --- | --- | --- |
| 一日 | 白塔敲钟三十六下，书卷之月开始；白银议会书卷会期随钟声开启；学习者绕大理石广场“钟声跑” | 白塔城邦 |
| 一日起 | 白塔大理石广场的公开考校；各校学士结业大考；书卷联盟七校的联合考校 | 白塔城邦与各城 |
| 本月内 | 各校选任组议聘 | 各校 |
| 十二日 | 白银学会公告第三十轮学科评定的结果，此后六十日为复核期 | 卡奈奇 |
| 十八日 | 温特沃斯坐满三十六年，在卡奈奇大学大讲堂让出塞弗林讲席，作让席讲演 | 卡奈奇 |
| 二十一日至二十五日 | 学部年会与四门联合年会，见下 | 九城 |
| 二十一日至二十五日 | 公共科研资助的十二个评审组闭门会评，各在本门类年会的所在城 | 九城 |

本年的学部年会与四门联合年会：

| 年会 | 做东的城 | 承办 |
| --- | --- | --- |
| 第一学部（法则与真理） | 白塔城邦 | 白塔大学 |
| 第二学部（元素与术式） | 奥图 | 奥图大学 |
| 第三学部（工匠法则与造物） | 卡奈奇 | 卡奈奇理工学院 |
| 第四学部（舰装与引擎） | 塔林 | 塔林工业大学 |
| 第五学部（封印与位面） | 埃斯卡隆 | 星月学院 |
| 第六学部（博物与生命） | 德罗拉 | 德罗拉医学院 |
| 第七学部（度量与标准） | 瓦伦 | 联盟计量学院 |
| 第八学部（盟约法学） | 翼狮城 | 萨萨尔德大学 |
| 四门联合年会（史学与典籍、语言、艺术、商贸） | 恰恩 | 恰恩大学、大图书馆 |

各年会公开的宣读与辩论，照例经传声网转播至别城的讲堂，时间见各城讲堂的告示。持与会附记的凡世学者，只进公开场次，入场时出示通行证。
