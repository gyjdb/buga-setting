# 年名提案

> 提案 · 2026-11-03 · 第一稿。D103 定下年名的规矩：年名是预言，由万物之塔依星象推定，每年沉眠之月末日以联盟的名义宣布来年的年名；原著的年名都可以拿来用，不必与原著的年份完全对上。D110 以来的待办里有一项是“给重要的年份定年名”；D112 采纳十二环法术学会，说它在七色之年解散，年份“到年名一项再定”。本稿给混沌纪年与第一纪的四十七个年份定下年名，其中二十四个是原著的名字，二十三个是新拟的；七色之年定在第一纪 296 年，风土志序里有一处出入请作者定（第四节）。
>
> 已采纳（D114，2026-11-03）：作者答复“取甲，改作“长期””，其余各节没有提出异议。年名照第二、三节，七色之年是第一纪 296 年；第四节取甲，风土志序与编者材料里的“一直”改为“长期”；《联盟学科年表》写确切年份的条目注上年名。设定记入 D114，现行正文不改。

## 一、取名的办法

1. **已定的照旧。** D103、D112 已经定了年份的，以及原著给了年数、又在今年以前的，共十六个，照旧用：混沌纪年的君（327）、月暮（471）、光辉重返（824）、亡月（1437）、繁茂（1455），第一纪的启示（1）、分立（100）、实穗（279）、雷霆（312）、垂变（320）、星聚（321）、蓖麻（325）、穴兽（342）、呼啸（350）、丰获（360），以及今年的繁花与夏叶（375）。丰获是这次核对原著时找到的，原著写作“丰获之年（1st.360年）”。
2. **原著没给年数的，推得出年代就用。** 苔、马齿苋、耀金、终结、七色、光耀、朔花、柱八个，按原著的上下文放在推得出的年份上，理由见第六节。
3. **其余重要的年份新拟。** 重要的年份取三类：《联盟学科年表》里写到确切年份的条目，D103 的纪年锚点，D109 的高等院校年份。“前后”“年代”一类的约数不定年名。新名照原著的样子，取一个草木、鸟兽、天候或器物的意象，以两个字为主；不用十二个月的月名，不用原著留在今年以后的名字，同一纪之内不重复。
4. **大多不写应验。** 年名是前一年末依星象推定的，与当年的事大多看不出关联。表里只在三处写后世的读法：应验的白石与终结，与当年正相反的晴空。D103 已举的光辉重返、启示与繁花与夏叶照旧。

表中标“地上”的，是原著记下的地上诸国的事，供对照。

## 四、七色之年与图拉曼

D112 采纳的十二环法术学会，专研十二环法术，曾是布加最高的学术团体之一，在七色之年解散；最后一任银色首领是图拉曼，学会解散以后，他离开卡奈奇，回到地上隐居。学科史词条第二批照此写了一句，年份留到这里。

**年份。** 本稿定为第一纪 296 年，在今年以前七十九年。风土志第六章说图拉曼“在取得环席以前，长期生活在埃鲁因”：学会解散以后他回到埃鲁因，到取得环席要隔很长一段年月，七色之年就要离今年足够远。原著里的图拉曼是须发皆白的老者，七十九年前已是学会的首领，也说得通。学会为什么解散，原著没有写，本稿不拟。

**一处出入。** 风土志的序是图拉曼自述：“取得环席以前，我一直住在埃鲁因，不在任何一座浮空城。”编者材料第一节也写“此前一直住在埃鲁因”，第二、三节照引。D112 说他在学会解散以后才离开卡奈奇，那么此前住在卡奈奇，与“一直”不合。作者 2026-09-21 补充的原话是“取得环席以前长期生活在埃鲁因”，同日亲自改写第六章，写的也是“在取得环席以前，长期生活在埃鲁因”。

- **甲（推荐）：** 序与编者材料第一、二、三节的“一直”改为“长期”，与第六章和作者原话一致。图拉曼做学会首领时住在卡奈奇；七色之年学会解散，他回到埃鲁因，此后长期住在那里，直到取得环席，今天仍是埃鲁因王家图书馆的馆长。改后的序与作者亲手改写的第六章说法一致，“不在任何一座浮空城”说的是取得环席以前那一长段年月；第六章本来就是“长期”，不用改。
- **乙：** 序不改。学会设在卡奈奇，图拉曼一直住在埃鲁因，按会期上卡奈奇；学会解散以后就不再去。D112 的“离开卡奈奇，回到地上”，读作离开学会，从此不再上天。

### （三）不取原著所记之事的

- **辉耀。** 原著把它放在繁茂之年以后不久，说白银之民在这一年遁世。D112 不采纳这件事，可否作为最低接触原则的来历留待以后再议；辉耀一名也就暂不落位。
- **更替。** 原著说这一年炎之王吉尔特率领人类穿过大平原，抵达奥索帕鄂，是凡世的开端。风土志编者材料（FB10）定的是一位先知带领敏尔人穿过大平原、建立敏尔帝国，凡人纪元由此开端，两处不合。更替一名以后可以另用，不取原著这件事。
- **龙惧、坠星、圣贤。** 原著里都在敏尔王朝或更早，推不出混沌纪年的年数。
- **龙坠。** 风土志第五章已经用过（班西亚人在龙坠之年追随萨萨尔德人），年份不定，本稿也不定。
- 原著另有两处与已定的年份不合：一处说繁茂之年在今年以前三百五十年；一处把亡月之年写作“第一纪亡月之年（Chaos.1437）”。照 D112 与混沌纪年的年数，不改。

## 六、编者说明

### （一）推定年份的八处

- **苔（混沌纪年 1428 年）。** 原著说黑剑壁垒“最早始建于混沌纪元的苔之年，在第一纪元开始时落成”，又说“苔之年前后人类就几乎将秩序之地扩张到了极限”。开拓自 1435 年起碰壁，苔之年在此前不久。
- **马齿苋（1435 年）。** 原著说“马齿苋之年前后，接下来就是一连串无法预计的失败”，即 D112 所定开拓者碰壁的 1435 年。亡月之年（1437）以后五年处处碰壁，二十年后的繁茂之年（1455）有了定论，前后相合。
- **耀金（812 年）。** 原著说“自从耀金之年以来最后一支敏尔人氏族退入大冰川以后，事实上世人就再也没有见过这些‘先民’的身影”。风土志第七章说圣者之战“终结了敏尔人的黑暗统治”，又说敏尔人曾征发人类修筑冰川上的要塞群，残部退入大冰川与此相合。本稿把耀金之年放在战争结束的一年，并采用退入大冰川一事。
- **终结（1516 年）。** 原著只说一处崇山圣所“在终结之年以前”还有神官驻守，后来遗失已久，与一场大灾相合。年表记第一纪四十年代万物之塔比对大魔潮以前几十年的星历，认出大魔潮的几种先兆：1515 年末推定“终结”的时候，星历里已经有了先兆，只是当时没有人认得，后世因此说它应验。
- **七色（第一纪 296 年）。** 见第四节。
- **光耀（315 年）。** 原著说这场圣战“开始于光耀之年，前前后后持续近半个世纪”，最后七年是十一月战争；另一处又说第二次圣战在星聚之年结束。D112 定为约在第一纪 315 年前后开始，到穴兽之年前后告一段落，本稿取 315 年；持续近半个世纪、在星聚之年结束两说都不取。原著第五卷第五十五幕在圣者之战与这一场之间，另列一场混沌纪年末期为开拓荒野打的圣战，所以称这一场为第三次；风土志没有写那场开拓战争，照 D112 称第二次。
- **朔花（358 年）。** 朔花之年是原著女主角芙雷娅出生的年份；她在开篇时是布契民兵的分队长，还是个少女，本稿取 358 年。朔花也是月名；新拟的名字才避月名，原著的名字照用。
- **柱（374 年）。** 原著说洛茵、班罗尔、卡拉斯等地的流民暴动遭帝国与炎之圣殿镇压，“直到柱之年前后才逐渐恢复了生气”；斗篷海湾之灾在 358 年。本稿取 374 年，即去年。

### （二）新拟的名字

新名二十三个，大多与当年的事无关。有几处可以附会，如书卷之约的灯芯、传声网的归雁、留痕签记的火漆、“一缕”的细雨，表里都不写成应验。白石另有一层：原著说圣者之战的盟约签在“今天的白石之野”；风土志写作曼克托尔的原野，本稿不改地名。原著有一个白鹭家族，所以第一纪 27 年不用白鹭，改用苇莺。
