# 布加风土志（试写）

> 提案 · 试写片段 · 2026-09-21 · 用于确定叙述声音，不替代《银色联盟设定导读》草稿

布加巫师联盟，通称银色联盟，是一个建在天上的国度。它由约三十座浮空城邦组成，每一座都是悬在空中的城市，分布在沃恩德不同地区的上空：有的在萨萨尔德地区之上，有的在亡月之海的上方。联盟的中心，是首府卡奈奇、白塔城邦与恰恩三座城组成的核心城邦群；整个浮空城群的最高处，则是白塔城邦上空的一座潮汐观测塔。布加人在地面上也保有一些据点和领地，但构成这个国家的，始终是天上的城：联盟的正式成员，全都是浮空城。

一座浮空城，首先是一件需要时时照看的巨大造物。城体装有引擎与悬浮阵列，外面罩着城体主结界。这道结界一刻也不能中断，每座城邦都要安排人手昼夜维护；引擎有专人守护，四周的空域有哨所警戒，一旦有敌人或魔物登上城体，另有应急的队伍处置。城邦可以移泊，也可能坠落，对这样的城来说，坠落是一种需要预先防范、事后追查的事故。城与城之间，靠航道与空港往来。天空在这里也有它的地形，需要测绘，需要设置航标；航道上要防备的，是风暴、乱流、魔力潮汐和云海的气象变化。云海里栖息着浮空的生物，也有自己的资源，其中一些地方禁止开采，滥采的人会被追究。

住在这些城里的，主要是布加人。他们属于白银之民，与银精灵同为白银之民的代表，也是联盟的主体民族；此外，城中也有混血者与妖精，他们同样可以成为联盟的公民。布加是沃恩德最富有的国家，几乎什么都不缺。水和食物可以用魔法生产，建造房屋时，魔法可以代替大量的人工。这种富足也有边界：魔法不能凭空造物，总要有原料；普通的白银也无法用魔法廉价取得，所以布加的货币仍然以白银为准备。衣食既然不成问题，一个布加人真正缺少的，就是知识、获取知识的途径，以及能力。

在众多城邦中，有三座与布加的知识传统关系最深。卡奈奇与白塔被视为布加正统传承之所系，合称“秘银学会”。卡奈奇是首府；白塔城邦是白塔奥维利亚的所在地，这座白塔是布加人依照先祖的记忆与残存的建造法则仿建的，塔名取自要素五境中的法则之塔，相传玛莎在那座塔里写下了一切真理与法则。第三座是恰恩，联盟的大图书馆就设在这里，沿用的是巴贝尔白银图书馆的名字。布加人的先祖奥奇杜学者，正是巴贝尔通天塔的图书馆管理员；巴贝尔毁灭之后，塔中的典籍散失于大地与元素疆界之间。把它们找回来，至今仍是联盟三项使命中的第一项。

## 编者材料（不属于正文）

**本次调整**
- 每段只讲一件事：国度的位置与形态 → 浮空城的维护与航行 → 居民与富足 → 与知识传统关系最深的三座城。
- 第一段删去了缓冲区和出入许可，只保留少量城名作为方位参照。缓冲区和布加对地上的态度，留到后文写联盟与地上的关系时再讲。
- 第二段不再点出负责这些事务的机构名称，改写为城邦生活本身需要做的事。
- 第三段删去了对地上之民的态度与最低接触，只写居民与富足。

**作者的概括与判断（有事实依据，不属于新设定）**
- “分布在沃恩德不同地区的上空”：依据萨萨尔德、亡月之海两例和台网分区表所作的概括。
- “构成这个国家的，始终是天上的城”：依据是正式成员全为浮空城，地面据点不算成员。
- “坠落是一种需要预先防范、事后追查的事故”：依据是联盟为城体设立检验机构，并设有坠落事故复盘机构。
- “天空在这里也有它的地形”：依据是执政院下设“天空测绘与航标研究院”，负责天空地形、浮空航路与航标体系。
- “衣食既然不成问题，一个布加人真正缺少的，就是知识……”：概括自“什么都不缺，对个体来说缺知识、获取知识以及能力”。
- “有三座与布加的知识传统关系最深”：卡奈奇与白塔是正统传承所系，恰恩是大图书馆所在地，这是按事实所作的组织性判断。

**回查结果：云海与银材、魔核**
- 上一版写“云海出产银材与魔核”，**没有直接依据**。执政院“云海资源与生态部”的职掌是“银材、魔核、云海资源、矿脉、浮空生态与禁采区管理”，几项是并列的，并没有说银材、魔核出自云海。
- 本版只写有依据的内容：云海有浮空生物与资源（云海生态与资源调查院）；设有禁采区（同上）；滥采可被追究（盟约监察院组织法第十条，“云海资源的滥采”可提起公益诉讼）；云海气象属于航道预报的内容（航道气象与风暴预报台）。
- 城体只写“装有引擎与悬浮阵列”，不涉及城体为何能浮空。
