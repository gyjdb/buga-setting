# 《联盟学术名篇》篇目与排印本

《联盟学术名篇》（Classic Papers of the Silver League）是这个世界里的一部选本，恰恩大学出版部编，第一纪三百七十五年修订本。它选录联盟学问史上改变了一门学问问法的论文二十篇，从混沌纪年 824 年塞弗林的《二十四问》，到第一纪 360 年卡明斯的《推演机与领悟》。每篇前有编者的题解，后附一篇相关的短文；照编选说明第七条，各篇以发表先后为序。

## 排印本

- [联盟学术名篇.pdf](联盟学术名篇.pdf)：中译本合订一册。书名页、编选说明与目录之后是二十篇，正文页码连续，每篇从单数页起；书签按混沌纪年、第一纪分组。
- `原刊/` 下的二十份 PDF：各篇的英文原刊，照原作当年所在的刊物排印，前附单行本封面，页码照原刊；文件名前的序号即本册的篇次。

两种排本的文字相同，取自 02_PROPOSALS 各批的提案（中译、题解与附）与英文原刊。现实论文的对照、新定的设定与审稿的取舍，记在各批提案第二节的编者说明。

## 排印

PDF 用 Typst 排印，脚本在维护者本地的 `tools/paper_pdf/`，不随公开仓库发布：`make_papers.py` 逐批排出单篇，`make_volume.py` 照上表的次序合订中译本、给英文原刊编号，写入本目录。PDF 里嵌的是所用字体的子集。提案或英文原刊改动以后重跑 `make_volume.py`，它会核对上表的合订本页码。
