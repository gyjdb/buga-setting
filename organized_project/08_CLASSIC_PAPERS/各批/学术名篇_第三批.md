# 《联盟学术名篇》中译（第三批）

## 一、《联盟学术名篇》（第三批）

**《联盟学术名篇》**（Classic Papers of the Silver League）　恰恩大学出版部编　第一纪三百七十五年修订本

### 编选说明

一、本册选录联盟学问史上的名篇，供各门类的学士研读原文，也供一般读者查考。选录的标准不是篇幅，也不是后人引用的次数，而是它有没有改变一门学问的问法：读过以后，同行不能再照旧提问，或者从此都用它的办法。依这条标准，有的名篇只有十几页，有的结论已被后来的研究推进，也照样收入。

二、每篇之前有题解，记作者、刊处与写作的缘由，概述论证，并记此后的反响与订正。题解是编者的话，正文是作者的话，二者分开排印。

三、第一纪的论文照原刊录入，只改排印错误；作者后来自行订正的，正文照订正本，并在题解中说明。古典时代的论文原用古典通用语写成，今用编者的今译，篇题、节次与表格照原刊。原刊的页码与眉题不录。

四、正文中圆括号内是作者的原注，［］内的数字是原刊的引文编号；【】内是编者注，说明古今名称的变化，或者后来的订正。

五、依《银色联盟魔法基本法》第九条与第二十八条，弦术的施法要领不予刊布；依《银色联盟学术研究与特许知识保管法》第十五条属于特许知识的内容，也不录。删略之处都注明。

六、有的篇后附一篇与它直接相关的短文，如同时代的回应、作者的订正，或者第一份独立的复核，以见一篇论文是怎样被学界接受的。

七、各篇以发表先后为序。

#### 题解

塞弗林，恰恩的学者，生卒年与师承都已不可考。混沌纪年 824 年（光辉重返之年），奈塔斯创盟，同年白银学会召开第一次全体大会；大会最后一日，塞弗林登台宣读了二十四个问题。这些题目原本散见于各城与各学派的往来信札，由他一手拢集并排定次序，学界自此称为“塞弗林二十四问”。本篇是那次宣读的全文，载《白银学会会刊》第一卷，即第一次全体大会的纪事；会刊当时还不分辑。原文用古典通用语，这里是编者的今译，篇题、问次与表格照原刊。

那时圣者之战结束才十二年，各城的学者大多忙于寻回和校订战火里散失的残卷。塞弗林在篇首说：“先祖守着巴贝尔遗下的典籍，可找回来的旧书终归有翻尽的一日，前人未曾动笔的空白，总得由后人接续。”这句话后来被反复引述。他为列入的问题定了五条：要问得清楚；要难，但不能无从下手；答“不能”也是答，摸清哪条路走不通，本身便是学问的分内之事；答案要写得让别城的学者核得过；宁可一问拆成几问，不要几件事揉成一问。二十四问里，第四、第五、第十八与第十九问后来给出的，都是“不可为”的界限。篇末的请求是答案抄两份、存两城。大魔潮毁了许多手稿，诺兰证第二问的亲笔稿也在其中，靠拉塔基的一份誊录副本才保全下来。

宣读时的问法许多颇为粗疏，经几代人推敲，才渐渐收束为精确的命题。第四问后来问的是：任何一套足以表达自然数算术、推演规则可以照章列举的体系，若自身不自相矛盾，能否仅凭内部规则自证其无矛盾。第五问难在“法”字没有确切的意思，此后九百年间无从下手，后来收束为：对理想化的通用符文链，是否存在能判定它是否终将停机的总判验程序。第八问宣读时只有一句。第二问出自恰恩一部旧抄本页边的一行小字，后来摘得首届蒙塔古奖的长篇小说《抄书匠》，敷演的便是这段页边轶事。第一问所附的十万以内的质数表，是恰恩抄书匠手算的；星算阵造出以后，质数表才数到更远。

一千多年过去，二十四问已有十九问得出定论，两问解开半程，三问依原样悬置。古典时代解出十三问：第二问（诺兰，1340 年前后），第三问的三维情形（1440 年前后），第六问（法则代数，1060 年前后成形），第七问（韦斯特法尔的分层说，930 年前后），第十二问（芬奇，980 年前后），第十三问（奥德里奇的潮汐方程，1100 年前后），第十五问（魔网联调，1320 年前后），第十六问（格兰维尔，1460 年前后），第十七问（里弗斯，1490 年前后），第十九问（奥斯本，1390 年前后），第二十问（塔尔博特，1410 年前后），第二十一问（1190 年前后证实若干烈性疫害出于微魔；白银之民为何不染，至今未明），第二十二问（霍尔特，1330 年前后）。五维单连通位面的分类，由白塔大学的温德尔在第一纪完成，249 年获卡莱尔奖章。第一纪解出六问：第四问（290 年），第五问（卡明斯，318 年），第八问（塞尔比与奥姆斯，338 年），第十四问（洛温，30 年前后），第十八问（哈尔丁，358 年），第二十四问（阿普尔比，354 年）。解开半程的是第十问与第二十三问：梅瑞克在 345 年证出有十几个多余的字符，字符体系是否完备至今未证，只有蒙克顿 1250 年前后的部分结果；佩恩的制剂只治一类常见的损伤，318 年获温斯洛奖。未解的是第一、第九与第十一问；第一问的近似规律在 1010 年前后由克罗斯利证出，精确的误差即奥尔丁猜想，见本册奥尔丁一篇。

第四问的解答并非出自布加学者：第一纪 290 年，大图书馆降级释出一卷入库封存多年的巴贝尔遗殿残片，负责校订的斯塔福德从中读出了完整的推导。第一纪 9 年订立书卷之约时，五校合力把二十四问清点过一轮，本篇后附这次清点的节录。第一纪 307 年创盟千年，千年基金会公布千年七题，其中五题直接承接二十四问里未了的题目，即第一、第八、第九、第十与第十八问；另两题由第十三问与第五问的研究衍生而来。

#### 正文

**二十四问**

塞弗林

（混沌纪年八百二十四年，即创盟之年、光辉重返之年，白银学会第一次全体大会最后一日宣读）

诸位同道：

大会今日散会。开会以前，学会托我把各城、各学派这些年往来信札里提到的难题拢在一处，排个次序，在散会前念给诸位听。我拢了半年，删去重复的，把问的是同一件事的并成一问，剩下二十四个问题。念以前，我想先说几句：为什么要念它们，又为什么这样念。

我们这一代人做学问，多半是在找回来的旧书上做的。圣者之战打了一百年，许多城的书库烧了，许多抄本散了。战后这十二年，诸位和我一样，一城一城地去找，一卷一卷地拼，把残卷照巴贝尔留下的体例校齐。这件事还没有做完，也一定要做完。可我常想：先祖守着巴贝尔遗下的典籍，可找回来的旧书终归有翻尽的一日，前人未曾动笔的空白，总得由后人接续。今天要念的，就是我们在旧书里翻不到答案的地方。

一门学问，只要还有问题可问，便是活的；问题问完了，或者没有人再问，它就只剩下传抄。一个好问题的用处，不只在它的答案。为了答它，人要想出新的办法，新的办法又能拿去答别的问题；一个问题悬得越久，围着它长出来的办法往往越多。巴贝尔的旧书里，有许多办法我们至今只会用，不知道当初是为了答哪一个问题想出来的。

问题有两种来路。一种出自我们在世上见到的事：潮汐为什么有起落，魔核在云海里怎样凝成，疫病为什么多在潮年。一种出自学问自己：数质数的人，数着数着便要问它们往后怎样分布；记写法则的人，写着写着便要问这套写法能不能写尽一切法则。前一种让学问不离开世上的事，后一种让学问自己长出新的办法。两种都要问，今天的二十四问里两种都有，而且常常是前一种问到深处，就成了后一种。

什么样的问题值得列进来，我定了五条。

第一条，要问得清楚，清楚到将来有人拿出答案的时候，大家判得出他答了没有。所以每一问都先写成简明的问句。有几问我问得还粗，那是因为我只问得到这个地步；后来的人若能把它问细，那是好事，把一个问题问细，本身就是向答案走了一步。

第二条，要难，难到非想出新的办法不能答；可也不能难到无从下手。一个问题若连从哪里试都看不出，列进来也只是叫人发愁。所以多数问题后面，我附上几句：眼下我们知道到哪里，可以从哪里试。有一两问只有一句，那是因为除了问，我什么也说不出。

第三条，答“能”是答，答“不能”也是答。摸清哪条路走不通，本身便是学问的分内之事。巴贝尔的典籍里有一条老证明：质数没有最大的一个。证明一出，世上便再没有人去找最大的质数；这一条“没有”，省了后人多少工夫，又引出了多少别的问题。今天的问题里，说不定有几问的答案就是“不能”。若是那样，请诸位不要觉得白忙：证明一件事做不到，与证明一件事做得到，在学会看来同样是答案。

第四条，答案要写得出来，让别城的学者核得过。证明要写得让人一步一步照着查，只有作者自己看得懂的证明，还不算答案。问世上的事，答案要交代试验的条件与误差，别城的人照着做，得出相合的结果；一个办法试了几回都灵，若说不出在什么条件下灵、灵到什么程度，还只算线索。释读文字，要能拿别的残片对得上。法则、算学与施法，这一条都一样。有人说，严密的证明总是繁的，不如凭领悟来得快。我以为不然。写严密的人不得不想清楚每一步凭什么成立，想清楚了，多余的步子自然去掉，严密的证明往往也是简单的证明。领悟是好东西，可领悟要写成别人核得过的话，才成为学问。

第五条，宁可把一个问题拆成几问，不要把几件事揉成一问。一个问题里若藏着好几件事，答了一件，旁人还以为全答了。相连的几件事可以同列一问，但要标明哪几处须分开认定。

一个问题答不出的时候，有两条路可走。一条是把它问窄，先答一种特殊的情形：第三问我先问三维的位面，便是这个意思。另一条是把它问宽：有时候一个问题单独答不了，放进一类问题里一起看，反倒看得出门路。两条路都走不通，多半是因为还缺一种办法，或者缺一种记法。我们记数的办法传了几千年，许多算学的事，换一种记法就简单了；第六问问的正是法则的记法。

我还有一个信念，说出来请诸位斟酌：凡是问得清楚的问题，总有一个答案，或者是“能”，或者是“不能”，或者是“在什么条件下能”。我们今天答不出，不等于永远答不出。这是我自己的信念，学会列这些问题，并不靠它。只是说“不能”的人，要说清不能的是什么、在什么条件下不能；一时答不出，不算证明了不能。

二十四问的次序，大致从最抽象的排到最切身的：第一至第五问问数、形与证明；第六至第十一问问法则与施法；第十二至第十四问问元素、潮汐与魔枢；第十五至第二十问问城体、水晶、魔核、传送与封印；第二十一至第二十三问问疫害与法力池；第二十四问问巴贝尔的书。这样排，不是说前面的更要紧。一门学问往往要借另一门的办法；排在一处念，是想请诸位看看别人的问题。

**第一问　质数的疏密**

**问**　质数愈往后愈稀，其疏密有无确切的规律？

一到一百之间有二十五个质数，一百到二百之间只有二十一个；数到一万，平均每一百个数里只剩十二个上下。巴贝尔的典籍证明了质数没有最大的一个，却没有说它们是怎样稀下去的。恰恩的抄书匠替我数过十万以内的质数，每满一万记一次，数目如表一。

每一万里新添的质数一路减少，却减得很慢，又不是一路都减：第八个一万比第七个多出二十几个。我看这些数，觉得它们稀下去的样子大体是匀的，匀得像有规律，零碎的起伏又像没有规律。质数像雨点落在地上：盯着一小块地看，雨点疏密全无章法；看一大片地，落得却很匀。

我要问：给定一个数，比它小的质数有多少个，有没有一条确切的规律？若写不出确切的，近似的规律能近到什么程度，最多差多少？这一问可以先从近似的问起，但不要停在近似上。我求的不是再数一张更大的表，表总可以一个一个地数下去；我求的是不必一个一个地数，便能说出整体的疏密，并说出它最多差多少的规律。我猜确切的规律不会是一条简单的式子，或许要换一种数法：不直接数质数，而数与质数相连的别的东西，再从那里推回来。

抄书匠还告诉我一件事：质数有时扎堆，有时隔得很远；相差为二的一对质数，像十一与十三、十七与十九，数到十万也还常常遇见。这样的成对是否没有穷尽，我不另列一问，附在这里，供数质数的人留意。

**第二问　偶数与质数**

**问**　凡大于二的偶数，皆两质数之和？

这一问我是从恰恩一部旧抄本的页边抄下来的。那是一部算学典籍，抄书的人不知是谁；他在誊写的间隙拿偶数拆着算，末了在纸角留下这一行小字。我替他验过，一万以内都对，许多偶数还不止一种拆法，数越大，拆法总体上往往越多。可我不知道它为什么对，也想不出怎样证。一句话就问得清清楚楚、而我们答不了的问题，正是学会该列的。

这一问看着与第一问相近，其实不同。第一问问质数整体上有多少，这一问问每一个偶数能不能恰好拆开。知道了质数整体上大约有多少，并不就知道每一个偶数都拆得开：只要有一个偶数拆不开，这句话就错了，而整体上的多少说不到某一个数头上。大的偶数拆法往往更多，这一点让人相信它对；可“拆法越多”是平均而言，平均说不到每一个。

**第三问　封闭位面的形状**

**问**　封闭的位面，可能有哪些形状？

有的半位面，人一直往前走，走着走着又回到原处，既没有边，也走不出去。我先问最简单的一类：大小有限，连成一片，没有边，而且每一处的近旁都与寻常的空间一样。走回原处只是这类位面的一个样子，不能拿来当判据。这样的位面可能是什么形状？两个封闭的位面，有没有办法判断它们是不是同一种形状，进而把可能的形状列全？这里说的形状，不问大小，只问连法：一个位面若能不撕、不粘、不把两处并成一处，慢慢变成另一个，就算同一种形状。三维的位面最切身，先问三维；更多维的，我们连该怎么想都还说不清，但我也一并列在这里。

眼下我们只会一种办法：在位面里拉一根绳子绕一圈，看它能不能不剪断而收成一点。每一根绳子都收得拢的位面，与收不拢的位面，一定不是同一种形状。这个办法分得出一些形状，分不尽：两个位面里的绳子若都收得拢，它们是不是就是同一种形状，我不知道。

**第四问　算学的根基**

**问**　推演的规则，能否自证不自相矛盾？

我们用一套规则，从公认的道理推出算学的种种结论。假如这套规则能一条一条照章列出来，足以表达整数的算术，又确实不自相矛盾，那么，能不能只凭这套规则本身，证明它永远不会既推出一句话，又推出这句话的反面？我们信它不会自相矛盾，可信不是证明。

这一问要的不是再推出几条新结论，而是替推结论的规则作保。一套规则只要推出过一次矛盾，便什么都推得出来，它推出的一切也就一文不值。这一问也许要先把“推”这件事本身写成可以照章检查的东西：哪一步算推，哪一步不算，要像核账一样核得出来。

**第五问　判尽术式**

**问**　有无一法，可于任一术式未施之先，断其终局？

术式一经展开，或平息下来，或无休止地运转下去；一道自行调节的结界，会不会永远调节下去，眼下只能施展了看；可它迟迟不停，并不能证明它永远不停。若有这样一法，许多危险的术式就不必拿人去试；若没有，我们也该知道为什么没有，没有的界限又在哪里。

**第六问　法则的算式**

**问**　法则之线，能否以严密的算式记写？

法则巫师看见法则之线，靠的是登塔时的领悟和手稿里传下来的分门，彼此说起一条线来，常常要比划半天，说完了还未必是同一条。我问的是：能不能像记数那样记法则，让不同的人照着算式得出同一个结果？若能，许多今天只能口传的东西，就可以写下来核对了。

三万六千个字符记的是怎样施展，不是怎样推算；有了字符，我们能把一道术式刻下来，却不能拿两道术式来比、来算。算学所以传得远，是因为它有记法，一个人推的，别人照着记法能推一遍。法则若有记法，就不必只靠领悟去传了。

**第七问　世界的层次**

**问**　术式经由何处取力？

元素术式经元素取力，这一点没有人疑。法则术式与弦术从何处取力，说法不一：有人以为世界只有元素与Tiamat两层，法则之线就是Tiamat，那么两种术式都从法则之线取力；可施法的人又常说，在禁魔结界里，法则术式施展不出，弦术却往往照样施展。术式与Tiamat之间究竟隔着几层，各是什么？巴贝尔残卷说到网的地方，用的词不止一个，我想那里或许有线索。

这一问若能答出，许多施法的怪事或许就有了说法：为什么同一道术式在有的地方施展不出，为什么有的结界拦得住这一种术式、拦不住那一种。

**第八问　魔力是否连续**

**问**　魔力是否连续？

**第九问　第十环的分界**

**问**　施法何以自第十环起，便损伤法力池的上限？

九环以下不会；唯独白银之民，施展十三环以下的术式都不受这种损伤。为什么一般的分界恰恰在第十环，白银之民的分界又在第十三环？损伤的轻重与环级之间，有没有定量的关系？有人说，那是法则在惩戒越权的人，这只是比喻，不是道理。这一问问的是施法者的身体，也问的是法则之线的构造，我想答案要从两头一起找。

**第十问　三万六千字符**

**问**　三万六千个字符，够不够写尽一切能写的法则？其中有没有在一切合法的用法里都能用别的字符拼出、因而多余的字符？

这套字符是从巴贝尔传下来的。这里是两问，我并在一处，因为答其中一问的人，多半要同时想另一问。两问要分开认定。若字符不够，有些法则便不能用这套字符写下，要补字符，或者另寻记法；若有多余的，删去它们，刻写或许会更简单，也更不容易出错。

**第十一问　时间术式的因果**

**问**　时间术式能否改动它施展以前已经发生的事？

若能，因果就不再是一条往前走的线，与它相关的记录都要重新核对，受影响的范围有多大，须先辨明；若不能，限住它的又是什么？这一问不许拿人冒险去试，要先从术式与法则上推，再寻不伤人的观察。

**第十二问　元素的转化**

**问**　四大元素彼此转化之际，什么是不变的？

火化为风，水化为土，施法的人天天在做。有没有一笔账，把转化前后的元素、盛它们的器物和四周一并记进去，总是相符？今天我们只知道转化总有损耗，不知道损耗到哪里去了。若有这样一笔账，元素的转化便可以照账去算，而不必全凭经验。

**第十三问　魔力潮汐**

**问**　潮汐的起伏，有无定数？

十年一潮，百年一次大潮，这是先祖记下来的。此外的起伏，大的小的，看着杂乱。它们与十二轮魔月有没有关系？能不能像推算日月那样，事先把它们算出来？这一问要许多代人的记录。我请各城把潮汐记下来，记的办法尽量一样：每日什么时刻读，读几次，用什么器具读，都定下来；记的时候，也请记下测处的位置、器具校准的日子，以及当时有没有异常的供能。各城的记录能互相比，才算得出东西来。

**第十四问　潮汐中的稳定输出**

**问**　魔枢在潮汐冲击之下，能否自行稳住输出？

潮汐一来，魔枢的输出便跟着起伏；如今全靠匠师守在枢旁，一面看着，一面调校。匠师调得好，城里便觉不出来；调得慢了，或者调过了头，供能就忽大忽小。人力有尽：城越造越大，引擎越来越多，总有守不过来的一天。在潮汐不超出魔枢所能承受的范围之内，能不能让它自己稳住，不靠人守？

**第十五问　城体的悬浮**

**问**　悬浮阵列局部受损之时，城体能否不假人手而维持不坠？

一座城托在几组阵列上。一组坏了，别组要多担一些；担得过来担不过来，如今全凭匠师的经验，补得慢了，城体便要倾斜。我问的是：剩下的阵列若还有足够的托力，供能与主结界也照常，城体能不能不靠人手，自己稳住不坠。

**第十六问　元素水晶**

**问**　元素水晶的魔力用尽以后，能否再生？

用尽的水晶就成了一块死石头。若能再生，靠什么再生？

**第十七问　魔核**

**问**　魔核耗尽以后，能否重新充能？

若能，充能有没有损耗，能充几回？

**第十八问　偏折传送**

**问**　偏折传送的落点，能否预先算准？

偏折传送救过许多法则巫师的命，可落点至今没有人算准过，有时落得很远，落进比原处更险的地方。我问的是：只凭施法以前知道的事，能不能算出准确的落点？若不能，误差最小能小到多少？

**第十九问　封印的极限**

**问**　现行的封印，能否从此免于人工照看？

现行的封印都要人照看，隔些年便要查、要补。人会疏忽，一处封印失了，那是一城的事。若不能免，它们损耗的规律又是什么，多久该查一回？

**第二十问　魔核的成因**

**问**　魔核在云海中如何凝成？

魔核从云海里采来，采一颗少一颗。它凝成要多久？我们采得比它长得快吗？第十六、第十七与这一问，我看是一件事的三面：用尽的能不能再生，耗尽的能不能回充，没有的能不能长出来。三问合起来问的是，联盟的力气能用多久。

**第二十一问　疫害的来源**

**问**　疫害从何而来？

有几种烈性的疫病，专害城里的凡人、混血的居民、牲畜和庄稼，白银之民却不染。老人说疫年多在潮年。它为什么随潮而来？为什么白银之民不染？这本身就是线索。知道了来源，防起来才有根据；来源未明以前，各城已有的防护经验也要记下来。我请各城把潮年、病例与航道的往来一并记下。

**第二十二问　法力池的本质**

**问**　法力池是什么？

它在身体的哪里，怎样长，怎样会伤？我们只知道它会枯竭、会恢复，上限受了伤，有些长久不见恢复；可暂时的枯竭和长久的损伤，眼下连分都分不清。分不清，便不知道哪一个施法者歇一歇就好，哪一个须少施法、须医治。

**第二十三问　法力池的损伤**

**问**　法力池的损伤，能否安全、迅速、普遍地修复？

我问的是人人都用得上的修复，不是一两个人侥幸恢复过来。这一问要等第二十二问有了眉目才好下手，我仍旧把它单列，因为受伤的人等不得。

**第二十四问　巴贝尔的未知文字**

**问**　巴贝尔遗殿残卷里的第三种文字，能否释读？

遗殿的残卷里，除了我们读得懂的两种文字，还有第三种，谁也读不出来。抄书匠照样一笔一笔地抄，只是不知道自己抄的是什么。它写的是什么？我列这一问，是因为它也许会把我们带回旧书里去；可这一回，要靠我们自己的办法去读。

二十四问念完了。最后还有几句话。

这些问题分属好几门学问，可它们并不各自孤立。数质数的办法，说不定就能拿来数潮汐的起伏；判尽术式与算学的根基，是一件事的两面；魔核怎样凝成，与魔核能不能回充，答案多半要从同一处去找。学问越分越细，各城各派各守一门，这是免不了的；可一个问题往往要别一门的人来答。

有人担心，学问越积越多，总有一天没有一个人能通晓全部，到那时学问便要散了。我不这样看。每想出一种新的办法，旧的许多事就变得简单，原来要读十卷书才懂的，往后读一卷就够了。学问会越来越多，却不必越来越乱。

学会请诸位把这份清单带回去，抄给自己城里、自己学派里的人，也抄给别城、别派的人。谁答出了哪一问，或者证明了哪一问答不出，请寄回学会，学会记下来，在下一回大会上念。

这份清单没有封口。二十四问里，总有几问将来会被问得更细，有几问会被证明问错了，也总有新的问题要添进来。我只盼着，下一回、再下一回的大会上，有人站在这里，念的不是问题，而是答案；念的若是“不能”，那也是答案。

还有一个请求：答出来的，请抄两份，存在两座城里。我们刚从一场战争里把书找回来，诸位都知道，一份手稿是多么容易就没有了。

#### 题解

奥尔丁，拉塔基的算学家，生卒年不详，常年借用万物之塔的星算阵演算。混沌纪年 1197 年，白银学会承认他为院士；次年他把这篇论文送交学会作为答谢，刊于《白银学会会刊》1198 年卷。原文用古典通用语，这里是编者的今译，节次、公式与表格照原刊。

塞弗林第一问问质数的疏密有无确切的规律。1010 年前后，白塔城邦的克罗斯利把计数化为可用流变算估计的积分，证明了近似的规律：数到一个大数为止，质数的个数大致等于该数除以它的对数；更准确的近似，是把各处的疏密逐段累加起来的平滑计数式。实际的个数与平滑计数式相差多少，他没有说。奥尔丁把克罗斯利用过的乘积等式推广到复数上，得到疏密函数，把它延展到整个复平面，求出它在 s 与 1 − s 之间的对称；又由它的根写出质数个数的确切公式，称为疏密算式。公式说明，实际的个数与平滑计数式之差，除去平滑的部分与几项小量，都来自疏密函数的非平凡的根；一组根离实部为二分之一的那条直线越远，误差就可能越大。他算出最前三个根，都落在这条直线上，并猜想一切非平凡的根都落在线上；若猜想成立，数到任何一个数为止，误差都不超过与所数之数的平方根大致同一量级的界限，只多出一个对数因子。这便是奥尔丁猜想。篇末用万物之塔星算阵筛出的一千万以内的质数表作了比较，并说明塞弗林看见的“零碎的起伏”，是各个根给出的起伏叠起来的。

几种叫法要分清。平滑计数式是克罗斯利的，疏密函数与疏密算式是奥尔丁的；去掉疏密算式里一切根的部分，便是“疏密算式的估值”。年表说误差是相对疏密算式的，千年七题的公告说相对“奥尔丁疏密算式所得估值”，学科史词条说相对平滑计数式，三种说法讲的是同一件事：年表说的疏密算式，指的是它的估值（相对确切的疏密算式，误差恒为零）；估值与平滑计数式又只差几项比平方根小的量。

本篇刊出的次年，白塔城邦的星算阵把奥尔丁的根独立复算一遍，又往下算到第十个，都在线上，附在篇后。1340 年前后，诺兰把疏密函数在长区间上取平均，绕过了筛法的奇偶之障，证出塞弗林第二问。古典时代末期，各城的演算机联算，核验了最前一千多万个根。第一纪 307 年，奥尔丁猜想列为千年七题之一。318 年卡明斯在《论可判之事》里指出，这一猜想可以化成一条符文链停不停的问题。360 年代，各城的演算机用带区间证书的算法，并以独立的计数确认没有遗漏，核验了最前十的十八次方个根，无一落在线外；但核验再多，也不是证明。猜想至今未解。

#### 正文

**论质数的疏密**

奥尔丁

（混沌纪年一千一百九十八年送交白银学会）

学会去年承认我为院士。我想，答谢这份荣誉最好的办法，是早一点用上它给我的许可，把一项研究送交学会。我选的题目是质数的疏密。塞弗林把它列为二十四问的第一问；克罗斯利近两百年前证出了它的近似规律，此后研究它的人也不少。这个题目，大概不至于配不上这样的答谢。

克罗斯利证明的是：数到一个大数 x 为止，质数的个数大致等于 x 除以它的对数；更准确的近似，是把各处的疏密 $1 / (log t)$ 逐段累加起来的平滑计数式。至于实际的个数与平滑计数式之间究竟相差多少，他留给了后人。本文要说明：这个差是由一个函数的根决定的，它的大小取决于这些根落在什么地方。

**一、疏密函数**

克罗斯利的证明用到一个等式，它把一切质数与一切正整数连在一起：

　　$ product_p 1/(1 - p^(-s)) = sum_(n=1)^oo 1/n^s $　　（一）

左边乘遍一切质数 p，右边加遍一切正整数 n。等式成立，是因为每个正整数都能唯一地分解为质数之积。克罗斯利只让 s 取大于一的实数。我让 s 取复数，写作 $s = sigma + t i$；只要实部 σ 大于一，两边照样收敛、照样相等。我把它记作 $zeta(s)$，称为疏密函数，因为质数的疏密都写在它里面。

（一）式只在 $sigma > 1$ 时给出 $zeta(s)$。要知道它在别处的样子，先换一种写法。Γ 是把阶乘延展到复数上的那个函数，$Gamma(n) = (n - 1)!$；当 $sigma > 0$ 时，由

　　$ integral_0^oo e^(-n x) x^(s-1) d x = Gamma(s) / n^s $　　（二）

当 $sigma > 1$ 时对 n 求和，便得

　　$ Gamma(s) zeta(s) = integral_0^oo x^(s-1) / (e^x - 1) d x $　　（三）

**二、延展到全平面**

现在考虑积分 $integral_oo^oo (-x)^(s-1) / (e^x - 1) d x$，它沿着这样一条路走：从正无穷处出发，贴着正实轴的上方来到原点附近，绕原点正向一周，再贴着正实轴的下方回到正无穷；绕的圈要小，不包住 $e^x - 1$ 的其余零点 $plus.minus 2 pi i, plus.minus 4 pi i, dots$。$(-x)^(s-1)$ 照 $e^((s - 1) log(-x))$ 理解，$log(-x)$ 在 x 为负数时取实数。这个积分对一切复数 s 都有确定的值，并且处处可以逐项展开。当 $sigma > 1$ 时，把路缩到实轴上，绕原点的小圈趋于零，上下两段合起来是 $-2 i sin(pi s)$ 乘以（三）式的积分，便得

　　$ 2 sin(pi s) Gamma(s) zeta(s) = i integral_oo^oo (-x)^(s-1) / (e^x - 1) d x $　　（四）

右边的积分，绕的圈取定一个小于 $2 pi$ 的半径，便对一切 s 都有确定的值，处处光滑。左边的乘子 $sin(pi s) Gamma(s)$ 却有零点，除过去须小心。由 $Gamma(s) Gamma(1 - s) = pi / sin(pi s)$，（四）式可以写成 $zeta(s) = (i Gamma(1 - s)) / (2 pi) integral_oo^oo (-x)^(s-1) / (e^x - 1) d x$，所以 $zeta(s)$ 只可能在 $Gamma(1 - s)$ 变成无穷之处，即 $s = 1, 2, 3, dots$ 变成无穷。可 $s = 2, 3, dots$ 处，$zeta(s)$ 本由（一）式给出有限的值，那里的积分恰为零；只有 $s = 1$ 一处真变成无穷，像 $1 / (s - 1)$ 那样增大。这样，$zeta(s)$ 便延展到整个复平面。

**三、对称**

$zeta(s)$ 还有一种对称，它把 s 与 $1 - s$ 连在一起。令

　　$ psi(x) = sum_(n=1)^oo e^(-n^2 pi x) $

万物之塔的潮汐演算师把一段记录分解成分潮时，常用一个等式，用在这里便是（x 取正数）

　　$ 2 psi(x) + 1 = x^(-1/2) (2 psi(1/x) + 1) $　　（五）

把（二）式里的 s 换成 $s/2$、x 换成 $n^2 pi x$，得 $integral_0^oo e^(-n^2 pi x) x^(s/2 - 1) d x = pi^(-s/2) n^(-s) Gamma(s/2)$；当 $sigma > 1$ 时对 n 求和，得 $pi^(-s/2) Gamma(s/2) zeta(s) = integral_0^oo psi(x) x^(s/2 - 1) d x$。把这个积分从 $x = 1$ 处分成两段，前一段用（五）式换到 1 以外，便得

　　$ pi^(-s/2) Gamma(s/2) zeta(s) = 1/(s (s - 1)) + integral_1^oo psi(x) (x^(s/2 - 1) + x^((1 - s)/2 - 1)) d x $　　（六）

右边把 s 换成 $1 - s$ 不变，所以

　　$ pi^(-s/2) Gamma(s/2) zeta(s) = pi^(-(1-s)/2) Gamma((1-s)/2) zeta(1-s) $　　（七）

（六）（七）两式起初只在 $sigma > 1$ 时推出；（六）式右边对 0 与 1 以外的一切 s 都有意义，两式便处处成立。由（七）式，s 取 $-2, -4, -6, dots$ 时，左边的 $Gamma(s/2)$ 变成无穷，右边却是有限的，所以 $zeta(s)$ 在这些地方等于零。这些根我称为平凡的根，其余的根称为非平凡的根。

**四、根**

令 $s = 1/2 + t i$，又令

　　$ xi(t) = 1/2 s (s - 1) pi^(-s/2) Gamma(s/2) zeta(s) $　　（八）

由（七）式，$xi(t)$ 在 t 换成 $-t$ 时不变；由（六）式，它在整个平面上处处有确定的值，没有一处变成无穷，可以写成 $t^2$ 的幂级数，收敛得很快；而且 t 取实数时，$xi(t)$ 也取实数。$zeta(s)$ 的非平凡的根，正是 $xi(t)$ 的根。这些根的 t 的虚部都在 $-1/2$ 与 $1/2$ 之间；换句话说，非平凡的根都落在 $sigma = 0$ 与 $sigma = 1$ 两条直线之间的带里，并且对于 $sigma = 1/2$ 这条直线左右对称。带以外没有非平凡的根：$sigma > 1$ 处，（一）式的对数乘积绝对收敛，ζ 不为零；$sigma < 0$ 处，由（七）式的对称也就没有。带的两条边上有没有根，要另想办法。我以为边上没有根，与克罗斯利的近似规律，即质数的个数与 x 除以 log x 之比趋于一，是一回事，可这要另证，这里不细说。

非平凡的根之中（重根按重数计），t 的实部在 0 与 T 之间的，个数大约是

　　$ T/(2 pi) log(T/(2 pi)) - T/(2 pi) $　　（九）

误差不超过 log T 的量级。这个数可以这样算：让 $xi$ 沿着一个长方形的边走一圈，看它的角度一共转了多少；主项出自 $pi^(-s/2) Gamma(s/2)$ 沿直线的角度，其余的边上，ζ 的角度变化不超过 log T 的量级。边恰好经过根时，把边挪开一点。

我算了 $T = 30$ 以内的根。我先照（六）式备好 ξ 的级数与余项的界，再请万物之塔的星算阵逐差展开数表。t 取实数时 $xi(t)$ 也取实数，所以每一处变号，至少夹住一个奇数重的、落在 $sigma = 1/2$ 上的根；偶数重的根却不变号，单凭变号还不够。我在 t 从 0 到 30 之间找到三处变号，在 14.1 与 14.2、21.0 与 21.1、25.0 与 25.1 之间，两端的值都远大于余项的界，符号不会算错。又照上面转圈的办法，在 t 的实部从 0 到 30、虚部从 −1 到 1 的长方形上，沿边每隔二十分之一取一点，各点 ξ 的值都远离零，相邻两点之间角度的变化都不到四分之一周，所以不会漏掉整周；角度一共转了三周，即这一段里按重数计共有三个根。所以三处变号各夹一个单根，线上线外都没有别的根。它们的位置见表一。（九）式在 $T = 30$ 处给出将近三个，与此相合。

**五、质数的个数**

令 $F(x)$ 为小于 x 的质数的个数；x 恰是质数时，取它跳上去以前与以后的平均。再令

　　$ f(x) = F(x) + 1/2 F(x^(1/2)) + 1/3 F(x^(1/3)) + dots $　　（十）

即每个质数记一，每个质数的平方记二分之一，立方记三分之一，余类推。对（一）式两边取对数，得

　　$ log zeta(s) = sum_p sum_(n=1)^oo 1/n p^(-n s) = s integral_1^oo f(x) x^(-s-1) d x $　　（十一）

这个式子由 f 求得 $log zeta$，也可以倒过来，由 $log zeta$ 求 f：

　　$ f(x) = 1/(2 pi i) integral_(a - i oo)^(a + i oo) log zeta(s) x^s (d s)/s $　　（十二）

积分沿着 $sigma = a$ 的直线，a 与 x 都大于一；上下限取 $a plus.minus i T$，再令 T 趋于无穷。$log zeta$ 在 $sigma > 1$ 上照（十一）式的级数定义，在正实轴上取实数。在质数的幂处，积分给出跳上去以前与以后的平均，与（十）式的约定相合。潮汐演算师由分潮合回一段记录，用的也是这样一对算法，只是这里合回的是质数。

$xi(t)$ 可以写成 $xi(0)$ 乘以一切 $(1 - t^2 / alpha^2)$ 之积，α 走遍 $xi$ 的根，但 α 与 −α 只取一次，重根按重数计。这要两件事：由（六）式，$xi(t)$ 的增长不超过 $e^(|t| log |t|)$ 的量级，所以这个积收敛；ξ 又是偶函数，增长这样慢，积以外不能再有指数的因子。于是 $log zeta(s)$ 分成几部分：一部分来自 $s = 1$ 处的那个无穷，一部分来自 Γ，其余每一部分来自一个非平凡的根。逐部分代入（十二）式：先把积分截在 $a plus.minus i T$，T 取在两个根的高度之间，把路往左推，每个根给出一项，$s = 1$ 给出 $L(x)$，Γ 的那一部分给出最后的积分，常数一项给出 $-log 2$；再证明推路时上下两条横边上的积分随 T 趋于无穷而趋于零，便得

　　$ f(x) = L(x) - sum_rho L(x^rho) - log 2 + integral_x^oo (d t)/(t (t^2 - 1) log t) $　　（十三）

这里 $L(x)$ 是克罗斯利的平滑计数式，

　　$ L(x) = integral_0^x (d t)/(log t) $

积分过 $t = 1$ 时取两边对称的极限。克罗斯利原来从 2 积起，两种写法只差一个定数，约为 1.045，下面的比较里可以不计。ρ 走遍非平凡的根，重根按重数计。$L(x^rho)$ 照 $integral_(-oo)^(rho log x) e^u / u d u$ 理解，路从左边绕到 $rho log x$，不能先算 $x^rho$ 再取对数；上下半平面的两项互为共轭。各项截取到根的虚部的绝对值不超过 T 为止，再令 T 趋于无穷。最后，由（十）式倒推，

　　$ F(x) = sum_(m=1)^oo mu(m)/m f(x^(1/m)) $　　（十四）

$mu(1)$ 为一；m 有平方因数时 $mu(m)$ 为零，否则 m 的质因数个数为偶数时取一，为奇数时取负一。x 一定时，m 大于 $(log x) / (log 2)$ 的各项都是零，所以（十四）式其实只有有限项。（十三）（十四）两式合起来，就是质数个数的确切公式，我称它为疏密算式。

**六、误差**

把疏密算式里平滑的主项照（十四）式反演，便是

　　$ A(x) = sum_(m=1)^oo mu(m)/m L(x^(1/m)) $　　（十五）

　　$ = L(x) - 1/2 L(x^(1/2)) - 1/3 L(x^(1/3)) - 1/5 L(x^(1/5)) + 1/6 L(x^(1/6)) - dots $

我称它为疏密算式的估值。（十五）式的级数收敛得慢，算的时候用下面这个等价的式子，收敛得很快：

　　$ A(x) = 1 + sum_(k=1)^oo (log x)^k / (k dot k! dot zeta(k + 1)) $

x 大的时候，估值与平滑计数式只差 $1/2 L(sqrt(x))$ 等几项，加起来不过 $sqrt(x) / (log x)$ 的量级。

$F(x)$ 与估值之间的差，除去 $-log 2$ 与最后那个积分反演出来的几项小量，在表的范围内加起来不到一，全部来自非平凡的根。每个根 $rho = beta + gamma i$ 给出一项，它的包络约为 $x^beta / (|rho| log x)$，相位随 $log x$ 以 $2 pi / gamma$ 为周期转动；各根的项还会彼此抵消。根是成组的：ρ 与 $1 - overline(rho)$ 对 $sigma = 1/2$ 左右对称，一组里偏右的那个，实部是 $1/2 + |beta - 1/2|$，它决定这一组的起伏能增长得多快。所以一组根离 $sigma = 1/2$ 越远，它的起伏就可能越大；实际的个数偏离平滑计数式多少，全看根落在哪里。

若一切非平凡的根都落在 $sigma = 1/2$ 上，每一项的包络便只有 $sqrt(x) / (|rho| log x)$。要把它们加起来，先换一种计数：每个质数的幂 $p^k$，只要小于 x，便记 $log p$，跳点上也取平均，记作 $H(x)$。H 的确切公式与（十三）式同样推出，只是更干净：$H(x) = x - sum_rho x^rho / rho - log 2 pi - 1/2 log(1 - x^(-2))$。把根截到虚部的绝对值不超过 T，截掉的部分不超过 $x (log x T)^2 / T$ 的量级；留下的部分，由（九）式，不超过 $sqrt(x) (log T)^2$ 的量级。取 T 与 $sqrt(x)$ 相当，两部分都不超过 $sqrt(x) (log x)^2$ 的量级；再由 H 回到质数的个数，除去一个 log x。于是：

x 足够大的时候，数到 x 为止，实际的质数个数与疏密算式的估值相差，不超过一个定数乘以 $sqrt(x) log x$；与平滑计数式相差，也是这个量级。

我猜想事实正是如此。但我只能在一切根都落在线上的假定之下推出它，而这个假定本身我证不出。反过来也成立：若误差对一切大的 x 都不超过定数乘以 $sqrt(x) log x$，则 $H(x) - x$ 不超过 $sqrt(x) (log x)^2$ 的量级，于是 $-(zeta'(s)) / zeta(s) - s / (s - 1) = s integral_1^oo (H(x) - x) x^(-s-1) d x$ 在 $sigma > 1/2$ 处处有确定的值，ζ 在那里没有根；再由对称，非平凡的根都在线上。若有一个根落在线外，便没有一个定数能对一切大的 x 管住误差。所以这两件事是一件事：问误差有多大，就是问根落在哪里。上面的几处估计，我只写出了要点，没有写尽。

塞弗林当年看着十万以内的质数，觉得它们稀下去的样子“大体是匀的”，零碎的起伏“又像没有规律”。现在可以说：匀的部分是平滑计数式；零碎的起伏也有规律，它是疏密函数的根各自给出的起伏叠起来的。图一画的是五十以内的质数个数，跳点上取半值：一条是估值；一条是加上前三个根的结果，每个根的项 $L(x^rho)$ 也照（十四）式对各个 m 反演，连同共轭的根一起算，根的位置用未取整的数。加上三个根以后，曲线开始在阶梯的拐角处弯折，但还远不足以描出阶梯；要描出阶梯，须加上许多根。

一、最前三个根。两组算得 t 为 14.1347、21.0220、25.0109，误差都小于万分之一；各自取到小数第二位，与论文所记的 14.13、21.02、25.01 相同。

二、往下算到 t 为 50。这一段里，$xi(t)$ 变号十次；照论文的转圈之法另算，这一段的根也是十个。所以这十个都在线上。新算出的七个，t 约为 30.42、32.94、37.59、40.92、43.33、48.01、49.77。论文的（九）式在 t 为 50 处给出八个半上下，与数得的十个相容。

三、质数表。我们用另一种筛序把一百万以内的质数重筛一遍，得七万八千四百九十八个，与万物之塔的表相同。

我们没有找到线外的根。可是算了十个，也只是十个；论文的猜想说的是一切的根。我们请学会把复算的办法定下来：以后凡有人报出新的根，都须由另一处独立复算，并且两处都要数清那一段里根的总数，免得漏掉线外的根。

#### 题解

洛温，白塔大学的法则学者，混沌纪年 1455 年（繁茂之年）生，大魔潮那年六十一岁。本篇是他八十七岁时写的，第一纪 26 年秋暮之月收稿，刊于《白银学会会刊》第四辑（舰装与引擎）27 年（苇莺之年）第一期。

塞弗林第十四问问魔枢能否在潮汐冲击下自行稳住输出。七百年间，各城的回答都是匠师值守：潮汐一来，匠师守在枢旁看着输出、调着吸入，城体全靠人手日夜盯着死压；大魔潮那一年，好几座城的引擎险些没有压住。第一纪 24 年的潮年以后，塔林与卡奈奇的匠师在试台上试过让魔枢照输出的偏差自己回调吸入，有的稳住了，有的越摆越大，谁也说不出缘故。洛温不论回调纹怎样刻，只论回调以后魔枢怎样动。他把魔枢自身的响应、读数的延迟与改吸入的延迟写成三个流变方程，证明偏差的运动由一个三次方程的根决定，稳的条件是中间两项系数之积大于两端两项系数之积；三处延迟相等时，回调的强弱必须小于八倍。回调越强，潮汐留下的偏差越小，却越近于界限，这就是匠师们说的“刚好”。要连这点偏差也消去，须加积差，积差又不能积得太快，他给出了界限。六台试台的记录与推算大体相合，恰在临界上的一台判定不了；积差只有推算，没有试过。篇末他写明推算只在偏差小、回调不越过魔枢容量时成立；更高次方程的通法他没有找到，留给算学家。

这篇文章当时没有几个人读得懂。塔林的魔枢匠师阿伦德尔借过试台记录给他，读了这篇，照文中量延迟、定强弱的法子，在魔枢的吸入端加刻一道回调纹，第一纪 30 年前后造出能在潮汐里稳住输出的稳流魔枢。城体引擎在 30 年代陆续换装，不过二十年间，各城的引擎与舰队都换上了它，魔力潮汐起伏时不再需要匠师值守调校。阿伦德尔由此成了塔林最富有的人，洛温却分文未得。阿伦德尔晚年逢人便说这件东西有一半功劳是别人的，146 年拿出大半家产设立阿伦德尔奖，设立文书里写着：“道理要等人造出东西来才算数，东西要等人把道理想明白才改得动。”149 年首届发现奖授予洛温，那年他二百一十岁，致辞只有一句：“东西造出来以后，道理才有人读。”

本篇第十节的两处保留，后来都应验了。一是容量：第一纪 310 年，恰恩的周刊《奥术》刊出一篇署名“抄书街一学徒”的短报，指出城体引擎通行的稳流算法假定回调不会超出魔枢的容量，可十年潮的高峰与几种分潮、一日之内的涨落叠在一起时，回调会越过容量，延迟随之变长，洛温的稳定条件不再满足，输出便越摆越大。塔林与卡奈奇的两处试验场复现了摆荡，浮城安全监察局先限制叠潮时的负载，两年之内改换了算法。短报的作者是当时在恰恩求学的哈伍德，二十年后才承认，那时已是银冠院士。二是通法：任意次方程只看系数便判定稳与不稳的办法，第一纪 64 年由恰恩大学的普赖斯给出，今称普赖斯判别。

#### 正文

**论稳流**

洛温

（第一纪二十六年秋暮之月收稿）

**提要**　魔枢按自身输出的偏差回调吸入量，便可在潮汐里自行稳住输出；可试台上有的回调使输出稳住，有的却使它越摆越大。本文不论回调纹的刻法，只论回调的动力学。偏差小、回调不越过魔枢容量的时候，偏差的运动可以分成几个部分，每一部分或者一路增大，或者一路减小，或者越摆越大，或者越摆越小；稳的条件，是一切部分都属第二或第四种。魔枢自身的响应、读数的延迟与改吸入的延迟三处合起来，偏差满足一个三次方程，稳的条件是中间两项系数之积大于两端两项系数之积；三处延迟相等时，回调的强弱必须小于八倍。回调越强，潮汐留下的偏差越小，可越强越近于界限。若要连这点偏差也消去，须加积差，积差积得太快，又会越摆越大，本文给出它的界限。这些推算与塔林、卡奈奇和白塔六台试台的记录大体相合。文末给匠师一条量延迟、定强弱的法子，并说明本文推算不到的地方。

**一、问题**

塞弗林第十四问：“魔枢在潮汐冲击之下，能否自行稳住输出？”［1］七百年来，各城的回答都是人：潮汐一来，匠师守在枢旁，一面看着输出，一面调吸入。大魔潮那一年，好几座城的引擎险些没有压住；我那时在白塔，见过匠师三天三夜不离枢旁。第一纪二十四年是大魔潮以后的第三个潮年，书卷之月里，塔林的城体引擎有两回在潮峰上忽大忽小，值守的匠师调了两天才压平［9］。

让魔枢自己按输出的偏差去改吸入，这个念头并不新。二十四年以后，塔林与卡奈奇的匠师在试台上试过几种刻法，白塔大学的工坊也替我做过两台［10］。结果叫人困惑：有的魔枢一经回调，潮汐的推动只在输出上留下很小的偏差；有的却越摆越大，非得截断回调不可；同一种刻法，回调刻得强些，就从前一种变成后一种。匠师们说，回调要“刚好”，可谁也说不出刚好是多少。

本文不论回调纹怎样刻，只论回调以后魔枢怎样动。这本是塞弗林问题里最要紧的一层：能不能“自行”稳住，不在刻得出刻不出回调，而在回调以后稳不稳。

坎宁算过城体倾侧以后托力怎样在各组阵列之间重新分配［3］。他问的是最后停在哪里，不问停下以前怎样走；本文问的正是后者。一架器械在一处停得住，与它受了扰动以后能不能回到那一处，是两件事。

**二、魔枢与回调**

设魔枢的输出比定下的数多出 y，称为输出的偏差；吸入量比定下的数多出 u。吸入量变了，输出并不立刻跟着变，要过一会儿才到；潮汐也推动输出。量 u 的单位，取吸入改变 u 以后输出最终也改变 u。设潮汐的推动为 w，即吸入不变时潮汐会使输出改变多少。潮汐大多变得很慢：十年潮、各个分潮与一日之内的涨落，都比魔枢的延迟慢得多［4］；只有潮头骤至时，才像突然加上了一份推动。魔枢自身的响应写作

　　$ tau_0 (d y)/(d t) + y = u + w $　　（一）

$tau_0$ 称为魔枢自身的响应时间。回调纹读输出，读数也不能一下跟上，要照（二）式渐渐跟上；设读数为 z，

　　$ tau_1 (d z)/(d t) + z = y $　　（二）

$tau_1$ 是读数的延迟。本文说的延迟，都是这样渐渐跟上的响应时间，不是等一段时候再一下跳到。读到偏差以后改吸入，吸入也不能一下改到位：

　　$ tau_2 (d u)/(d t) + u = -K z $　　（三）

$tau_2$ 是改吸入的延迟，K 是回调的强弱：读数每多一分，吸入最终少 K 分。实际的魔枢、读数纹与吸入纹未必恰是这样跟随的；照这个样子写，是因为它最简单，试台上量得出来，量出来的跟随也与这样子相合（见第七节）。三处又假定各自独立，在一次试验之中不变，潮汐只当作加在输出上的推动。

这三式还都假定两件事。第一，偏差小，所以各处都与偏差成比例。第二，回调要的吸入，连同暂态之中的每一刻，都在魔枢的容量以内。这里的容量，是魔枢单位时间里所能吸入的上下限：u 有正有负，吸入多了碰上限，少了碰下限。它与燃料和魔核的余量有关，与核容［5］不是一回事，核容说的是一枚魔核放尽时交付的总能量；试验时各台魔核的余量都在一半以上。若潮汐太猛，回调要的吸入越过上下限，吸入便顶在限上，不再随读数而变，（三）式就不成立了。下面的推算，都只在这两条之内。

回调纹读输出，用的是魔力计那样的感受件［2］，只是装在输出的导流上，读的是交付给负载的魔力，不是四周的游离魔力。试台上先接上已知的负载校准；旁边另装一枚不接导流的感受件，从读数里扣去四周魔力的直接影响。读数还要拿一个基准去比。汤顿查明，受过魔潮扰动的原器，容量与响应都会长久地改变，他比对的一组，前后之比是一点零一一［8］。所以本文说的“稳”，是对基准而言：基准变了，输出也跟着变；感受件受过魔潮，响应时间也可能变，须重量。

**三、四种运动**

令 w 为定数，去掉它所留下的定偏差以后，（一）至（三）式的解是若干项之和，每一项都形如 $e^(n t)$，n 是某个方程的根（若有重根，项前还要乘上 t、$t^2$ 等，但只要根的实部为负，这些项照样衰减）。根可以是实数，也可以是成对的复数。于是偏差的运动可以分成几个部分，每一部分的幅度是下列四种之一：

一、一路增大；二、一路减小；三、来回摆动，越摆越大；四、来回摆动，越摆越小。临界之时还有第五种：来回摆动，不增不减，见第五节。

第一与第三种，与稳流不相容；好的回调只许有第二与第四种。这在算学上就是：一切实根都是负的，一切复根的实部都是负的。

**四、只有一两处延迟的时候**

若没有回调，K = 0，偏差在 $tau_0$ 的量级里趋于 w，潮汐推多少，输出就偏多少。

若改吸入毫无延迟，$tau_2 = 0$，n 满足 $(tau_0 n + 1)(tau_1 n + 1) + K = 0$。它的两个根之和为 $-(tau_0 + tau_1) / (tau_0 tau_1)$，是负数；两根之积为 $(1 + K) / (tau_0 tau_1)$，是正数，所以两根都是负实数，或者是实部为负的一对复数。回调再强，也不会越摆越大。两根一旦成了复数，实部便恒为 $-(tau_0 + tau_1) / (2 tau_0 tau_1)$，回调越强只摆得越密，摆幅衰减的快慢却不变。

可试台上的魔枢确实越摆越大。缘故在于：吸入不能一下改到位，读数也要一会儿才跟上，改吸入的延迟从来不是零。本文所论的这一类回调，至少有三处延迟，下面就是三处的情形。

**五、三处延迟**

把 $e^(n t)$ 代入（一）至（三）式，n 须满足

　　$ (tau_0 n + 1)(tau_1 n + 1)(tau_2 n + 1) + K = 0 $　　（四）

展开为

　　$ a n^3 + b n^2 + c n + d = 0 $　　（五）

其中 $a = tau_0 tau_1 tau_2$，$b = tau_0 tau_1 + tau_0 tau_2 + tau_1 tau_2$，$c = tau_0 + tau_1 + tau_2$，$d = 1 + K$，四个系数都是正的。

要问的是：K 多大的时候，（五）式有实部为正的根。设 K 从零增大。K = 0 时三个根是 $-1/tau_0$、$-1/tau_1$、$-1/tau_2$，都是负的。K 增大，根随之连续移动；实根不会越过零，因为 n = 0 时（五）式左边等于 d，是正的。所以若要有根的实部转正，必定是一对复根越过虚轴。越过的那一刻，n 是纯虚数 $n = omega i$，偏差既不增大也不减小，只以周期 $2 pi / omega$ 来回摆。把 $n = omega i$ 代入（五）式，实部与虚部各自为零：

　　$ b omega^2 = d, quad a omega^2 = c $

两式相除，得临界时 $b c = a d$；这时（五）式恰可分解为 $(a n + b)(n^2 + c/a) = 0$，一个负实根之外，是一对纯虚根 $plus.minus i sqrt(c/a)$。在临界以下，三个根的实部都是负的；越过临界时，这对根的实部随 K 增大而增大，因为在 $n = omega i$ 处，n 随 K 变化之率的实部是 $c / (2 (c^2 + b^2 omega^2))$，是正的。于是：

**稳的条件**　中间两项系数之积大于两端两项系数之积，

　　$ b c > a d $　　（六）

即回调的强弱必须小于

　　$ K^* = (b c) / a - 1 = ((tau_0 tau_1 + tau_0 tau_2 + tau_1 tau_2)(tau_0 + tau_1 + tau_2)) / (tau_0 tau_1 tau_2) - 1 $　　（七）

三处延迟相等时，$K^* = 8$（这里假定三处延迟都大于零，K 不小于零）。一处延迟远小于另外两处时，$K^*$ 很大，这正是第四节说的情形。延迟越不齐，界限越宽；延迟越齐，界限越窄。

回调的好处，是潮汐留下的偏差变小。w 不变、又满足（六）式时，偏差最终停在

　　$ y = w / (1 + K) $　　（八）

回调越强，留下的偏差越小；可越强越近于界限，近于界限时平息得慢，越过界限便越摆越大。这一取一舍，匠师们说的“刚好”，就在这里。

**六、临界的周期与量法**

在临界上，偏差以周期

　　$ P = 2 pi sqrt(a / c) $　　（九）

来回摆，不增不减。在临界附近，摆动的周期与此相近；离临界远了，周期与摆一回剩下多少，都要由（五）式的复根求出，没有复根时也就不摆。

匠师要用这个条件，须先量出三处延迟。量的时候先截断回调，锁住其余各处，一处一处地量。把吸入突然改一点，看输出走到它最终改变量的六成三，即一减去 e 的倒数，用了多少时候，这是 $tau_0$；让输出突然变一点，看读数走到六成三用了多少时候，这是 $tau_1$；锁住读数，让它突然变一点，看吸入走到六成三用了多少时候，这是 $tau_2$。K 也另用静的办法量：锁住读数，改一点，看吸入最终改了多少。照（七）式算出 $K^*$，回调的强弱取它的一半上下，便留下了余地。

匠师守枢，其实也是一种回调：他看见输出，想一想，再动手改吸入，这三步各有延迟。老匠师常说“宁慢勿猛”，猛的匠师调过了头，供能就忽大忽小，塞弗林在第十四问里说的正是这个。本文的条件与这句老话相合：回调的强弱越过界限，不论是人手还是回调纹，都会越摆越大。至于人手何以比回调纹难守，本文没有给人手写方程，不敢断言。

**七、与试台的比较**

**八、积差**

（八）式说，回调总要留下 $w / (1 + K)$ 的偏差。要连它也消去，可以在回调里加一项：偏差存在多久，就把它积多久，按积下的量继续改吸入，称为积差。（三）式改为

　　$ tau_2 (d u)/(d t) + u = -K z - K/T integral z d t $　　（十）

T 是积差的时间，T 越小，积得越快。对恒定的推动，只要下面的（十二）式成立、补偿所要的吸入始终在容量以内，偏差最终归零；潮汐若是缓缓变化的，偏差只是跟着变化，不能说全消。n 须满足

　　$ a n^4 + b n^3 + c n^2 + (1 + K) n + K/T = 0 $　　（十一）

照第五节的办法，令 $n = omega i$ 求临界，虚部为零得 $omega^2 = (1 + K) / b$，实部为零得 $a omega^4 - c omega^2 + K/T = 0$。T 极大时，新添的一个根约为 $-K / (T (1 + K))$，其余三个仍是（五）式的根，所以只要（六）式成立，T 大的时候便稳；T 变小时，首次越过虚轴恰在下式取等号之处。于是稳的条件为两条（这里 K 与 T 都大于零）：第一，（六）式照旧成立；第二，

　　$ (b c - a (1 + K))(1 + K) > b^2 K / T $　　（十二）

也就是积差不能积得太快，T 须大于 $b^2 K / ((b c - a(1 + K))(1 + K))$。三处延迟都是五秒、K = 4 时，T 须大于九秒。积差积得太快，偏差还没回来就又压过了头，便越摆越大；积得慢，偏差回零也慢。图一的第四条线是 K = 4、T = 30 秒的情形，偏差最终归零。积差这一部分，试台上还没有做过，这里只是推算。

**九、两套调节**

奥尔德姆在卡奈奇一个城区试行魔网联调时，阵列的调节与引擎的调节一度互相抵消，阵列来回摆动，后来改为分层：阵列先就地调平，引擎再慢慢调总出力，才稳下来［7］。两套调节同调一件事，各自都在界限以内，合起来却可能越界。最简单的情形是：两套回调读的是同一个输出，动态又相同，合起来就是一套强弱为 $K_1 + K_2$ 的回调，$K_1$、$K_2$ 都小于 $K^*$，二者之和却可能大于它。快慢不同、作用的地方不同时，要另写联接的方程，本文不论。分层以后，阵列先稳下来，引擎再慢慢调，这与第八节积差要积得慢，道理相近；可两者的联接不同，（十二）式不能直接搬过去用，奥尔德姆的分层为什么稳，还要另算。并联的魔枢也是如此。布兰登在并联的魔枢之间加刻均流纹，使几枚按比例分担负载［6］。若几枚魔枢相同、动态相同，各自的回调读的又是同一个总输出，合起来的强弱便是各枚之和，须照这个和定强弱。一般的情形要另写方程；而且总输出不摆，并不就是各枚不摆，几枚之间还可能一增一减地摆，均流纹管的正是这一种。

**十、推算不到的地方**

本文只问偏差小、回调不越过魔枢容量时的运动。潮汐太猛，回调要的吸入超过容量，吸入便顶在容量上，这时上面的方程不再成立。顶在限上的那一段，回调实际上弱了，积差却还在积，等吸入离开限的时候，积下的量可能已经过多。我猜那时就像延迟变长了一样，可这只是猜想；以后会怎样，我还算不出来。

三次的方程，稳的条件只看系数便能判定，即（六）式；四次的（十一）式，照第五节的办法也求得出来。更高次的方程，用同样的办法也能逐个求出临界，但要一个一个地求；只看系数便能判定一切根的实部是否都为负的通法，我没有找到。几套调节、几枚魔枢连在一起时，方程的次数很快就高起来。这件事我留给算学家。

回调纹刻在魔枢的吸入端，怎样刻，本文不论；照现在的做法，每一种机型都要各自刻写。

（阿伦德尔工坊的值守簿，第一纪三十四年；录自塔林阿伦德尔工坊旧址所藏原簿）

本城城体引擎的四枚主枢，于三十一年换装稳流魔枢。回调纹照白塔洛温先生的法子定强弱：先在试台上量出三处延迟，各枢不同，约在四秒到七秒之间；照他的（七）式算出界限，回调的强弱取界限的一半。又加积差，积差的时间取他的（十二）式所要的三倍。换装那年不是潮年，平日的涨落里输出都稳。今年是换装以后的第一个潮年。

复苏之月，今年第一回潮起。往年潮月里主枢旁要有十二名匠师分三班值守，今年每班只留两人，只看不调。潮峰那几日，输出的偏差最大不过定数的百分之一点二，比往年人手值守时小得多；摆动都是一两回就平。夏胧之月第二回潮起，也是这样。

书卷之月十九日夜，潮峰与一日之内的涨落叠在一处，第三枢的输出摆了三回才平（表上看不出摆动，便算平了），偏差最大到百分之二点六。第三枢的三处延迟是六秒、四秒、五秒，照洛温先生的（七）式，界限约为八点二五，回调取四；（十二）式要积差的时间大于八点六秒，取三倍，为二十六秒。查簿上那一夜实际吸入的读数，离上限还有一成余。照洛温先生说的，回调若顶到上下限，他的推算便不管用了；这一回没有顶到。我们把第三枢的积差时间放长了一半，改为三十九秒；此后潮退，没有再遇到这样的叠潮，放长有没有用，还说不定。

书卷之月以后潮退，各枢都没有再摆。

我照洛温先生的文章做这件东西，第五节读了三遍才懂。他文中说“匠师守枢也是一种回调”，我们的老匠师听了不服，后来看了这一年的簿子，也就不说什么了。
