## 一、定位与基本原则

### 1.1 定位

内务治安部为联盟公共治安之主管部门。联盟之暴力合法使用分为两轨：对外御敌之武装力量（依《防务基本法》），与对内执法之治安力量（依本架构及城邦治安制度）。本部为后者之联盟层机关——不打仗，只执法；不御外敌，只治内乱。

### 1.2 基本原则

1. **文官节制、非军事化**——本部不入武装力量序列，不受联盟军事委员会指挥，其武装仅以执法为限。军队不介入日常治安，治安力量不承担作战。
2. **留痕为纲**——对街头魔法之约束，不在于普遍设置禁魔，而在于施法必留痕、施暴必追责（《魔法基本法》第二十九条）。本部之执法体系以留痕追责为第一支柱，禁制强制为第二支柱，武力为最后手段。
3. **第一现场在城邦、联盟补位不替位**——城邦自管本邦治安（《宪章》第八条），本部承担城邦力所不及、事权跨邦、或依法属联盟之事项。本部对城邦治安机关行指导与协调，不行领导与统辖。
4. **执法自身必留痕**——凡本部人员之执法行为——盘查、拘捕、禁制、侦缉、布设临时禁魔场、使用武力——其过程本身须全程留痕，与嫌疑人之施法留痕同录并存。追责之剑双向悬置：施暴之民必被追责，滥权之吏亦必被追责。
5. **最小强制**——强制措施以制止危害、控制现场为限，与危害之性质与程度相当。禁制优先于伤害，控制优先于制服，劝止优先于动手。

## 二、职权与边界

### 2.1 法定职权（依《白银执政院》）

1. 联盟公共治安；
2. 跨城邦刑事协助——协查、通缉、移送与案卷交接之指导与执行；
3. 暴乱处置；
4. 禁区巡逻——节点禁区、封存设施外围等法定禁区之治安性巡逻与违规查处；
5. 流民风险处置——流民潮之秩序维持与风险处置。

### 2.2 边界（本部不做什么）

| 事项 | 归属机关 | 界线 |
|------|---------|------|
| 城邦本邦治安 | 各城邦治安机关 | 本部指导协调，不领导统辖 |
| 城体防御、武装威胁处置 | 城邦卫戍军（城防应急队） | 卫戍军不管治安，本部不管防御 |
| 边境异常、节点预警 | 银烛会 | 银烛会管预警监测，本部管治安执法 |
| 联盟级安全风险（反渗透、反间谍、反颠覆、反秘密结社） | 联盟安全部 | 本部管普通治安与刑事协助，安全部管联盟级安全风险 |
| 涉禁术、涉弦魔法案件之技术管辖 | 禁术管制委员会（留痕稽查、术式鉴定） | 本部先期处置、移送会签 |
| 重案强制、裁断执行、涉禁术者拘传 | 执行官团（裁断体系） | 执行官团不承担日常街头响应，本部不承担裁断执行 |
| 军职纪律及军事犯罪 | 军法体系依《防务基本法》权限处理 | 普通犯罪不因军人身份免于治安调查；严重案件依法移送联盟庭署 |
| 流民登记、安置、民籍 | 民政部（民籍誓籍局） | 民政管登记安置，本部管秩序风险 |
| 走私之税务查处 | 税关总署 | 缉私之治安执法由税关缉私局承办（见十四局） |
| 城体结构与设施之安全监察 | 浮城安全监察局 | 工程安全归安监，治安违法归本部 |
| 航道航路之行政管理 | 航道空港局 | 航路行政归该局，航路治安归本部七局 |

### 2.3 战略设施之双轨守卫

节点禁区、封存设施等联盟战略设施实行双轨守卫：**军事守卫**由要塞军团承担，对武装攻击、魔物与混沌入侵实施防御；**治安巡逻**由本部禁区巡逻总队承担，查处越界闯入、违规施法、盗采盗掘等治安违法。两轨互不指挥，现场遇武装威胁时以军事处置为先，治安力量协助外围管控。

## 五、执法权限与强制措施

### 5.1 权限总则

本部人员依法享有下列执法权限，一切权限之行使全程留痕：

1. **盘查核验**——对有违法嫌疑者盘查身份、核验誓籍（对接民籍誓籍局）；
2. **传唤与拘捕**——对联盟管辖案件之嫌疑人依法传唤、拘捕；城邦管辖案件，应城邦之请协助执行；
3. **现场管控**——封锁现场、疏散人员、保全留痕证据；
4. **禁制强制**——使用禁制器械、布设临时禁魔场（依5.3）；
5. **技术侦缉**——依令状实施留痕深度追溯、侦讯占卜与符讯侦听（依5.7）；
6. **武力使用**——依5.4之分级。

### 5.2 禁制器械之分级

> 治安执法之根本难题在于：执法对象之施法能力可能远超执法者。本部之答案不是以环级对抗环级，而是以**器械分级 + 力量递补**应对——器械压制其力，递补机制兜底其余，留痕追责断其侥幸。

| 器械等级 | 名称 | 压制能力 | 配发范围 |
|---------|------|---------|---------|
| 常备级 | 禁制铐 | 有效压制七环及以下之施法 | 全体执法人员 |
| 重装级 | 禁制枷 | 有效压制九环及以下之施法 | 机动支队、禁区巡逻支队、监所 |
| 阵列级 | 便携禁魔阵列 | 有效压制十一环及以下之施法（多具联动） | 机动支队、重大事件处置 |

1. 禁制器械依《魔法基本法》之禁魔原理，以制止未经许可的施法为目的，并负有减少伤害的义务；实际效果、适用对象与风险须经设备验证，不能保证任何对象均无损伤。弦魔法不受禁魔压制，已成型法术不因禁魔自动消失。
2. 执法对象之环级明显超出现场器械压制能力者，**不作强攻**——依5.5之递补程序召请执行官团或依法请求军事协助。以人命填环级差距，为本部勤务规程所禁止。
3. 禁制器械之术式标准由白银学会学术认定、工艺与奥术科技部定行政标准，本部依标准采购配发。

### 5.3 临时禁魔场之布设

依《禁魔分区规程》第二十七条第二款，本部及城邦治安于**处置暴力事件或违规施法时**得布设临时禁魔场。布设必须明确范围、强度与期限，全程留痕，事由消失即撤（同规程第二十八条）。无正当事由长期布设者，依规程第八章查处——本部自身亦在查处之列。

### 5.4 武力使用之分级

1. **劝止**——口头警告、鸣示；
2. **制止**——徒手或非伤害性术式制止违法行为之继续；
3. **禁制**——禁制器械之使用、临时禁魔场之布设；
4. **武力**——足以造成伤害之强制手段，仅限于暴力抗法危及执法者或第三人之人身时；
5. **致命武力**——仅限于正在发生之危及人命之暴力且别无他法制止时。

每一级之动用均须留痕记录动用理由；越级动用武力者，由督察审计局调查，构成犯罪者移送裁断体系。

### 5.5 高环级对象之递补程序

现场执法对象之施法能力超出处置能力时，依次递补：

1. **稳控与留痕**——不作强攻，保持现场留痕采集，疏散周边；
2. **召请执行官团**——涉禁术、涉弦魔法或需重案强制者，即请执行官团介入（《禁魔分区规程》第三十一条）；
3. **军事协助之例外**——对象之危害构成武装威胁级别者，依《防务基本法》之相应程序请求军事力量协助；军事协助以排除威胁为限，治安处置权仍归本部；
4. **红线上报**——事态构成《宪章》第六条红线事件者，即依红线事件流程上报；只有依法发布的紧急授权或接管令明确调整的程序可在其范围内调整，报告本身不产生无限强制权，不豁免弦魔法禁令或高阶施法授权。

### 5.6 誓约持证

本部一切执法人员须完成誓约登记并持联盟执法资格证上岗（誓约任用体系对接组织部）。执法资格证载明持证人之权限等级与可动用之器械等级。无证执法、超权限执法者，其执法行为无效，并依纪律程序处理。

### 5.7 技术侦缉之令状原则

1. 留痕深度追溯、侦讯占卜、符讯侦听，以及同等侵入性的心智或记忆读取，一律凭裁断体系令状实施。令状须说明法定事由、对象、手段、范围、期限、必要性及最小侵害安排；到期失效。
2. 迫切生命危险或证据即刻灭失时，可按已获批准的紧急规程先行采取必要措施，由值班主管签署理由并在三日内补请司法追认；普通办案便利不属紧急。法术本身仍须具备相应许可，不得实施绝对禁术。
3. 未获追认的材料不得作为针对被侦缉人的定案证据；立即停止收集，由裁断体系监督封存用以审查违法取证的必要副本，其余材料依法限期销毁。不得以销毁为名灭失追责证据。
4. 全程记录申请、紧急理由、访问、转移、追认和处置；记录可由书面和可核验技术共同完成，不保证留痕不可伪造。受督察审计局、盟约监察院监督，受影响者可依《裁断体系组织法》申请救济。

## 六、与城邦治安之关系

### 6.1 两层治安体制

联盟治安实行两层体制：城邦治安机关依《宪章》第八条自管本邦治安，为治安之**主体与第一现场**；本部为治安之**联盟层与补位力量**。两层并立，以事权划分而非层级隶属相联。

### 6.2 联盟事权清单

下列事项属联盟事权，由本部管辖：

1. 跨城邦之刑事案件与追缉；
2. 法定禁区之治安巡逻与查处；
3. 涉联盟机关、联盟官员之案件；
4. 暴乱及超出单一城邦处置能力之重大事件；
5. 流民潮之跨邦秩序风险；
6. 联盟航路与空港之治安（七局）；
7. 城邦主动请求联盟协助之事项。

清单之外，城邦治安自管，本部不得越权介入。

### 6.3 协作机制

1. 城邦治安机关经"联盟治安协办"窗口提出协作请求，本部依《执政院机构设置》指导城邦间之协查、通缉、移送与案卷交接；
2. 城邦治安遇涉禁术、涉弦魔法或超出本邦处置能力之案件，应即移送本部或请执行官团介入，各方共享留痕与警讯（《禁魔分区规程》第三十二条）；
3. 本部对城邦治安发布之通缉令与协查通告具联盟效力，各城邦治安机关应予执行；
4. 联盟治安学院及各直属院校向城邦治安人员开放培训；本部拟订之治安规程对城邦为指导性标准，城邦得依本邦制度采认。

### 6.4 争议处理

本部与城邦的权限争议先由执政院协调；协调不成或需紧急保全时，依《裁断体系组织法》第九条提请银章裁断庭处理。税赋、赔补等实体公法请求依同法第十四条进入联盟公法裁断庭。协调不停止必要救援，不授权任何一方扩大事权。

### 7.2 寂环塔

1. 寂环塔为联盟最高戒备监所，收押经裁断体系判处之高环级重罪服刑者——其环级超出常规监所禁魔结界之压制能力者。
2. 寂环塔坐落于孤悬浮空平台，不邻任何城邦，位置为涉密事项。全塔常设最高强度禁魔场，其结界工程由节点结界工程部建造维护，供能与结界运行由节点结界工程部负责工程监测；银烛会接收异常预警并负责外部边界监测，两类节点不得混称。
3. 寂环塔之收押、提审与释放，一律凭裁断体系之裁断书或执行官团之执行令办理；任何行政机关不得指令寂环塔收押或释放任何人。
4. 塔内管束以依法限制自由和在技术可行范围内压制施法为限，不加体罚，不作任何形式之魔力抽取或研究利用；违者依虐待被管束人之罪移送裁断体系。
5. 涉弦魔法之极端个案，其人身羁押是否适于寂环塔，报银色学派评估；银色学派认为超出羁押可行性者，依其终局判断处置。
6. 寂环塔接受盟约监察院之羁押与刑执巡察（《盟约监察院组织法》第五条）。

## 实施附件 治安立案与跨机关协作

### 警实一 启动与权限
现场机关先救援、隔离危险、保存证据；案件五日内登记分流。城邦普通治安由城邦办理，跨城邦案件由协查与通缉局统筹并指定一个主办机关，原现场机关签收移交；禁术案件会同禁术管制委员会，职务犯罪移送监察院。军人普通犯罪不自动进入军法，军事事项依《防务基本法》处理。

### 警实二 强制与救援
逮捕、搜索和侵入性侦缉须具法定依据及裁断令；法定现行犯制止或迫切生命危险现场处置应以最小必要范围实施，二十四小时内向有管辖权庭署报请审查，庭署七十二小时内决定是否维持。技术侦缉的三日追认另依5.7。不能仅凭职责清单创设拘禁或刑罚。禁魔现场先查场域、设备及医疗后果；调整禁魔依《禁魔分区规程》，高阶施法依《魔法基本法》与禁术委员会许可规则，二者相互独立。

### 警实三 记录、监督和结束
侦查一般九十日内形成移送或结案；复杂案件经部长或其授权主管说明理由可延长九十日，限制人身及财产措施仍逐项受司法期限约束。案件争议、投诉及强制异议可向督察审计局、监察院或有权庭署提出，内部投诉不阻碍诉讼。危险解除后结束现场限制、移交设施管理者，结案时清点证物、解除不再必要措施并书面通知；涉嫌事故过失和费用负担分送相应机关，救援支出先走合法应急预算，不以等候归责阻延救援。
