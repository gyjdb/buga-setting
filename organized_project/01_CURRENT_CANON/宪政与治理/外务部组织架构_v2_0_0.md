# 《外务部组织架构》

## 一、定位与基本原则

### 1.1 定位

外务部为白银执政院组成部门，依《银色联盟宪章》第四条、第二十六条第7项，掌最低接触外务与对外口径（《白银执政院组织架构》二·2）。本部办理联盟与外部城邦、凡世政权、异族共同体、外部商队及使节之间最低必要之接触，以维护联盟空域安全、节点稳定与遗产封存为要务。边境监测与凡世态势情报归银烛会，不列入本部。

### 1.2 基本原则

1. **最低接触**——本部不介入凡世诸国之战争、继承、圣战、宗教征伐与疆界争夺；本部所拟、所发之文书与安排，不得使联盟承担从属义务或军事盟约（宪章第四条）。
2. **以事由定接触**——接触以实际事由为限：口岸往来或文书往返足以办妥者，不扩大为驻留；降级足以止损者，不提请强制措施。
3. **止损为先**——凡世行为危及联盟空域安全、节点稳定或遗产封存时，对外处置以止损、隔离、封存、降级为先；强制措施由有权机关依法决定。
4. **口径统一、实质不改**——联盟对外之声明、照会与通告由本部拟定并发出；内容出于其他机关决定者，依原决定表述，不改变其实质。
5. **会签不代授权**——本部之会签、最低接触意见与评估，不代替有权机关之决定，亦不代替动武授权。
6. **留痕与密封并行**——对外文书、协定与降级决定全程登记；依法密封之部分不公开，但不豁免记录与监督。

## 二、职权与边界

### 2.1 法定职权

1. 低接触规程、外交降级机制、对外通牒口径与外部事件应对规则之制定；对外声明、使节接待、外部商队准入原则与外部驻留限制（《白银执政院组织架构》二·2）；
2. 低接触口岸之指定，外部驻留之审定，驱逐之决定，停留、驻留、改正与离境期限之分类标准及来访档案存档期限之另定（《出入境与接触等级规程》第四、十六、十八、十九、二十一、二十二、二十七条）；
3. 对外事务协定之谈判（《白银议会组织法》第二十六条之一）；
4. 对外军事行动授权审议前之最低接触意见，行动中之通告与降级协商（《银色联盟防务基本法》实施附件防实五）；
5. 涉及凡世之回收远征计划之最低接触评估（《联盟遗产法》第二十二条）；
6. 凡世学者查阅大图书馆晨光级典藏之批准（《大图书馆章程》第十条；《出入境与接触等级规程》第十三条）；
7. 凡世货币兑换牌价、边贸结算与流入管理办法之会签（《布加联盟储备系统章程》第十五条）；
8. 出入境与口岸管理局之管理（《白银执政院组织架构》七·1）。

### 2.2 职权边界

| 事项 | 归属机关 | 界线 |
|------|---------|------|
| 军事威慑、拦截与作战 | 联盟军事委员会 | 军委决定军事应对；本部只出具最低接触意见，行动中负责通告与降级协商；空域内拦截驱离之现场警告依防务法与现行勤务 |
| 边境监测、缓冲区出入许可与凡世态势情报 | 银烛会（边境警戒总局、外域情报局） | 本部使用其通报，不指挥其情报工作，不派遣以凡世身份活动之人员 |
| 对外惩戒与条文宣读之许可 | 银色十二环 | 依宪章第十三条第5项终局许可；本部依许可文书拟定文本、组织送达 |
| 知识代理人之遴选与管理 | 大图书馆（回收远征司） | 本部不掌其名册，不经由代理人传递外务文书（《大图书馆章程》第十五条） |
| 域外追缉 | 内务治安部（域外追缉工作局） | 追缉在本部最低接触框架内实施，经外务渠道处置；侦查事项由治安部决定 |
| 税赋关检与缉私 | 税关总署 | 关检由税关总署作出；口岸机关提供有关资料 |
| 疫害检疫 | 卫生与疫害委员会 | 检疫由该委员会决定 |
| 禁术与遗产事项 | 禁术管制委员会、遗产主管机关、有权治安机关 | 本部会签与移送，不代作决定 |
| 外国施法者之访客执照 | 彩虹之焦术士联合会 | 联合会可在口岸设窗口；通行与接触许可仍依《出入境与接触等级规程》 |
| 船只之航行、停泊与空港通行凭证 | 天空航务部（航道空港局） | 船只许可与人员入境分别记载 |
| 非公民之居留登记 | 民政部（民籍誓籍局） | 长期驻留许可由管理局作出，居留登记由民籍誓籍局办理 |
| 凡世货币与边贸结算办法 | 联盟储备院 | 储备院规定；本部与商贸与行会部会签 |
| 成员城邦之对外往来 | 成员城邦 | 城邦依宪章与本邦规则办理，可以向本部通报；城邦之约定不约束联盟 |

### 2.3 十二环终局事项与对外文书

1. 对外惩戒与条文宣读，依宪章第十三条第5项须经银色十二环许可；本部依许可文书拟定文本、组织送达，不得以部令代替许可。
2. 针对凡世政权之对外惩戒，另须十二环不少于九席许可（《银色联盟防务基本法》实施附件防实五）；本部在授权审议前出具最低接触意见。

## 三、首长层

| 职务 | 员额 | 产生方式 | 分管 |
|------|------|---------|------|
| 部长 | 1 | 依执政院组成部门首长任命之通例 | 全面工作；直管督察审计局、政策法规司 |
| 副部长（规程与驻留） | 1 | 部长提名，依通例任命 | 接触规程司、外部驻留司、出入境与口岸管理局、人事训练司、行政财务司 |
| 副部长（事件与地区） | 1 | 部长提名，依通例任命 | 外部事件司、地区事务司、外务值守中心 |

## 五、出入境与口岸管理局

### 5.1 地位与职掌

出入境与口岸管理局为本部管理之专项局，依《出入境与接触等级规程》受理来访申请，作出口岸许可、入境、停留及长期驻留决定，签发来访者通行证，组织离境登记与依法遣返。税赋关检归税关总署，疫害检疫归卫生与疫害委员会，边境异常预警归银烛会（《白银执政院组织架构》七·1）。

### 5.2 下设单位

| 下设单位 | 职能 |
|---------|------|
| 来访审核处 | 来访申请之受理、审核与决定（同规程第八、九条） |
| 通行证处 | 来访者通行证之签发、变更与补发，接触等级印记之制作（同规程第十至十二条） |
| 长期驻留处 | 长期驻留许可之决定、续期与终止；通知民籍誓籍局（同规程第十八条；《民籍与誓籍登记法》第二十条） |
| 离境与遣返处 | 离境登记、遣返之组织与候乘安排（《出入境与接触等级规程》第二十三条） |
| 违规查处处 | 违规之查明、改正、警告、限制与吊销；驱逐之报请（同规程第二十一、二十二条） |
| 各口岸驻员 | 驻各低接触口岸，核对到达、登记来访、查验印记，与航路治安分局及城邦接待机关互通资料（同规程第五、六、二十条） |

### 5.3 规则与个案

本部制定规则、审定外部驻留、决定驱逐；来访许可与通行证之个案由管理局决定，本部不代为决定。

### 5.4 复核

1. 当事人对管理局之决定不服者，向本部申请复核，由政策法规司组织未参与原决定之人员审查，三十日内答复。
2. 对本部决定之复核，依《白银执政院组织架构》行政第二条向执政院申请。
3. 复核不妨碍依法请求裁断；通行证、停留、长期驻留、遣返与驱逐争议，由联盟公法裁断庭初审（《出入境与接触等级规程》第二十六条）。

## 六、对外往来程序

### 6.1 外务渠道

本架构所称外务渠道，是本部与外部城邦、凡世政权、异族共同体之间经确认之联络方式，包括来使、本部派出之特使、经核实之书信往来，以及依6.5或协定设立之联络处。外务渠道由使节接待司维护。

### 6.2 对外文书

1. 对外文书以盟约通用文为准，附对方通用文字之译本；译本与原本不一致者，以原本为准。
2. 对外文书、协定与降级决定交银章文枢署登记令号；依法密封之部分，依密卷与传讯部之密级体系保管。

### 6.3 外部事件之处置与降级

1. 外部事件司接到通报、口岸报告或其他机关之移送后，查明事件是否涉及联盟空域安全、节点稳定或遗产封存，提出处置建议。
2. 降级措施各依其法源：
   - 依《出入境与接触等级规程》第四条第3款，缩减或暂停有关低接触口岸之接待；
   - 外部驻留之批准期满不再续展（同规程第十九条）；
   - 暂停接待来使与派出特使，或依协定条款暂停协定之履行；
   - 依6.4发出通牒。
3. 需要封锁、强制措施或动武者，由有权机关依法决定；本部之意见不代替授权。
4. 事态消退后，外部事件司提出恢复接触之建议，记明经过、已采取之措施与恢复条件。

### 6.4 通牒

1. 通牒载明联盟之要求、期限与逾期后之措施；所列措施，以有权机关已经决定或依法可以决定者为限。
2. 通牒由外部事件司拟文，依6.7第1项会签，经执政院会议决定，由本部发出。
3. 通牒属于对外惩戒或条文宣读者，依2.3经银色十二环许可。

### 6.5 驻外与特使

1. 本部不在联盟以外设常驻使馆。
2. 需要对外交涉者，由部长提名、执政首席任命特使；特使持执政院授权书，按授权事项出使，事毕即回，提交出使报告。
3. 经成员城邦同意，本部可以借用其地面据点设对外联络处；联络处只收转文书、安排会面，不设常驻使节。

### 6.6 对外事务协定

1. 条约事务司拟订谈判方案，载明事由、范围、拟议条款、最低接触意见与履行所需预算，经部长批准后进行谈判。
2. 协定文本由执政首席依《白银议会组织法》第二十六条之一提交元老会；经批准，由执政首席授权签署，交银章文枢署登记并发布联盟公报，依法密封之部分存档不公开。
3. 协定不得设立从属义务或军事盟约，不得替代议会法、战事动员法案及银色学派之终局许可；未经批准之事项，本部只在已有协定与法定权限内作执行安排。

### 6.7 会签与意见

1. 涉及军事威慑者，会签联盟军事委员会；涉及边境异常者，会签银烛会；涉及禁术泄漏、知识遗产外流者，会签禁术管制委员会、大图书馆或白塔（《白银执政院组织架构》二·2）。
2. 本部就下列事项出具最低接触意见、评估或会签意见：对外军事行动与对凡世政权之对外惩戒，在授权审议前；涉及凡世之回收远征计划，在议会审议前；报请批准之对外事务协定；凡世货币兑换与边贸结算办法。
3. 会签与意见不代替有权机关之决定。

### 6.8 申请、公开与监督

1. 本部行政申请依《白银执政院组织架构》行政第一条受理；拒绝、限制或其他不利决定，说明事实、依据、理由与救济途径，重大不利决定先给十日申辩。
2. 本部公布接触规则、口岸指定、分类期限、申请条件及已依法公开之协定；依法密封之部分，盟约监察院依法审查时应当提供。
3. 督察审计局检查行政执行，盟约监察院依法独立监察与审计。

## 七、与城邦之关系

### 7.1 城邦之对外往来

成员城邦与外部城邦、凡世政权之往来，由城邦依宪章与本邦规则办理。城邦可以向本部通报其往来事项与对外约定；涉及联盟最低接触原则或联盟对外口径者，本部提出意见。城邦对外订立之约定不约束联盟，亦不代替联盟之对外事务协定。

### 7.2 地面据点与联络处

借用城邦地面据点设联络处，须经该城邦同意，借用文书载明用途、期限与终止后之交还。

### 7.3 口岸与城邦接待

低接触口岸由本部会同天空航务部及有关成员城邦指定；城邦指定之访客接待机关依其规则提供接待（《出入境与接触等级规程》第四、二十条）。

### 7.4 争议处理

本部与城邦之权限争议先由执政院协调；协调不成或需紧急保全时，依《裁断体系组织法》第九条提请银章裁断庭处理。

## 十、职级与规模

### 10.1 职级

本部不另设职级体系，人员职级依联盟通行惯例。

### 10.2 编制归属

本部与出入境与口岸管理局分别列编；驻口岸人员列入管理局。特使依任务任命，不另设常设编制。

## 实施附件 对外文书、协定卷宗与任职登记

### 外实一 对外文书

对外文书载明发文机关、事由、依据与日期；出于其他机关决定者，注明原决定之令号。发出前，办公厅核对授权、会签与译本，送达方式与回执记入原卷。来文登记收文日期与来使，转承办司；需要答复者，在答复期限内拟文。

### 外实二 协定卷宗

每件协定立一卷，收谈判方案、谈判记录、各机关意见、批准文书、签署本、登记号与履行记录。密封部分单独封存，注明密封依据与解封条件，卷内其余部分依档案规则公开。协定到期、修订或终止者，在同一卷内注明，并通知执行机关停止依旧文执行。

### 外实三 任职登记

公民在外部城邦、凡世政权或异族共同体任职者，可以向外部驻留司登记任职机构、职务与期间，说明可能之利益冲突；登记义务由议会法另定，本架构不设禁止。登记人承担联盟公务、事涉其任职机构者，外部驻留司将登记资料转送其所在机关，由该机关依回避规则决定。登记资料只用于此目的，本人可以查阅、更正与撤回。
