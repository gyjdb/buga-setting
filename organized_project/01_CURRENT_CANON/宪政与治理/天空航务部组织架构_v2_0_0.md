# 《天空航务部组织架构》

## 一、定位与基本原则

### 1.1 定位

天空航务部为白银执政院组成部门，依《银色联盟宪章》第二十六条第1项，掌航权与空域治理中之民用航务（《白银执政院组织架构》二·10）。本部统筹联盟空域之分层、航路与民用航行秩序，保障公民依宪章第十条第2项迁徙与通行，维护跨城航运之安全与连续。舰队之护航与作战部署归联盟军事委员会，航路治安归内务治安部，不列入本部。

### 1.2 基本原则

1. **航规统一**——联盟航道与空域规则由本部依法统一制定；成员城邦不得私立与之冲突之航道与空域规则（宪章第八条第1项）。
2. **运营在城邦**——城邦负责本邦空港及接驳设施之日常运营，公布本邦空域内之航路、起降场所与飞行规则（《天空航道与空港规程》第三条第3款；《联盟成员城邦通例》第二十六条）；本部对其不作日常指挥。
3. **规则与个案分立**——本部制定规则、审定航路；航道通告、停泊许可与空港通行凭证之个案，由航道空港局办理。
4. **安全为先**——航务安排以船艇与旅客之安全为先：风暴、乱流与魔力潮汐依预报改道，航标依航图刻制与维护。
5. **通行有据**——临时改道不使原有合法通行凭证失效；公民之通行只受航权等级与合法封锁令约束（宪章第十条第2项；《天空航道与空港规程》第十六条第3款）。
6. **处分照决定**——城邦航权之削减由白银议会决定，本部依决定执行，不扩大亦不缩小其范围（宪章第九条）。

## 二、职权与边界

### 2.1 法定职权

1. 空域分层、航路规划、航道规则、空港互认、护航走廊与民用航行秩序；商队、客运艇、工程艇与补给舰之通行规则（《白银执政院组织架构》二·10）；
2. 航行层之划定，跨城航路之审定，符文航标标准之制定，浮城移泊后航路之复核，军用航道优先次序之协调与公告，航务机关之间协调之主持（《天空航道与空港规程》第五至八、十九、二十九条）；
3. 载客或载货船艇之驾驶与领航资格之主管（《职业执业资格法》第六条第8项）；
4. 试航空域临时扩展之协调公告（《浮空战舰建造、验收与入列规程》第十六条）；
5. 各城使用共同航道之运输与通行记录之提供（《联盟税赋与共同义务份额法》第十二条第1款）；
6. 航道空港局之管理（《白银执政院组织架构》七·2）。

### 2.2 职权边界

| 事项 | 归属机关 | 界线 |
|------|---------|------|
| 舰队之护航、作战部署与空域内之拦截 | 联盟军事委员会、银色舰队 | 本部只划定护航走廊、协调军用航道并公告（《天空航道与空港规程》第十九条） |
| 空港配套设施与城体工程安全 | 浮空城建设与水务部 | 本部定空港等级之航务条件；设施部分由该部定 |
| 浮城移泊之技术审查 | 浮城安全监察局 | 移泊决定与检验资料送航道空港局，本部复核航路 |
| 民用艇之适航检验 | 工艺与奥术科技部 | 该部组织检验；本部汇集报告所载之运行条件 |
| 航路治安 | 内务治安部（航路治安局） | 航路行政归本部与航道空港局，航路治安归七局 |
| 外来者之入境、停留与接触等级 | 外务部、出入境与口岸管理局 | 空港通行凭证与来访者通行证分别使用 |
| 航道、通行与空港税费 | 税关总署、成员城邦 | 项目与标准由议会法及城邦依法另定（同规程第二十八条）；本部不征收 |
| 城邦航权之削减与其他处分 | 白银议会 | 本部依决定调整航路与互认范围，不代议会作出处分（同规程第二十七条第3款） |
| 城邦间之航权争议 | 裁断体系 | 本部只协调，不裁定 |

| 边境与空域异常之预警 | 银烛会 | 本部据预警资料拟订护航走廊与航路风险 |

## 五、航道空港局

### 5.1 地位与职掌

航道空港局为本部管理之专项局，依《天空航道与空港规程》承办航道通告、临时改道、空港等级备案、停泊许可，以及空港通行凭证之核发与互认。航道空港局不制定航务政策，不裁定城邦间航权争议（《白银执政院组织架构》七·2）。

### 5.2 下设单位

| 下设单位 | 职能 |
|---------|------|
| 航道通告处 | 航道通告、临时改道与恢复通告之发布（同规程第十六至十八条） |
| 航图发布处 | 新航图、航标及启用条件之公布（同规程第八条第2款） |
| 空港备案处 | 空港等级之备案（同规程第九条） |
| 停泊许可处 | 停泊许可之决定（同规程第十条） |
| 凭证处 | 空港通行凭证之核发、变更与互认（同规程第十一条） |
| 航标巡检队 | 联盟航路上不属任何空港辖区之航标之巡检与报修；空港辖下之航标仍由所在地空港运营人负责（同规程第七条第2款） |
| 各空港值守人员 | 航标异常之引导、预报与通告之转达；与空港运营人、航路治安分局及出入境与口岸管理局之驻口岸人员互通航务信息（同规程第七条第3款、第十五条） |

### 5.3 规则与个案

本部制定规则、审定航路；通告、许可与凭证之个案由航道空港局决定，本部不代为决定。需新增规划以外之跨城航路或变更规划者，报本部审定。

### 5.4 复核

1. 当事人对航道空港局之决定不服者，向本部申请复核，由政策法规司组织未参与原决定之人员审查，三十日内答复。
2. 对本部决定之复核，依《白银执政院组织架构》行政第二条向执政院申请。
3. 复核不妨碍依法请求裁断；通行证之核发、吊销、限制，以及航道税、通行税、港口税之争议，由联盟公法裁断庭裁断（《天空航道与空港规程》第二十六条）。

## 六、航路与航权程序

### 6.1 跨城航路之审定

1. 跨城航路之新设与调整，由航图司拟订方案，征求途经及起讫城邦、有关空港运营人之意见，经部务审议后由本部审定；航道空港局据此发布通告。
2. 城邦之意见记入审定理由，不具否决效力；城邦对审定不服者，可以申请复核并请求裁断。
3. 航路之审定涉及航权互通协定或空域规则变更者，由执政院依《白银议会组织法》第十一条第3项提请议会。

### 6.2 护航走廊

1. 护航走廊是航路规划中为舰队护航预留之航段，由航图司依航路风险、预报与银烛会之预警资料拟订，会签联盟军事委员会后公布。
2. 是否护航、以何种编队护航，由联盟军事委员会依防务法决定；本部不指挥舰队。
3. 走廊内之通行记录，由航权与运输司汇集，供有权防务机关核算舰队护航指标时查取（《联盟税赋与共同义务份额法》第十二条第2款）。

### 6.3 航权处分之执行

1. 白银议会依宪章第九条削减城邦航权者，本部依议会决定调整该城之航路、分层与空港互认范围，航道空港局据此变更通告与凭证。
2. 调整以决定所列之范围与期限为限；决定变更或期满者，本部即恢复原有安排。
3. 调整期间，在途旅客之改道与滞留协助以及人命救助照常进行（《天空航道与空港规程》第二十二条）。

### 6.4 个人飞行

1. 以法术或其他方式个人飞行，不属《天空航道与空港规程》第二条所列之民用航行，不需停泊许可与空港通行凭证；城内飞行依施法执照与城邦飞行规则（《联盟成员城邦通例》第二十六条）。
2. 民航规程司拟订个人飞行者与船艇相遇时之避让指引，以及进出空港之通行指引，向社会公布；指引不设许可，不增加施法执照以外之义务。
3. 个人飞行进入空港与客舱者，依《禁魔分区规程》及《天空航道与空港规程》第二十三条关于戒备区之规定。

### 6.5 预报、改道与恢复

1. 航道气象与风暴预报台之预报送本部、航道空港局及有关空港；航道空港局核对受影响之航路、船艇类别与空港条件，组织航务处置（《天空航道与空港规程》第十五条）。
2. 临时改道依本部审定之规划；需新增规划以外之跨城航路者，报本部审定（同规程第十六条第2款）。
3. 改道事由消退后，航道空港局发布恢复通告；涉及航路规划变更者，先经本部审定（同规程第十八条）。

### 6.6 会签与资料

1. 航路涉及浮空生态、资源作业与禁采区者，会同云海资源与生态部划定界限；涉及军用航道者，会签联盟军事委员会；涉及城体与空港配套设施者，会同浮空城建设与水务部。
2. 低接触口岸之指定，由外务部会同本部及有关成员城邦办理（《出入境与接触等级规程》第四条）。
3. 会签与资料不代替有权机关之决定。

### 6.7 申请、公告与监督

1. 本部行政申请依《白银执政院组织架构》行政第一条受理；资格考核之决定期限依《职业执业资格法》第十条。拒绝、限制或其他不利决定，说明事实、依据、理由与救济途径，重大不利决定先给十日申辩。
2. 本部公布航行层、航路、航标标准、通行规则、资格考核标准与申请条件；办公厅保存决定原卷与更正记录。
3. 督察审计局检查行政执行，盟约监察院依法独立监察与审计。

## 七、与城邦之关系

### 7.1 统一规则与城邦运营

联盟航道与空域规则由本部统一制定；城邦负责本邦空港及接驳设施之日常运营，公布本邦空域内之航路、起降场所与飞行规则，不得与联盟规则冲突（宪章第八条第1项；《联盟成员城邦通例》第二十六条）。

### 7.2 城邦航务实施办法

城邦航务实施办法应遵守联盟统一之航道与空域规则（《天空航道与空港规程》第二十九条第1款）；空港协同司核对后提出改正意见，本部不撤销城邦之规则。

### 7.3 城邦间之航务分歧

城邦之间之航务分歧，由空港协同司组织协调，记明各方意见与协调结果；本部不裁定城邦间之航权争议，协调不成者，依《裁断体系组织法》请求裁断。

### 7.4 争议处理

本部与城邦之权限争议先由执政院协调；协调不成或需紧急保全时，依《裁断体系组织法》第九条提请银章裁断庭处理。

## 实施附件 航路审定、资格考核与值守

### 航实一 航路审定

方案载明航路起讫、途经空港、所属航行层、适用船艇、航标位置、预报风险与禁采区界限。征求意见之记录、技术意见与审定理由一并存卷；审定后交航道空港局发布通告，并附启用条件。航路停用者，在同一卷内注明原因与替代航路。

### 航实二 资格考核

考核分载客与载货两类，科目包括航图与通告之辨识、操控实作、险情处置与旅客转移。考核由未参与培训该申请人之考官主持，结果与评分理由交申请人。外国驾驶与领航资格不自动互认，依《职业执业资格法》第十一条办理。

### 航实三 值守记录

航务值守中心记录收到之预报、报讯、军委需求与首报，注明来源、收到之先后、承办人与处置；交接值守时移交未结事项。记录之保存期限依档案规则。
