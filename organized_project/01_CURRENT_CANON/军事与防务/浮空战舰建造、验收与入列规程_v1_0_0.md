# 《浮空战舰建造、验收与入列规程》

## 第一章 总则

### 第一条 宗旨

1. 本规程依《银色联盟防务基本法》第三十七至四十条制定，规定浮空战舰之定型、建造、检定、验收及交付，保障联盟舰装标准之施行。
2. 新舰建造以议会批准之规格、预算及编制为据，各主管机关依其职掌签认，制作与检定之记录随舰保存。

### 第二条 适用范围

1. 军用船坞建造、改装护卫舰级以上战舰，适用本规程；改装之检定与试航范围，按所改系统及其对全舰之影响确定。
2. 城邦卫戍军舰只适用本规程有关安全与通讯标准兼容核验之规定，由舰装谱系检定局出具兼容核验记录。
3. 军用船坞之产权、委托运营及产能基线，依《银色联盟防务基本法》第三十二至三十五条。

### 第三条 职掌

1. 联盟军事委员会后勤装备部提出用途需求、装备计划及交付要求；国用工务总局组织采办、供应、船坞排产及军工履约验收。
2. 工艺与奥术科技部主管舰装标准之拟订、试验场布局、军工产能排序及工业安全；舰装谱系检定局实施舰装谱系检定，标准谱系局实施通用部件检定，术式工业安全局履行安全监管。
3. 受托城邦依委托运营契约负责船坞日常运转、工匠雇佣、设施维护及安全管理，指定船坞长组织生产与试航中的工艺作业。
4. 白银学会依学部分工提供技术认定；财政部掌预算与拨款，联盟公产监督管理委员会依职掌实施船坞出资人监督。

## 第二章 舰型与列装登记

### 第四条 新型号设立

1. 后勤装备部提出新型号用途需求，送白银学会第四学部作技术认定；涉及材料、封印及检验方法的，由第四学部会同第三、第五、第七学部提出认定意见。
2. 工艺与奥术科技部依技术认定拟订型号规格、建造标准、材料谱系及验收要求，作为联盟舰装标准之修订报议会通过后颁布。
3. 同型后续舰依已颁规格建造；影响型号用途或主要系统的设计变更，由前两款程序审查并修订标准。

### 第五条 列装型号目录

1. 联盟军事委员会会同工艺与奥术科技部编订列装型号目录，报白银议会备案，登记各型号所属舰种、等次、名称及所据舰装标准。
2. 舰种依《银色联盟防务基本法》第十七条分为主力舰、护卫舰、巡逻舰、运输舰与特种舰。阿卡加斯之龙级登记为主力舰中的最新一代战列舰；荣光级登记为主力舰中的最高一等。
3. 荣光级的用途登记包括承载强大魔力核心与重型阵列，在节点覆盖以外向随舰巫师供能、供其轮换休整，以及运送战团分队与回收远征队。
4. 目录的编订与变更，以已颁舰装标准为据；单舰接收、编入建制及舰名另依本规程登记。

## 第三章 立项与造舰

### 第六条 立项与经费

1. 国用工务总局依装备计划提出采办与产能测算，财政部编列预算；造舰经费列军备与军工账，数额由议会拨款法另定。
2. 工程涉及不同城邦船坞或工坊共同承造的，国用工务总局会同工艺与奥术科技部提出跨城邦重大工程方案，由执政首席提请议会，自城邦院起始审议立项与拨款。
3. 军工产能标准、舰装规格及船坞安全规程之立法框架，自公议院起始审议；工程开支按生效拨款授权执行。

### 第七条 造舰令

1. 国用工务总局依财政部核定之预算及生效拨款法下达造舰令，向受托城邦送达排产与交付文书。
2. 造舰令载明型号、舰序、承造船坞、适用标准、批准预算、材料拨付依据、主要交付节点及履约验收责任。
3. 排产与交付期限由国用工务总局依核准工程方案及委托运营契约另定；变更影响预算授权的，先按预算程序提请议会决定。

### 第八条 跨船坞分工

1. 单一船坞不能独力承造的，由国用工务总局会同工艺与奥术科技部拟定分工方案，明确总装船坞、部件承造者、装配接口、交付顺序及检验责任，纳入工程方案。
2. 各受托城邦依核准方案组织本坞生产，工坊依承造约定制作并交付部件；国用工务总局协调排产，工艺与奥术科技部处理跨城产能排序及标准适用事项。
3. 接口变更由提出方说明原因，经原技术认定与检定机关按职责审查后，由国用工务总局通知有关承造者；须修订舰装标准的，依第四条。

### 第九条 银材与魔核拨付

1. 银材、魔核之采权与战略配给归云海资源与生态部；质量检验由银材与魔核质量检验所承担。
2. 工程用纯银、纯化秘银依《布加联盟储备系统章程》第十八、二十条，由战略银材储备库按合法拨款或授权呈批直拨。
3. 魔核之实物保管、能级检定及出库校验归魔核能源局；划拨须有储备院账务指令与魔核能源局出库校验双方签发。
4. 船坞收存出库与收讫凭证，将领用材料记入所属部件谱系；直拨回执副本报盟约监察院，工程结余依储备章程原路缴回。

### 第十条 驻场工匠

1. 外城驻场工匠由所属工坊或行会派遣，凭工坊凭照局登记之凭照及派遣记录列入本坞名册；船坞长安排工段、作业范围及现场负责人。
2. 本人身份可以民籍誓籍证明、已登记凭照或其他合法文书查明；须施法或须专业资格之作业，另核相应执照、许可及资格。
3. 驻场工匠之工钱依派遣约定由所属工坊或城邦支付，不从造舰经费支取；工时、工序及交付成果由本坞签认。
4. 驻场工时经议会程序认可、白银学会会同相关行会估值评议后，可以折抵所属城邦共同义务份额；扣除联盟已付报酬的部分，登记与复核依《联盟税赋与共同义务份额法》。

## 第四章 部件谱系与在坞管理

### 第十一条 部件谱系卡

1. 承造者应为装舰部件随附谱系卡，记明部件名称、所属舰与装配位置、材料来源及出库回执、成色与稳定性检定、制作工坊及凭照登记、主制工匠署名、学术认定、通用部件检定及舰装谱系检定。
2. 刻印、附魔、魔枢耦合等工序分别记录承作者与签认人；各出具机关就其所掌栏目签印，原始凭据随卡存档。
3. 装舰后续记装配、系泊复验、试航加载及修整结果；随舰工匠在所任工序的试航加载栏署名，检定员记明复验结论。

### 第十二条 检定与装舰

1. 舰装部件、护盾阵列、航行动力组件、军用通信节点及舰载封印装置，由舰装谱系检定局依联盟舰装标准检定；通用部件之检定记录由标准谱系局提供。
2. 舰装谱系检定在装舰前完成。谱系断缺的部件不得装舰，检定局应告知缺项及补正要求；补正后依原标准复验。
3. 不合规格的部件由承造者修整或重制，检定合格后交付；船坞依合格记录装舰并记明位置，不得自行降低规格。
4. 涉及阵纹或封印材料的专项试验，可以由封印材料与法阵工艺试验场依其职掌出具记录，送有关学部与检定机关使用。

### 第十三条 保密与防窥

1. 船坞人员、驻场人员及受托承造者，应保守所知之船坞军工信息；国用工务总局在委托运营及承造文书中列明保管、阅用与移交责任。
2. 未经许可，任何人不得对在建或试航舰只施展侦测术。工艺检验所需侦测，由国用工务总局会同舰装谱系检定局按作业计划确认对象、人员及范围；涉及施法特殊许可的，另依魔法法系取得许可。
3. 船坞长负责将阅用范围及现场安排告知有关人员；依法实施的监察、审计与裁断取证，依相应权限提供材料并保存交接记录。

## 第五章 系泊检定与验收试航

### 第十四条 验收组

1. 国用工务总局主持验收组，成员包括舰装谱系检定局检定员、白银学会第四学部认定人、受托城邦船坞长、舰队司令部接收代表及联盟军事委员会后勤装备部代表。
2. 验收组依各方职掌核验建造、检定、试验及交付记录，安排整改与复试；涉及专项认定的，由有关学部或检验单位提供意见。
3. 银烛会船坞与军工监察司可以列席并独立记录，不参与验收表决；监察意见依其法定职权提出。

### 第十五条 系泊检定

1. 受托城邦的船坞完成装配后，汇集部件谱系、装舰记录与本坞试验记录，申请系泊检定。
2. 舰装谱系检定局依标准检查装舰状态与系统配合，在有关谱系卡及全舰系泊检定记录上签印；发现缺陷的，交船坞修整后复验。
3. 验收组据系泊合格记录审查开航条件，确认防护、随舰人员、试验设施与应急安排具备，始得提请验收试航。

### 第十六条 试航许可与空域

1. 试航由受托城邦的船坞申请，国用工务总局会同联盟军事委员会后勤装备部报送工艺与奥术科技部许可。
2. 申请附型号标准、系泊检定、试航科目、随舰名册、施法与器物使用许可、防护救援安排及拟用空域；工艺与奥术科技部在许可文书中列明试航范围与开航条件。
3. 试航使用工艺与奥术科技部布局之常设试验场空域；临时扩展部分由联盟军事委员会提出需求，天空航务部协调公告，涉及城邦空域的会同该城邦。试航限于联盟空域内。
4. 航道空港局依《天空航道与空港规程》第十九条引导民用船艇改道；船坞依航道气象与风暴预报台的预报及许可所列条件决定开航。

### 第十七条 随舰人员与现场分工

1. 船坞随申请报送随舰名册，列明试航主持人、操舰负责人、各工段负责人、随舰工匠、检定与认定人员、军方接收及保障人员。
2. 船坞长依获准计划组织试航，由工段负责人分派工艺作业；舰队接收人员参加装备状态与勤务交接，军方随舰人员依名册承担操舰或安全保障职责。
3. 甲板依《禁魔分区规程》第六条划定自由施法区，设置青色界标与防护结界；结界维护人员维持安全区，工艺人员按已定科目作业。

### 第十八条 施法与器物使用

1. 随舰施法者须持相应施法执照；十至十三环施法者持载有该环段之执照，特殊用途与高危活动另取禁术管制委员会特殊许可。
2. 十四环非弦术式依《银色联盟宪章》第三十八条，经十二环不少于九席事先同意，文书载明对象、术式范围、条件、期限及记录要求，并于事后封存复核。
3. 器物使用依《魔法基本法》第八、十一条审查其启用条件、施术者知识与承载条件；施法或器物启用所需许可未齐备的，不得列入试航科目。
4. 平台供能、器物辅助与施术者自身能力分别记录；依赖器物之成果不得登记为个人永久能力。

### 第十九条 试航科目

1. 验收试航包括航行、动力、结界、通讯、施法平台负载及舰载封印装置等科目，操作条件、合格标准与试验期限由联盟舰装标准另定。
2. 新型号首舰执行全部科目，以验证设计与建造；同型后续舰完成全舰系泊检定，并按标准规定执行简化试航。
3. 经改装或采用影响系统性能之变更的，依标准增列相应科目；验收组不得以已交付同型舰的记录代替本舰应做的检验。
4. 各科目记录实作条件、参与人员、部件状态及结果，由负责检定与认定者分别签认。

### 第二十条 缺陷、修整与复试

1. 发现缺陷，现场负责人立即停止受影响科目并采取安全措施，验收组记录缺陷位置、所涉系统及处置经过，责令承造者修整。
2. 船坞工段负责人组织修整，有关承造工坊配合；修整记录保留原缺陷与所更换、调整的部件，不得涂销原谱系。
3. 修整后由验收组组织复试，检定员记明该科目及受影响系统之结果；尚有影响安全或交付用途的未合格项目，不得签发合格验收证书。

### 第二十一条 事故处置

1. 发生事故，现场负责人依《魔法基本法》第三十三条先组织救助、隔离风险、保全证据，通知受托城邦救援及有关主管机关；运营责任人按批准预算先行救助与必要修复。
2. 工业事故之技术调查由工艺与奥术科技部牵头，检验单位依职责鉴定；原审批或运营人员不得独自认定自身无过错。
3. 赔补、估价与先付后的追偿依《契约与赔补法》第十七至二十二条；事故记录与责任证据分别查明，不得仅凭事故发生认定犯罪。
4. 恢复试航须完成必要修复与复验；许可条件受影响的，报工艺与奥术科技部重新审查。

## 第六章 验收、交付与入列

### 第二十二条 验收证书

1. 系泊检定、规定试航及缺陷复试均已合格，验收组确认建造符合所据标准与履约要求后，依附件签署验收证书。
2. 证书记明型号、舰序、所据造舰令、舰装标准、预算授权、试航许可、检验结果与所附谱系目录，各方就其职责签认；有未解决之技术或履约异议的，应记明理由并组织查验。
3. 验收证书为军工履约验收凭证，由国用工务总局保存正本，副本送银烛会供战备审查、送盟约监察院供审计，并报白银议会备案。

### 第二十三条 交付与档案

1. 国用工务总局依合格验收证书组织交付，舰队司令部派员接收；交接文书记明舰体、装备、备件、谱系档案、维护要求及交接双方签署。
2. 舰装谱系档案随舰保存，并由国用工务总局另存完整副本；改装、大修、部件更换与复验续记其中，承接工坊应保留其制作记录。
3. 交付后的缺陷报告送国用工务总局，由其依履约责任组织有关承造者处理；舰队记录装备状态并提出维护需求。

### 第二十四条 编入建制与典礼

1. 舰队司令部接收合格舰只后，依议会批准的年度编制表确定所入建制，报联盟军事委员会登记。
2. 入列登记应载舰只身份、验收与接收文书、所属建制及舰长任命凭据；编制数量与舰种配比依年度编制表。
3. 入列典礼由联盟军事委员会军政部主持，公共文化与礼典部协办；典礼所用舰名与舰徽依登记文书。

### 第二十五条 舰名与舰徽

1. 舰名由联盟军事委员会军政部拟定，报白银议会备案，并登记于联盟军籍与荣誉档案；舰队司令部据此记入单舰档案。
2. 舰徽由舰队司令部提出，军政部审定登记；获授单位荣誉的，得依《银色联盟防务基本法》第五十六条标示相应荣誉。
3. 建造、试航与验收文书以型号及舰序识别单舰，舰名栏于入列时据命名文书填录，保持与原文书相互对应。

## 第七章 监督、救济与施行

### 第二十六条 监督与查验

1. 银烛会船坞与军工监察司依职掌监督产能基线、委托契约执行及军工质量；联盟战备审查署船坞产能核验科会同国用工务总局实施年度核验。
2. 盟约监察院军务监察厅独立审计军事预算及相关实物拨付；有关机关、城邦与承造者应依法提供原始凭证及查验条件。
3. 联盟公产监督管理委员会履行船坞出资人监督，发现重大处置或履约问题的，依其权限提出处理意见。

### 第二十七条 告知、复核与争议分流

1. 不予许可、不予检定合格或要求补正、整改的，作出机关应书面说明事实、依据、理由、应补事项及复核、裁断途径；技术异议附原检验记录。
2. 当事人得依《白银执政院组织架构》行政实施通则向有权上级机关申请复核，亦得依法请求裁断；同一事项已有机关记录的，由机关间调取。
3. 预算追加报议会，合规疑点报盟约监察院，权限与行政合法性争议报银章裁断庭，军工履约中的赔补与契约争议报联盟公法裁断庭，依《银色联盟防务基本法》第三十九条处理。
4. 争议部分不得无授权支付，未争议且已获授权部分继续履行。

### 第二十八条 费用与责任

1. 建造、检定、试航、验收及交接的费用，依批准预算与有效契约分别承担；应列军备与军工账的支出按该账核销，费用标准与具体数额由议会授权规定另定。
2. 承造者未按约交付或所交部件有缺陷的，依契约承担修整、重制及赔补责任；损害请求依《契约与赔补法》登记、查明与裁判。
3. 涉嫌违反《联盟罪名与刑罚法》的，由有权机关依法调查、移送；各机关分别保存技术检验、履约责任及违法线索记录。

### 第二十九条 公布与施行

1. 本规程经白银议会两院通过，由元老会轮值主席签署、加盖议会印信，移送银章文枢署登记编号并发布联盟公报；施行安排由议会另定。
2. 工艺与奥术科技部会同国用工务总局依本规程公布报送格式、责任窗口、补正要求及工作程序；申请、检定、复试与交付期限依有效授权另定并告知当事人。
3. 已在建舰只由国用工务总局会同受托城邦按工程实际整理已有谱系与试验记录，依议会所定施行安排补齐尚应检验的项目。
