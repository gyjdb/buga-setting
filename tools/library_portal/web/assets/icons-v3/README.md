# 白塔图标 v3

v2 的收尾精修：沿用原有风格，统一细节，提高小尺寸辨识度。文件名与 v2 相同，可直接替换。

## 目录

```
白塔图标/
  馆徽/        emblem-b-small.svg、emblem-b-mid.svg、emblem-b.svg
  馆徽/归档/   A、C 组 v2 原文件（未改动，不作为主标识）
  侧栏图标/    nav-*.svg，10 个
  主题图标/    topic-*.svg，6 个
  预览/        图标预览.html、尺寸对照@1x.png、尺寸对照@2x.png
  baita-colors.css   可选：主题图标与馆徽的换色映射
```

## 推荐尺寸

| 资产 | 推荐显示尺寸 | 画板 |
|---|---|---|
| 侧栏图标 | 20 或 24 px | 24 × 24 |
| 主题图标 | 32、40、48 px，大卡片可放大 | 32 × 32 |
| 小号馆标 `emblem-b-small` | 高 32 到 64 px（页头、侧栏） | 36 × 48 |
| 中号馆标 `emblem-b-mid` | 高 64 到 160 px | 36 × 48 |
| 完整馆标 `emblem-b` | 高 160 px 以上 | 36 × 48 |

- 馆标只设高度，宽度按 3:4 自动计算。三个版本 viewBox 相同，骨架一致（尖拱、菱形顶饰、底座、塔身轮廓），只是细节逐级增加，可以直接互换。
- 每个文件的根元素带有与画板相同的 `width`/`height`，作为默认尺寸，可被 CSS 覆盖。

## 配色

**侧栏图标**只使用 `currentColor`：描边、20% 透明底色和实心点缀都跟随父元素的 `color`，普通、悬停、选中状态直接用 CSS 控制。

**主题图标和馆徽**共用 5 个颜色。文件里直接写默认色（适合深色背景），不含 CSS 变量，任何渲染器和设计软件都能正确显示。每个上色元素另带一个角色类名（如 `bt-fill-ink`、`bt-stroke-silver`），需要换色时由站点 CSS 接管。

| 角色类名 | 变量 | 默认（深色背景） | 浅色背景建议 | 含义 |
|---|---|---|---|---|
| `bt-fill-ink` / `bt-stroke-ink` | `--baita-ink` | `#e2e6e0` | `#26363a` | 银白：主轮廓、主纹章、白塔 |
| `bt-fill-silver` / `bt-stroke-silver` | `--baita-silver` | `#a9bbbb` | `#6f8487` | 银灰：拱门和次级纹理（文字线、链条、币沿、晶体暗面、星芒） |
| `bt-fill-field` | `--baita-field` | `#2f474c` | `#dfe5e2` | 深石青：主题图标主体底色 |
| `bt-fill-warm` | `--baita-warm` | `#d8b878` | `#c08f45` | 暖光：只用于馆徽窗光 |
| `bt-fill-niche` | `--baita-niche` | `#0d171a` | `#e4e9e6` | 龛内底色：只用于完整版馆徽（62% 不透明度） |

换色方法：在站点里引入 `baita-colors.css`。它把上述类名映射到 CSS 变量（每个变量都带默认色），并附一个浅色主题示例：

```css
.theme-light {
  --baita-ink: #26363a;
  --baita-silver: #6f8487;
  --baita-field: #dfe5e2;
  --baita-warm: #c08f45;
  --baita-niche: #e4e9e6;
}
```

给浅色区域的外层容器加 `theme-light`（或改成站点自己的主题选择器）即可。不引入这个文件时，一切按默认色显示。

## 引用方式

- 需要 `currentColor` 或换色时，请把 SVG 内联到页面里。用 `<img>` 或 CSS 背景引用时，侧栏图标会显示为黑色，主题图标和馆徽只显示默认色。
- 侧栏图标也可以作为 CSS `mask-image` 使用，背景色设为 `currentColor`，20% 底色会保留为 20% 透明度。
- 侧栏图标根元素带 `aria-hidden="true"`，由旁边的文字承担语义；单独使用时请去掉它并加 `aria-label`。主题图标和馆徽带 `role="img"`、`aria-label` 和 `<title>`。

## ID 与内联

全部文件都不使用 mask、clipPath、渐变、滤镜或任何 id 引用，同一个 SVG 在页面中内联多次也不会冲突。v2 中财政图标和馆徽塔身用到的 mask 已改为几何路径：镂空用 `fill-rule="evenodd"`，钱币叠压处直接计算切口。文件中没有脚本、`<style>`、内联 style、外部字体、外部图片或位图，坐标精度为两位小数。

## 本轮主要修改

**馆标**
- 正式采用 B 组「拱门＋白塔」。完整版去掉拱顶的洞察之眼圆章，三个版本统一为同一枚菱形顶饰。
- 塔身加宽约 25%（48 px 高时约 7.5 px 宽），尖顶改为更清楚的钟形，两侧小尖塔缩小，窗孔和门洞加大。
- 拱门线重略减，拱形稍尖，缩小后仍能看出尖拱。
- viewBox 改为紧贴图形的 36 × 48，四周留白 0.6，修正 v2 顶饰超出画布被裁切的问题。
- 中号保留内侧细线和两侧菱形；完整版保留珠饰、卷叶、柱头、星点和塔身开窗。

**侧栏图标**
- 统一 24 网格、2 px 安全边距、主线 1.8、次线 1.5、圆头圆角、纸张类转角半径，以及 20% 底色加少量实心的比例。
- 按实际渲染的墨量校正分量：v2 最轻与最重相差约 2.3 倍，v3 约 1.5 倍。
- 羽毛笔：羽片加宽，一半实心，加羽片缺口和书写线。
- 机构总目：实心屋顶和三根柱改为描边山墙和三扇尖拱窗，呼应馆标的尖拱。
- 全部馆藏减为三本书；版本与关系的节点加大；沙漏加宽，上下座改为实心。
- 首页拱门采用与馆标相同的尖拱比例；主题总目保留四格，实心格内开一个菱形窗；现行法典去掉右侧小扣。

**主题图标**
- 统一 32 网格：主轮廓 1.75，小部件 1.5，次级线 1.4，最小间隙约 1.2。色彩层级统一为「深石青底色＋银白轮廓与主纹章＋银灰次级纹理」。
- 宪政：去掉卷轴铆钉，卷轴两端改为圆头，印章简化。
- 魔法：底座圆环去掉小菱形点，晶体保留明暗两面，两侧星芒放大。
- 司法：横梁、剑身、链条加粗，剑柄简化。
- 防务：去掉内侧细线和城垛圆点。
- 学术：文字线由 1.05 加粗到 1.4，去掉角饰和背后的书页层，改为一条书封边。
- 财政：去掉虚线圈和币边刻纹，改为实线币沿和更大的星，取消 mask。
