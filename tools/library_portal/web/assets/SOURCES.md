## 洞察之眼

阅读器书名页、样张章首与首页书封上的洞察之眼为本项目绘制的矢量图形（光冠版，2026-09-22 作者选定），依据风土志第五章“一枚悬于碧蓝海洋之上的眼睛”与作者答复 FA15：眼睛之上一圈放射光刃，下方两道海浪。配色沿用作者提供的徽记定稿（蓝 `#1A5A8A`、银白 `#E9EDEF`、辅色 `#A9C3D2`）；网站书籍部分的强调色随之改为 `#1A5A8A`。图形与配色是版面演绎，形状细节不构成对设定的补充。封面（档案馆藏本）、衬页的花纹与藏书票、书名页与封面上的拉丁馆藏章用的是同一枚徽记，由程序按纸面尺寸绘制（`book.js` 的 `bookCoverHTML`、`bookEndpaperHTML`、`bookTitleHTML`）。

## 已确认设定的对应关系

依据 `organized_project/01_CURRENT_CANON/学术与研究机构/白塔章程_v2_2_2.md`：

- 第二条的异质位面与内部楼层、回廊：转化为画面中的纵深和空间尺度；不推断实际建筑式样。
- 第三条的知识保藏与文库：转化为成排典籍、书廊和长期保管的材质。
- 第六条原文“白塔封存的知识不予销毁。”：首页摘句，链接到该条。
- 首页宪章摘句实际读取 K12 正文第二条，版本与数量读取现有数据。
- K12 导读根据规范层级、公民保障、议会、行政、裁断和财政章节；K28 根据位面、守护与保管规定；K20 根据魔力、环级、许可、禁制与公共秩序。主题导读只概括对应现行文献。
- 来源关系读取 `versionSets` 的 current / candidate / changelog / evidence；不推断机构隶属或版本先后。Archive 是馆藏语境，没有新增机器状态。

## 拉丁书封

`Charta Foederis Argentei`：本轮为这件书籍物件制作的拉丁题名，表达“银色联盟宪章”，不确认为世界内既有官方译名。

- [American Heritage：Magna Carta 词源](https://ahdictionary.com/word/search.html?q=magna+carta)：charta 的 charter 义。
- [Lewis & Short：foedus](https://atlas.perseus.tufts.edu/dictionaries/entry/urn%3Acite2%3Ascaife-viewer%3Adictionary-entries.atlas_v1%3Alat.ls.perseus-eng2-n18493/)：盟约、联盟；foederis 为属格。
- [Logeion：argenteus](https://logeion.uchicago.edu/argenteus)：银制、银色；argentei 与中性属格配合。该词条已在真实浏览器检查。

书封三行拼写经原图及浏览器放大图核对，文字作为透视中的哑银题签呈现。正式界面没有新增拉丁馆名、菜单、格言或英文展示口号。
